- Transaction Checklists
- Support for Searching Listings by Full Listing Address ( Original & New CMS ）
- Improved Mobile Navigation for Listings ( New CMS Only )
- Form Block Button Action Optimization ( New CMS Only )
- Landing Page Registration Rules Optimization ( New CMS Only )

## Menu Layout Change

A quick change that is worth pointing out is that the layout of the main navigation menu has changed. The available options on the menu have not changed, but their order has been adjusted in order to provide more structured access to the most-used features on the platform.

## New Transaction Detail Page

A new Transaction Detail Page has been built as the central location for upcoming Transaction Management improvements.

The transaction name is displayed directly at the top along with the transaction owner and the associated lead:

The transaction stages at the top are clickable to move the transaction through the transaction pipeline:

You can easily edit, delete, or send to an integrated platform (Brokermint, etc.) using the options at the top-right:

The available tabs in the main section include the following:

- Checklists . See below. This is a new feature with this release.
- Accounting . Includes the numbers of the transaction.
- Vendors/Partners . See How to Assign a Vendor/Partner to a Transaction .
- History . Displays a log of all changes/actions to this specific transaction.

## Transaction Checklists

Along with the redesign to the Transaction Detail Page, a new Transaction Checklist feature can be used to create tasks that are triggered at each stage of the transaction. This is done by creating templates that can then be applied to a transaction. These templates can only be edited by the Team Owner/Admin or those on the team who have the "Manage Team" permission (see Team Permissions ).

For more information on this new feature, please reference the following Help Center article: Transaction Management Checklists .

## Support for Searching Listings by Full Listing Address

*Available on Original & New CMS

An improvement has been made to the buyer searching experience on your Lofty IDX website. Previously, searching for a specific address would not produce viable results. With this release, we have now made it possible to search a specific address without the obstacles that previously existed. If a visitor to your site has a specific address in mind that they want to find, they can easily use the search bar to find it:

## Improved Mobile Navigation for Listings

*Only available on New CMS

With this release, visitors to the mobile version of your site will be able to more easily navigate between listing detail pages and the original list the were viewing. With the “down” arrow, visitors can go back to the property list (including map view and grid view), and they can use the "PREV" and "NEXT" buttons to go back and forth on the list.

Also, in order to better capture lead information, common actions be leads are presented/pinned to the bottom of the screen:

## Form Block Button Action Optimization

*Only available on New CMS

Due to restrictions by some browsers (including Safari), an additional configuration has been added to the Form Block (see Form Block ) that will confirm the redirect prior to sending the site visitor to another page. Existing forms will have this functionality applied to them.

This is where the new settings are located when editing any form block:

When the "Toast" option is selected, it will not redirect the user and instead will display a pop-up with the wording that you choose:

When the "Destination URL" option is selected, there are a couple more options. You will choose the "Thank You Message" as well as the button description for the redirect option, and then you will select a destination URL. Leaving it with the "/" will send the user to the Home page when clicked.

The new option to "Turn on to Preview the Button Action" will show what the action will look like when the form is submitted. For example:

## Landing Page Registration Rules Optimization

*Only available on New CMS

Landing page registration settings have been improved to make the transition to a redirected page work more smoothly. With this improvement, the registration rules of the landing pages will take effect on both the landing page and the pages after it redirects. This will allow users to better control the registration pop-up on this transition.

*IMPORTANT : Please note that if you plan to test the registration rules (which is always a good idea), be aware that having the main IDX website and a landing page open at the same time and in the same browsing session, etc. will likely cause a conflict. Be sure to test using a new incognito window each time you test or be sure to clear the browser cache and cookies.
