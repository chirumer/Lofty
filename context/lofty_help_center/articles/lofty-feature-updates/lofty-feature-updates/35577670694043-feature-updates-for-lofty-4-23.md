## Mass Pause and Resume Smart Plans

If you've ever wanted to hit the pause button on all your automations while you're away from work, we have a solution for you! Lofty now allows you to mass pause and mass resume all of your Smart Plans, both for all leads that are subscribed to a specific plan, or for all the plans subscribed to a specific lead.

A report is available so you can see the results and verify that your Smart Plans were successfully paused or resumed. Learn more here: Managing Smart Plans

## Select Scope When Copying a Transaction Checklist

With this update, a Transaction Checklist template can be copied to a scope other than what it was created for. That is, if a Transaction Checklist template was created under the Company scope, you could copy that template under your own Personal scope.

Learn more about simplifying your transaction management here: Transaction Management Checklists

## Unlink or Update MLS Claimed Listings on a Transaction

If you've ever selected the wrong MLS transaction when creating a transaction in Lofty, you know the pain of needed to start your transaction over from scratch. With this update, the MLS transaction can be easily unlinked or updated.

Learn more here: Transaction Management Introduction

## AI Blog Generation

We have added new blog capability to AI Copilot! Copilot can help draft a Listing or General blog post. Access the blog writer via the AI chat box or in the CMS tool.

Check out this video to see it in action!

Learn more about the features available with Copilot here: AI Copilot
