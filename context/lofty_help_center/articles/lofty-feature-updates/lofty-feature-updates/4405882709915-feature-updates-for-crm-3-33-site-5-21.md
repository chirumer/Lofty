## CRM 3.33

### Postcard Self-Purchase Process Improvement

The self-service postcard process has been improved so that you can define recipients, choose your mail settings, and submit a postcard order before actually finalizing the design. This change was made based on the fact that any postcard design might take an extended amount of time to complete which means having the order scheduled to send gets you one step closer to sending any mail content so you can design

As long as you complete the design before the schedule print date, the campaign will be sent out. If the design has not been edited before the scheduled print date, it will not send.

Notifications have been put in place to remind you of when you need to edit your designs for pending postcard campaigns.

Learn More: Self-Service Postcards .

### Postcards + Smart Plans

As part of this release, you can now send postcards via Smart Plans. This feature is available at both the "My Smart Plans" and "Team Smart Plans" levels.

Learn More: Sending Postcards Automatically via Smart Plans .

### AI Assistant Renter Dialogues

A new setting has been added to the AI Assistant settings that allow you to decide whether you want it to qualify renter leads or not. If you would like the AI Assistant to offer your services in response to rental inquiries, please choose "No." Otherwise, choose "Yes" and the AI Assistant will politely end the conversation with the lead if responding to interest in renting instead of buying.

Learn More: AI Assistant / Chatbot Setup Process .

### API Authorization Improvements

For your information, we have implemented a new authorization that allows vendors/partner applications to easily create a direct connection with the Lofty platform. This is via OAuth 2.0 which is the new authorization method that will be utilized for integrations moving forward. This method also allows for you as the user to have more control of your authorization (see Managing Authorization by Third-Party Apps & Services ).

### Registration Pop-Up Builder

The website forced registration pop-up has been simplified by establishing two preconfigured options focused on (1) higher conversion and (2) higher quality. For more granular control, there is still an option to choose custom registration settings.

Learn More: Registration Pop-up Trigger Rule .
