### Release Date

The release date for this set of features is Monday, October 21, 2019.

### Summary

- Slybroadcast Integration (Web)
- Undelivered Texts on Lead Profile Timelines (Web & App)
- Landing Page Tag/Note Optimization (Web)
- Smart Plan Optimizations (4) (Web)
- MLS Agent ID Search (Web)
- Direct Mail Text Code Feature (Print Product Only)

### Slybroadcast Integration

Lofty now integrates directly with Slybroadcast! With this feature, users can send pre-recorded voice messages to leads individually, in batches, or via scheduled Smart Plans ("My Smart Plans" only). Voice messages that are sent will be documented in lead profile timelines.

Specific information on how this integration works can be found HERE .

### Landing Page Tag/Note Optimization

When building landing pages via the CMS Tool, the "Lead Generation" template also provides settings to add a note and/or a tag to leads that register via that landing page:

With this update, this feature has been optimized so that tags and notes can also be added to existing leads already in the database if they complete the form again.

### Smart Plan Optimizations (4)

#### (1) Excluding current leads in the database

Previous to this update, whenever "Auto Apply" conditions are set up on a Smart Plan, all current leads and new leads will BOTH be added to that Smart Plan as long as they match the criteria. With this update, however, the criteria for “whenever leads meet the specified conditions” will now have the following options to select from:

- include current applicable leads
- exclude current applicable leads

With the second option, all current leads that match the specified conditions can be skipped on this Smart Plan for situations when you have already been working those leads and do not want to start them on a new Smart Plan.

*Should you want to exclude more leads, the criteria can always be edited.

#### (2) Send first auto email/text during a specific time range

This option is available for "Immediately" and "Wait ___ hour(s), ___ minute(s)." When selected, if the Smart Plan is triggered before the indicated time range, the auto email/text will be sent at the first available time within that range. If triggered after the indicated range, the auto email/text will be sent the following day at the first available time within the range.

#### (3) Resubscribe leads to Smart Plans if lead has accidentally unsubscribed

To resubscribe for the lead, go to Lead Profile > Smart Plans > Click on the gear icon at the top right. This switch was previously locked. Now, it can be turned back on to resubscribe the lead to Smart Plans.

#### (4) New auto email Lead Variables

Lofty has added two new lead variables to reference buyer-related property addresses in Smart Plan auto emails and auto texts. The new variables are the following:

- buyer_inquired_listing_addr . The address of the property that is associated with the lead's initial inquiry.
- trigger_behavior_listing_addr . The address of the related listing when the Smart Plan is triggered by leads requesting showings, saving listings, or viewing a listing multiple times.

Lead Variables can be found here when building an email template directly in a Smart Plan:

### MLS Agent ID Search

Lofty users can now find their "MLS Agent ID" by searching by listing address or MLS Listing ID. To do this, simply click on the "Need Help?" hyperlink under Settings > User > Profile > to the right of MLS Agent ID .  As a reminder, the MLS Agent ID is a requirement for certain features to work including certain Listing Discovery and Transaction Management features as it helps Lofty locate your MLS listings or your MLS transactions .

### Direct Mail Text Code Feature (Print Product Only)

A brand new text code feature will be available for clients who have purchased Lofty 's Direct Mail (or Print) product. For each client, Lofty assigns a virtual number and a unique code for each and every postcard that is sent out for geo farming. When homeowners text the text code to the number on the postcards, they will get a home evaluation report immediately. Meanwhile Lofty tracks and imports the homeowners’ info into the CRM.

When homeowners call the number on the postcard, Lofty will display the lead source on the phone and track and log inbound calls on the CRM.
