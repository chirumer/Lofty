## Dashboard and Reporting Page UI Updates

Overview

The updated Dashboard and Reporting page UI is being released to all Lofty users. We have been beta testing this UI, so you may already have had access.

Learn how to navigate your new dashboard here: Dashboard Overview

Learn how to navigate your new Reporting page here: How to Navigate the Reporting Page

## Right Panel UI Update

There's no change to your current functionality, but your notifications, workspace, AI Assistant, and calling/texting features have been condensed into a new panel on the right side of the screen.

## Calendar and Tasks UI Update

Overview

- Calendar, Task, and Showing modules are now grouped under the Calendar menu for easier access.
- Refreshed visuals in the Task and Calendar views, including agent headshots, icons, and layout enhancements.

Before | After

Release Details This update improves navigation and consistency by consolidating the Calendar, Task, and Showing modules under the Calendar menu. The Task module now includes agent headshots (or default images if unavailable), hover-over name display, a lead identification icon, and property details for transaction-related tasks. The Calendar module features a new color scheme and layout for a cleaner, more intuitive experience. The Showing module remains unchanged. Learn more here: Lofty Calendar

## Checklist Template Folders

Overview

- Transaction checklist templates are now organized into folders for easier management.
- Existing templates are automatically migrated, and permissions have been simplified.

Release Details Checklist templates are now stored in folders based on scope - Personal , Office , or Company - to improve clarity and navigation. Folders can be created, renamed, and managed in Settings → Transactions → Checklist Templates , and all new templates must be created within a folder. Your existing checklists are automatically migrated:

- Personal checklists → folder named after the user.
- Office checklists → folder named after the office.
- Company checklists → folder named after the company.

Learn more here: Transaction Management Checklists

## Active Segments

Overview

- Active Segments now automatically update lead lists in real time based on saved filters.

Release Details Active Segments provide dynamic, rule-based organization of leads that update automatically as lead data changes. Leads are instantly added or removed when they meet or no longer match the defined filters, keeping lists current without manual updates. Learn more here: Lead Organization with Segments
