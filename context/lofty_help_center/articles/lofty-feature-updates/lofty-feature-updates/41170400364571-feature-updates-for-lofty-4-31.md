## AI Sales Assistant Can Now Email!

The AI Sales Assistant now supports email in addition to text and chat, with replies sent in about 15 seconds.

Sales Assistant can monitor and respond to both new lead emails and ongoing threads using the email address set in Email Settings, ensuring seamless conversations across channels. We've also updated the AI Sales Assistant settings, so it's now easier to share the assistant across all users on the account. Learn more here: Getting Started with AI Sales Assistant

## Appointment Time Schedule Optimization

Appointment scheduling is now smarter: times adjust automatically when the start time changes, and all entries snap to 15-minute increments to prevent errors.

Appointments now default to the next 15-minute interval, with a one-hour duration that can be adjusted. The start time will always be before the end time and the ending time moves when start times change. This reduces errors and ensures smoother scheduling. Learn more here: Appointments

## Goal Module Update (Available Sept 25)

A new Business Goal Contribution Breakdown chart helps leaders track production by office and sub-offices. Activity goals are now optional when setting up goals with only Business Goals being required.

Starting September 25, account admins with user management permissions can view contribution breakdowns across offices and sub-offices for clearer performance insights. Goal setup has also been simplified: Business Goals remain required, while Activity Goals are now optional. Learn more here: Goal Setting Portal

## Activity Reporting Log: Beta Test (Available Sept 25)

A new Activity Log helps agents track performance, log custom metrics, and view leaderboards. Company admins can configure up to 10 metrics, with the option to make some mandatory. This feature is available only for accounts with the New Reporting Page Layout beta feature enabled on their account.

The Activity Log includes:

- My Activity : Agents can view performance, complete reporting tasks, and log custom metrics.
- Leaderboard : Shows rankings across default and custom metrics, visible by team hierarchy.
- Custom Metrics : Admins can configure up to 10 metrics in Company Settings, with mandatory options that trigger daily 6:00 PM reminders and submission pop-ups.

This structured reporting reduces errors, standardizes metrics, and ensures compliance where required.

Learn more here: Agent Activity Metrics
