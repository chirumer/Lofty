## Social Studio Auto-Post Logic Optimization

- Redesigned auto-post controls make “My/Team/Other” toggles the single source of truth.
- Prevents unwanted or duplicate social posts.

Each category toggle (My, Team, Other) now independently determines whether listings in that category auto-post on status change based on your triggers. Turning a toggle OFF stops future auto-posts regardless of existing feed records; turning it ON allows auto-posts when conditions match. “Clear All” still resets feed records, triggers, and connected profiles.

Actions for You Review and set desired toggles. Use Clear All to restart setup if needed. Learn more here: AI Marketer

## Goal Setting Optimization

- Activity Goals are now separate from Business Goals.
- New Activity Goal report under Reporting → Agent Activity.

You can set call/appointment objectives without creating transaction goals. Reporting adds a dedicated Activity Goal view for tracking progress, improving clarity for roles such as inside sales agents.

Actions for You No action required. Optionally review goal configurations and use Reporting → Agent Activity → Activity Goal . Learn more here: Goal Setting Portal

## Transaction Page Update & New Offer Page

- Refreshed Transaction UI with clearer navigation.
- New Offer tools: shareable link, manual entry, and per-offer management.

In Listing-type Transactions, the Offer tab supports link-based submissions from buyer agents and manual entry by listing agents. You can mark, edit, delete, and note offers. The History page is now called Activities ; controls for type switching, List/Board view, and Stage Settings are streamlined.

Actions for You Go to Listing-type Transaction → Offer tab to create/manage offers. No other action required. Learn more here: Offer Management

## Revamped Dotloop Integration

- Modern two-way sync via OAuth2 and webhooks.
- Manual claim/mapping of Dotloop loops to Lofty transactions.

Connect Dotloop in Personal Settings to enable real-time updates both directions. Send to Dotloop from Lead/Transaction, map existing loops, choose data precedence during claim, and view synced documents in a dedicated folder. Disconnecting does not remove historical data.

Actions for You Reconnect Dotloop via Personal Settings → Integrations to activate the new sync. Learn more here: Dotloop Integration

## Canva Integration

Note: This feature is expected to be available by the end of the year.

- Lofty × Canva app lets you design with live listing/agent data.
- Export finished designs back to Lofty for centralized storage.

Install the Lofty app in Canva to drag-and-drop Listings or Agent details into templates. Exports are saved to Design Center → My Designs → Canva Designs (auto-created). Works with free Canva accounts.

Actions for You Install “Lofty” from the Canva App Marketplace and sign in to connect. No further setup required. Learn more here: Canva Integration

## New Lofty AI Assistant Layout

Note: This updated is expected to be available on Wednesday, November 19.

AI Copilots is our new Lofty AI brand and consists of two key components:

- AI Assistant – This is the chat feature accessible via the right-side menu bar.
- AI Agents – This page showcases all the AI agents we currently support or plan to support

The Assistant centralizes chat, email/SMS, reminders, and web search, while domain-specific Agents execute tasks (e.g., sales follow-up, marketing). Users interact with one Assistant that coordinates underlying automations.

Actions for You No action required. Access the Assistant where Copilot previously appeared. Learn more here: AI Copilot

## Lofty AI Assistant - Web Search & Deep Research

Note: This updated is expected to be available on Wednesday, November 19.

- Real-time web search with citations.
- Multi-step research and report generation in chat.

The Assistant can fetch current facts from public sources and compile concise, sourced reports (executive summary, findings, charts when available). Designed to extend beyond internal CRM data for market intel and presentations.

Actions for You No action required. Ask the Assistant questions that need current data or request a research report.

## Lofty SEO Agent - AI Visibility

Note: This is a beta released feature. You may or may not have access to this feature.

- New dashboard for AI Engine Optimization (AEO) performance.
- One-click “Boost Visibility” drafts optimized content.

See Mention Rate, Traffic from AI, and top platforms (e.g., ChatGPT, Claude). Review real AI response samples about your brand/listings. Use Boost Visibility to generate SEO/AEO content ideas and drafts via the Assistant.

Actions for You Visit AI Visibility to review metrics and use Boost Visibility to publish optimized content.
