## Introduction

*Please note that the features available to you on the Lofty platform will vary depending on the package you have purchased. With any questions in this regard, please reach out to your assigned Customer Success Manager or our Support Team for more information.

### Release Date

The release date for this set of features is July 18th, 2019.

### Summary

- Inbound Call Forwarding
- Support Purchasing Call/Text Packages on Teams Under Enterprise Package
- Enterprise / Broker Edition IDX Website (Beta Testing)
- Team Lead Routing for Enterprise Edition (Beta Testing)
- Bounced Email Timeline Optimization
- Search Optimization on Mobile Devices
- Landing Page Optimizations
- More Lead-Related Settings in Landing Pages

### Inbound Call Forwarding

As a feature that has been requested by many of our users, Lofty now provides a solution for making sure incoming phone calls are not missed! Incoming calls to Lofty virtual numbers will be forwarded to a specific phone number if the agent is not unavailable or does not pick up the phone for a specified time.

Team Owners/Admins can easily apply all the calls to the same phone number (e.g. a company number) by applying the rule to all the team members using the switch at the bottom. Otherwise, this setting is managed by each individual user.

Want to know more？You can refer to this Help Center article: Inbound Call Forwarding .

### Support Purchasing Call/Text Packages on Teams Under Enterprise Package

Many Team Admins under Enterprise Accounts have requested the ability to purchase call/text packages in their CRMs. Lofty now supports this feature with this release. They can choose to use their own payment card (if on file via the Support Team or assigned CSM) or the Enterprise Account Admin’s card. If they want to use the Enterprise Account Admin’s card, an email will be sent to the Enterprise Account Admin requesting approval after the Team Admin submits the order. Once the Enterprise Account Admin approves the request via email, the requested call/text packages will be made available to the Team Admin for distribution among agents.

This is a screenshot of what the Team Admin would see when setting up the request to add call/text packages via Settings > Manage Dialer .

This is an example of the approval request email that the Enterprise Account Admin will receive and has to approve before billing is updated:

### Enterprise / Broker Edition IDX Website (Beta Testing)

Lofty clients with the Enterprise Edition now have the ability to beta test a new "Broker" IDX Website which, when leads register, can distribute leads to individual teams. This website must be set up like any other IDX website (requiring MLS data integration, quality review of data, etc.). Here is a glimpse of what it will look like:

### Team Lead Routing for Enterprise Edition (Beta Testing)

For clients currently using the Enterprise Edition (Broker Edition), we are releasing a feature for beta testing that allows you to set up lead routing rules to distribute leads from a main Enterprise/Broker IDX website to different teams. Lead routing from this top level website can only be assigned to teams, not individual agents, and is only able to use the "Round Robin" option.

### Bounced Email Timeline Optimization

In order to better troubleshoot bounced emails, this update will allow for a more detailed description to be documented in the lead's profile. The bounced reason is defined according to the SMTP code in the bounced notification Lofty receives in our email server. Below are the main types that can be listed:

- The email address does not exist
- The email server does not exist
- Rejected by recipient
- Mailbox unavailable
- Blocked due to spam content
- Connection timed out
- Unknown failure

### Search Optimization on Mobile Devices

This update provides some improvements on the "Listing" page on the mobile view:

- Now you can search the listings by address directly
- The filter now displays the number of applied filters
- Searches can now be saved on mobile devices now

### Landing Page Optimizations

As an additional Landing Page optimization, there are now seven new block types that can be added when adjusting the available content:

1. Lead Form
2. Call to Action
3. Listing Search (Address)
4. Listing Search (Advanced)
5. Header (Menu)
6. Header (Simple)
7. Footer

Some of the new block types can be adjusted in the following ways:

Lead Form

Users can edit the title, banner, field, and button action of the block in content.

The " Lead Form" block supports adding the full name field and configuring the button action from one of the below options:

- Jump Link: After clicking the button, the page jumps to the corresponding URL.
- Thank You Message: After clicking the button, the page pops up the toast popup.

*Lofty will support additional custom fields in future planned releases.

Call to Action

Users can edit the title, banner, button number, and button link of the block content:

The " Call to Action" block supports configuration for the number of buttons and the link destination of the buttons. However, only a total of three buttons can be added:

Listing Search (Address)

Currently, no content can be configured with this block.

Listing Search (Advanced)

Currently, no content can be configured with this block.

Header (Menu)

Currently, no content can be configured with this block.

Header (Simple)

Users can choose the agent to be displayed on the banner in the top-right.

Footer

Currently, no content can be configured with this block.

In addition, there is now a new option to create a "Blank Template" for Landing Pages so that users can create their own landing page by adding blocks of their choice. A total of 15 blocks can be added per landing page.

All templates also support the customization of URLs when they are created.

All templates also support the configuration of SEO tools including the commonly-used "SEO Cover Photo" which is the image that will appear when the link is shared on social media.

### More Lead Related Settings in Landing Page

Lead Type

Users can now select the lead type that is going to come in via the "Lead Generation" type landing pages This is found under Landing Page Editor > Settings > Basic Settings.

Lead Privacy and Assignment

Users can control whether the leads registered on the landing pages are Team Leads or Private Leads. Only users given the "Add Private Leads" permission can choose the option for Private Leads.

You can also choose to Directly Assign leads or do so via Lead Routing rules in the Assignment Method section. If you choose Private Lead in Lead Privacy, you can only choose Directly Assign and the Assignee can only be yourself.

Add Tags and Notes for Leads Registered on Your Landing Pages

With this update, you can choose tags and add notes in Landing Page Settings > Additional Actions. All leads registered on this landing page will have these tags and notes added automatically.

Control Welcome Emails/Texts or not

In Landing Page Settings > Additional Actions, you can also choose whether to send welcome emails/texts to the leads who register via the landing pages.
