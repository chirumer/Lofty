# Feature Updates for CRM 3.8.0 and Site 4.13

## Body

### Introduction

*Please note that the features available to you on the Lofty platform will vary depending on the package you have purchased. For any questions related to your package, please contact our Support Team or your assigned Customer Success Manager for more information.

### Release Date

The release date for this set of features is Wednesday, August 19, 2020.

### Summary

- CRM AI Assistant: "Assigned Agent" Control Smart Plan Last Modified Timestamp
- Site (New CMS Only) Market Snapshot Email Multiple Logos Listing Map Optimization for Mobile Devices

### AI Assistant: "Assigned Agent" Control

In this release, users who have purchased the AI Assistant can control whether or not the AI Assistant will work leads depending on who they are assigned to. If you do not want the AI Assistant to follow up on leads assigned to a specific agent, you can now deselect them on the drop-down list under the AI Assistant settings. This option is available for both NEW incoming leads and EXISTING leads as well:

### Smart Plan Last Modified Timestamp

A new timestamp has been added under the "Plan Name" of each Smart Plan in both My Smart Plans and Team Smart Plans . The timestamp simply records the last modified date/time. Currently, you cannot sort by the last modified time.

### Market Snapshot Email

*Only available on the New CMS

As mentioned in the previous release (see Feature Updates for CRM 3.7.0 and Site 4.12: Market Snapshot Page & Block ), the Market Snapshot Email will now send any buyer/seller who clicks the blue "See More Details" button to the updated Market Snapshot page where it will populate the data based on the email they were looking at.

If clients have old market snapshot emails, those links will still go to old market snapshot pages that will display the data in the old format. The pages will not be dead.

### Multiple Logos

*Only available on the New CMS

When using the CMS Tool to edit your website header, you now have the option to add a second logo. Simply double-click the header block and then scroll down to the "Logo2" section of the settings on the left where you can now add an additional logo. You can also customize the alt text, logo size, and even link when clicked. Note that you can only add one extra logo on the main website (via the Home page settings - Header ), but you can add individual logos on any landing pages that are built (see Landing Pages ).

### Listing Map Optimization for Mobile Devices

*Only available on the New CMS

The map search pattern that displays when browsing your site listings on a mobile device has been optimized. It is now easier to zoom in on the map and the interaction with the map itself is more intuitive. Site visitors can also see where the properties are on the map more clearly. They can find the area they want to look and then click the "Search This Area" button to search that specific zone. Overall, the user interface is now more clear and buyers can find the location they are looking for and access the available tools (draw, schools, satellite view, etc.) more quickly.
