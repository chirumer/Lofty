## Introduction

*Please note that the features available to you on the Lofty platform will vary depending on the package you have purchased. For any questions related to your package, please contact our Support Team or your assigned Customer Success Manager for more information.

### Release Date

The release date for this set of features is Wednesday, August 5, 2020.

### Summary

- CRM Dashboard Announcement Board Microsoft Teams Incoming Webhook Connection Resume System-Paused Smart Plans Add to Group Option When Removing an Agent Facebook Lead Form Integration: Import Info to Search Criteria Multiple Small Smart Plan Optimizations
- Site (New CMS Only) Form Block Auto-Tagging Market Snapshot Page & Block

### Dashboard Announcement Board

A new section will now be available on the Lofty Dashboard when you first log into Lofty each day. T he new section appears directly below the "Today's Hot Listings" section on the Dashboard. For more information on how this new feature can be used, see Dashboard Announcement Board .

### Microsoft Teams Incoming Webhook Connection

+

If you have a Microsoft Teams account, you can set up some initial connections by adding webhooks in Lofty. The webhooks need to be set up in Microsoft Teams first and then connected to Lofty.

To learn how to set up Microsoft Teams using Incoming Webhooks, please reference the following article: Microsoft Teams Incoming Webhook Connection .

Currently, the webhook integration supports the following actions:

- Share a Lead to Microsoft Teams
- Share an Announcement to Microsoft Teams

### Resume System-Paused Smart Plans

With the release of this new feature, the Team Owner/Admin (no one else on the team) can now restart multiple Smart Plans that were paused by the system for a variety of reason in the last 30 days. More information on this feature is outlined in the following section: If the system has auto-paused Smart Plans, is there a way to restart them? .

### Add to Group Option When Removing an Agent

As the Team Owner/Admin, you are the one responsible for adding/removing agent users from your team. When an agent is removed, this new feature allows for the leads who belong to that agent to be added to a specific GROUP in Lofty so that they can be easily located, redistributed, etc. The group must have already been created in order for it to populate on the list when removing the agent.

You will see this option appear when you go to remove an agent from your team:

### Facebook Lead Form Integration: Import Info to Search Criteria

The Facebook Lead Form Integration now supports sending additional information from the Facebook Form to Lofty. When you create a lead form on Facebook, it might be built around a specific listing or market area and it would be a good idea to bring that information into Lofty to apply towards lead routing, auto property alerts, etc.

For more information on how to set this up, please reference the following: How do I add search criteria using the Facebook lead form ?

Also, for your information, we have included an additional section that is related to the Facebook Lead Form Integration: How do I set it up so that leads that register on Facebook lead forms do not have to sign up on my site after being sent there? .

### Multiple Small Smart Plan Optimizations

(1) You can now start creating a new Smart Plan by double-clicking the "Standard Plan" option under Settings > Features > Smart Plans :

(2) When changing between task types (Auto Email, Auto Text, Call, etc.) in a Smart Plan, the system will now remember the content for each type if it was already added. Prior to this, the content would be lost when the task type was changed. Now, you can go back if you added something but wanted to see what another task type looked like.

(3) The default trigger time for the first step is "Immediately," but now the default trigger time for the next steps that are added will be "Wait 1 day(s)":

### Form Block Auto-Tagging

*Only available on the New CMS

The Form Block (see Form Block ) now has a new setting for adding tags to any leads who register via that form. This can be used to easily find the right leads post-registration on the People page but it is also extremely useful when triggering very specific Smart Plans (see Smart Plans ). All existing tags will be populated (see Lead Organization with Tags ), but a new tag can also be added here as well.

Here is what that new feature looks like when editing a form block on the website using the New CMS:

When a tag is added, it will be available on a lead profile. Here is a sample tag called "form tag":

Note that this feature also works for existing leads. If an existing lead fills out the form on the website that has been edited to include tags, those tags will be added to the existing lead's profile.

### Market Snapshot Page & Block

*Only available on the New CMS

A new "Market Snapshot" page and block template is now available to use on the New CMS. You can use this page/block to show local market trends and all related (sold) listings. In addition, site visitors can change the search criteria depending on what they are looking for which is a valuable way for them to compare local market results from different areas. This is especially useful for seller leads.

For more information on how the page and block can be set up and used, please reference the following articles:

- Market Snapshot Page
- Market Snapshot Block

Along with this change, note that the "Market Snapshot" emails will be optimized in an upcoming release so that leads that receive these emails will be redirected to these pages when clicking on links. Currently, the Market Snapshot emails that are sent out (see Property Alerts & Market Snapshots (Lead Engagement) ) will have links that, when clicked, will go to the old Market Snapshot pages that are only accessible via the emails.
