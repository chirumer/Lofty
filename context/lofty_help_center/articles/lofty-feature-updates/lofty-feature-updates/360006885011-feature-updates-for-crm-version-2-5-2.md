# Feature Updates for CRM Version 2.5.2

- Article ID: `360006885011`
- Category: `Lofty Feature Updates`
- Section: `Lofty Feature Updates`
- Updated: `2025-11-12T05:27:12Z`
- Source: https://help.lofty.com/hc/en-us/articles/360006885011-Feature-Updates-for-CRM-Version-2-5-2

## Body

Key Takeaways

- Additional Emails to receive Lead Notification (Web)
- Text Notification for Partial Leads
- Seller Welcome Email optimization for single page website users (Web)
- Zapier Optimization- Lead Address Added (Web)

Additional Emails to receive Lead Notification (Web)

You can add additional emails to receive new lead notifications in Settings -Preferences - Additional Emails .

Text Notification for Partial Leads

Now agents can receive text notifications once partial leads are imported from the home-valuation page.

e.g. Hi, it's Lofty ! A new partial lead was assigned to you. 1493 Gingerwood DR, Milpitas, CA 95035

Seller Welcome Email optimization for single page website users (Web)

The email header and login email and password are removed for Single page website users.

Zapier Optimization- Lead Address Added (Web)

Users can export Lead Address to the 3rd-party products via Zapier.
