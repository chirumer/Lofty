- Email Accountability Report
- New Opportunity Notifications
- New Message Notifications
- Additional Sold Listings Settings
- Co-Listing Agent Display
- Zapier Improvements

### Email Accountability Report

This new report will be found under Reporting > Email Accountability .

There are now options to view this report "By Email" and "By Lead." The "Unsubscribed" data can only be calculated based on the number of leads so will be the same whether you are looking at "By Email" or "By Lead."

Filters can also be applied for different time periods (e.g. this month, this quarter, etc.) as well as email type (e.g. property alert, Welcome Email, etc.). The main view is by chart but there is also a table view.

All reports include both Team Leads + Private Leads.

Team Owner/Admin View

The Team Admin/Owner and any users who have the "Manage Team" permission will have the report view for the whole team (see Team Permissions ). Three sections will display for these users: Overview / Email Performance / Email Performance by Agent.

Clicking on an a user's name in the "Email Performance by Agent" section will show a report for just that user.

Standard User View

Users without admin privileges will only have access to their data in these two sections: Overview / Email Performance.

### New Opportunity Notifications

Currently, all Opportunities are outlined here: Opportunities . Additional opportunity notifications will be added to this list under the "High Interest" category with this update:

1. When a lead saves a search on your Lofty IDX website
2. When a lead uses the mortgage calculator 3+ times in one day

With each "Opportunity," a notification will be triggered in the Web App as well as on the Mobile App.

### New Message Notifications

The Lofty Mobile App already has the notification for a new message being received--but this notification was previously unavailable on the Web App. With this update, when a lead sends either a text message to the Lofty virtual number or types a message into the chat box of the website, there will be a web notification as well so that no conversations are missed.

The notification title will vary depending on what type of message is received: "New Text Msg" or "New Chatbox Msg."

If this notification becomes annoying in any way, it can be turned off via the mobile app. Keep in mind that this setting adjusts both the Web App notification as well as the Mobile App notification:

### Co-Listing Agent Display

For Lofty users who are on teams and want to make sure the listing agent is displayed with their property on their Lofty IDX website, this is possible via the CMS Tool. With this update, co-listing agents can also be displayed as well.

To find this setting, access the CMS Tool > Page Editor > Property Details > Listing Detail Agent .

If "Yes" is selected here, Lofty will review all agent profile settings for their MLS Agent ID and License ID to attempt to match the agent with any active listings displayed on the Lofty website. If a match is found, the listing agent and any co-listing agent will be displayed on the listing detail page in the "Schedule a Tour" section as well as the "MLS Info" section.

*IMPORTANT: Please note that the displaying of the listing agent and co-listing agent does not affect the actual lead routing of the lead as it comes into the system nor any messages sent, etc. In other words, only the display of the listing/co-listing agent(s) are presented here but any leads that register would not be sent to the listing agent unless the lead routing was set up to assign to them.

### Zapier Improvements

Lofty 's Zapier integration will continue to improve in future releases. One improvement made in this release is the support for more fields when Lofty is the "Trigger." All fields that were available for the "Action" are now on the "Trigger" menu as well. Here are the supported fields for Lofty as the "Trigger."

- Source
- Group
- Tag
- Note
- Subscription - Smart Plans
- Subscription - Property Alert
- Subscription - Market Report
- Min Price (Buyer)
- Max Price (Buyer)
- City (Buyer)
- State (Buyer)
- Zipcode (Buyer)
- Address (Buyer)
- Min Beds (Buyer)
- Min Baths (Buyer)
- Beds (Seller)
- Baths (Seller)
- Price (Seller)
- SqFt (Seller) (optional)
- City (Seller) (optional)
- State (Seller) (optional)
- Zipcode (Seller) (optional)

This means that all of these fields can be sent out of Lofty when Lofty is triggering a corresponding action in another app.
