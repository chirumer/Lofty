## Lofty WordPress Plugin Optimizations

We've made some exciting optimizations to our WordPress plugin. The newest version allows you to customize your lead capture and registration form as well as set up property alerts.

The WordPress IDX Plugin is available to purchase in the Lofty Marketplace. Learn more here: WordPress + Lofty IDX Plugin

## Website Animation

Your Lofty website has been improved with stunning animation on some of the blocks. See an example here:

Qualified website blocks will already have the animation applied. Navigate to the block style setting to toggle the animation off. Learn more about the website blocks available with your Lofty website here: Lofty Block Library

## More Email and Text Message Variables

We've added new variables that can be used to automatically personalize your emails and text messages. Under General Variables, we've provided variables to identify the time of day, day of the week, month, and season.

Under Lead Variables, we've added a variable for a lead's family member's first name. Under Agent Variables, we've added a variable for the agent's sending email address.

Learn more about personalizing your messages here: Email and Text Variables

## Drag & Drop Email Editor Updates

Our drag & drop email editor has new formatting options! Add pre-built templates for agent details, listing information, and graphs. Also, the text box now supports emojis!

Learn how to use this email editor here: How to Use the Drag-and-Drop Email Editor

## Privacy Regulation: DSAR

DSAR stands for Data Subject Access Request. DSAR is a request that individuals (data subjects) can make to an organization to access the personal data that the organization holds about them. DSARs are a key part of data privacy laws.

If you are based in California, you will see a DSAR button at the bottom of your Lofty built website.

Learn more about what your website visitors can request here: Data Subject Access Request (DSAR)

## Update to Cookie Preferences Default Settings

The cookie settings on your Lofty built website allow your website visitors to decide what data is collected from them and how that data is used. By default, website visitors will be opted out of all non-essential cookies. This does not affect lead registration rates or the data that is collected from your website visitors that you can see in your Lofty CRM. This may, however, show decreased event counts if you use Google Analytics.

Learn more here: Cookie Preference Settings

## Sales Tax Update

Starting April 1, 2025, applicable sales tax will be charged on all Lofty packages and add-on purchases, in compliance with local tax regulations. This means that if sales tax is applicable, the sales tax amount will be added to your total at checkout, based on your location and the nature of the product or service. Sales tax will also be able to be viewed on your invoices. Please verify that your billing address is up to date by visiting your Lofty Billing Center.

Learn about this change here: Sales Tax

## New People Page UI

Over a year ago, we make a significant update to the Lofty People Page UI. We have allowed you to switch between the old and new UIs since this change. However, we have not updated the old UI and it is now out of date and can no longer be supported. If you have been using the old UI, you will see that only the new UI is available now.

Learn how to use the new People Page UI here: Updated People Page UI
