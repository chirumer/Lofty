## Summary

- CRM 3.37 Open House Tablet App Syncing Transaction Management: Column Customization
- Site 5.25 External Website Widget Improvements

## CRM 3.37

### Open House Tablet App Syncing

We have improved the Open House Tablet app and how the app syncs to the CRM. With this update, if leads fail to sync, there will be an error visible on the Open House in the web app CRM.

Once you click View Details , you will see the reason (email duplication or "other") and have the chance to re-upload in scenarios where that failed reason has been resolved.

Learn More: Open House Tablet App

### Transaction Management: Column Customization

With this release, you can now choose which columns they want to display and reorder the columns to prioritize specific information. All users (not just the admin) can customize their own view using the available options. All the available fields will be displayed in the dropdown (system defaults + custom fields). The only column that cannot be reordered is the "Transaction Name" as that will need to stay in the leftmost location.

Learn More: Transaction Management Introduction

## Site 5.25

### External Website Widget Improvements

#### Listing Block + Search Bar

A listing block style has been added that also includes a search bar at the top.

#### Saved Configurations

You can now save your widget configurations and give them a name so that you can edit and reuse them as needed.

Learn More: External Website Widgets
