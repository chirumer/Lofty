## CRM 3.22

### Self-Service Postcards

Lofty has released an exciting new feature allowing you to design and print postcards all within the Lofty platform. Use this feature to create designs, configure engagement mechanisms, and send postcards to your database.

Learn more about this feature here: Self-Service Postcards .

### Billing Center

*Only available via the Lofty Web App (not currently supported via the Lofty Mobile App).

The Lofty Billing Center will now provide you with easy access to review the following directly in the Lofty CRM:

- Account Status
- Amount Due (if any)
- Payment Methods

New pop-ups will appear if any amount is outstanding, a payment has failed, etc. in order to avoid interruption of service.

Future improvements to the Billing Center will include the ability to access previous billing statements and receipts, though that is not part of this initial release.

## Site 5.10

### Listings Block: Market Insights

Your site visitors will now have access to market insights directly in the listing search panel as they search in specific areas. This will be visible inside of all listing blocks. When a lead searches for a specific location (city, county, neighborhood, etc.), the website will display a breadcrumb site map for locations (which is good for SEO) as well as a button to access Market Insights . If a lead searches on the map or by looking for a specific address, this will not be available.

Once clicked, data from the Market Snapshot and Market Trend blocks will be displayed for this area.

*IMPORTANT : Please note that if sold data is unavailable from your MLS, certain aspects of this market insights section will not be visible.

### CMS Block Spacing Options

A new configuration has been added to each block allowing for spacing after all blocks on the website. Previously, a configuration was available to add space before/after the block but the space could not be customized. Now, a sliding configuration is available for ease of use when adjusting the spacing. There is no longer an option for space before a block, only after a block. All blocks now have this option with the exception of the Header and Footer blocks. There is a separate configuration for desktop and mobile views of the website.

Default values are the following:

- Desktop: 30px
- Mobile: 60px

### Style Recommendations

You may begin to see style recommendations when choosing blocks for your website build. These recommendations are simply indicating to you that a certain style matches the template chosen for your website so that you can keep things as uniform as possible.

### Mortgage Calculator: Tax Amount

The mortgage calculator has been improved to allow for a specific amount to be entered for "Property Tax" instead of forcing it to be a percentage.

### Listing Detail Page: Property History Block

A new section has been added to the Listing Detail Page. Leads viewing a specific listing page will now be able to see the history of the property which includes the following events: sold, price changed, listed as active, etc. This block is only available as part of a listing detail page and cannot be used elsewhere on the website.

*IMPORTANT : Please note that may not be available for your website if sold listing data is not provided by your MLS connection with Lofty . If unavailable, this block will not appear on a listing detail page. Please also note that because this is a new feature, many listings will not have a history populated. The history will be built up based on its history within the Lofty IDX website specifically as this data is not fed in by the MLS.

If you want to require registration before showing this information, you can navigate to CMS > Page Editor > Pages > Property Detail Page Group > Property History Block :
