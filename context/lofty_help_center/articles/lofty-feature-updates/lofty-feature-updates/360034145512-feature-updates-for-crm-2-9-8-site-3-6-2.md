# Feature Updates for CRM 2.9.8, Site 3.6.2

## Body

### Introduction

*Please note that the features available to you on the Lofty platform will vary depending on the package you have purchased. For any questions in this regard, please reach out to your assigned Customer Success Manager or our Support Team for more information.

### Release Date

The release date for this set of features is Wednesday, October 9, 2019.

### Summary

- Team Site and Subdomain Site Lead Login Credentials
- Zip Code/City Setting for Auto Alerts
- Add/Edit/Delete Alerts from Mobile App

### Team Site and Subdomain Site Lead Login Credentials

With this update, a lead can continue to browse the main website even if they are working with an individual agent who has their own subdomain and all their activity/triggers will go to that individual agent even if they have a subdomain that the lead is not looking at. Prior to this update, the only way for an individual agent to get notifications and records of a lead's website activity would be if (a) the team website was the only website being used or (b) the lead was browsing their individual websites.

If a lead registered on a subdomain website, he/she can now sign in on the main site using the same login credentials.

The only exception to this is with the website chat box. The website chat messages sent will go to the website's owner. If it is the team's website, the chat goes to the main seat on the account (Team Admin/Owner). If a subdomain website, the chat goes to the individual agent whose website it is.

Currently, the lead’s login credentials can be logged in both in main site and its related subdomains in one team. All lead’s activities can be recorded on to lead detail page in CRM and the assigned agent can receive the corresponding notification (except live chat, still sent to the site owner). Lofty will work on optimizing this in the future.

### Zip Code/City Setting for Auto Alerts

This option will be located under Settings > Features > Auto Property Alerts > Buyer Property Alert/Seller Property Alert/Auto Market Report > Location Criteria.

This update will allow you to set a default location setting for Auto Buyer/Seller Alerts/Market Reports. You can set the auto alert to only trigger based off of the "Inquired City" or "Inquired Zip Code." If you choose "Any," the system will trigger based on both city and zip code.

This information is typically gathered when the lead is imported via email parsing and the city or zip code are provided in the email or, if the lead registered on a Lofty website, their activity will be recorded for this purpose.

### Add/Edit/Delete Alerts from Mobile App

After many client requests, the Lofty Mobile App will now allow Lofty users to add/edit/delete Buyer/Seller Property Alerts on their mobile phones. The filters available on the mobile app will be synced with the web app meaning if users have specific filters from their MLS set up on the mobile app and Lofty website, they will also be available on the mobile app.

Limitations include the following:

1. We do not support the option to "plot" an area on a map when using the mobile app
2. The ability to send individual listings is not supported--only the creation of an alert using the available criteria. This can be done on the web app using Listing Discovery but is not currently available on the mobile app.
3. Market Reports cannot be created with this feature, only Buyer/Seller Property Alerts

### Questions?

If you have any questions regarding this topic or any others, please reach out to our Support Team via email at <support@lofty.com> or by phone at 1 (855) 981-7557.
