## All Features

### Listing Video Optimization

This is an update to the Auto-Generated Listing Video feature, which was released in beta with Lofty v3.54, noted HERE . With this update, we have increased the number of listing videos that can be created:

- Social Studio Pro users: Generate unlimited listing videos without watermarks
- All other Lofty users: Generate unlimited listing videos with watermarks
- A maximum of 10 listing videos can be generated per user per day

### MLS Agent ID Optimization

We have optimized the user experience when adding the MLS agent ID to the user profile. This is different from the MLS application. This is for agents that need to add their own MLS ID for MLSs that have already been approved and are active on their accounts.

After clicking 'Add Agent ID', a pop-up will prompt the user to select the MLS they are providing the Agent Id for. MLSs that are approved and active on the Lofty account will be available.

After selecting the MLS, the user will be prompted to enter their Agent Id.

### Buyer Tour

This is a new feature that allows Lofty users to set up a listing tour for home buyers. There are three (3) ways to set up the Buyer Tour:

1. Calendar

2. Listings

3. Lead Profile

For complete instructions on how to set up a Buyer Tour, please see this Help Center article .

### Social Studio Team

Social Studio Team is a new additional to our Social Studio. This package offers all the benefits of Social Studio Pro, and also allows you to connect up to 5 social media profiles per channel. For an additional $10/month, you can connect 5 more social studio profiles. There is no limit to the number of profiles that can be added.

To upgrade to the Social Studio Team package, navigate to Campaigns -> Social Studio, click the "Settings" icon, and select "Manage Package".

Here, you will see your current Social Studio package, as well as the packages that are available for upgrade. If you would like to downgrade your Social Studio package, please reach out to Lofty support.

Once upgraded to Social Studio Team, that user can connect multiple social media profiles to one account. This does not extend a social studio license to other members on their accounts. If the user wants to post to others' social media, it will need to be connected to the Lofty account with Social Studio Team enabled.

When creating a social media post, the user is able to select which profile to post to:

### Email Template Folders

We have restructured the email template section by adding folders, which will make it easier to organize your email templates. This can be found by navigating to Settings → Email → My Email Templates.

All Lofty users have the ability to add 'My Folder', but users must have the following permission enabled to create a 'Team Folder' or a 'Group Folder':

- Enterprise: Manage Templates - Entire Company: Can create Folders for the entire company Manage Templates - User's Group: Can create Folders for their group
- Team platforms: Manage Templates: Can create Team Folders

### AI Assistant Cooling Period

The AI Assistant has been adjusted to be less pushy to leads that are less responsive.

Old Logic:

If a new lead registered on the Lofty website, the AI Assistant would send a welcome text message to the lead. If the lead did not reply to the AI Assistant's text message, but still is active on the website, such as saving a listing, the AI Assistant would send another text message immediately.

New Logic:

If a new lead registers on the Lofty website, the AI Assistant will send a welcome text message to the lead. However, if the lead does not reply to the AI Assistant's text message, but still is active on the website, such as saving a listing, the AI Assistant will wait one hour before sending another text message.

### Website Subdomain Creation

This update applies to Enterprise accounts that are creating Subdomain websites. A Subdomain website is a carbon copy of its parent website, which is either a Company or Group website. When a change is made to the parent website, it is also made to the Subdomains that are built from that website. This update allows a user to change the Subdomain website's parent site. This will change not only the domain itself but will also change the look of the Subdomain site to mirror its new parent site.

To update the Subdomain's parent website, navigate to CMS Tool → Select the Subdomain website → Settings → Subdomain

### Re-marketing Ads

A new marketing option to market specifically to leads that are already in your database will be available in the Marketplace:

You must have an active Lofty website to utilize the Re-marketing ads. When purchasing the ads, you

will set up your monthly budget, listing areas, and billing start date. You will also see your potential results, similar to any lead gen campaign. There are two options to select the target audience:

1. Select the lead conditions: Filter leads by pipeline, segment, source, or tag
2. Upload a csv file The file must contain first name, last name, phone number, e-mail address for the leads.

These ads run through Facebook, so you will be prompted to connect to your Facebook page.

The management fee = 20% of the budget

### Closely App Optimization

A few optimizations are launching for the Closely app.

1. Leads can provide Closely app feedback by navigating to the Profile Tab → Feedback. The feedback will be sent directly to Lofty to help us improve the app's functionality.
2. The center point of the map will default to a location based on the MLS configuration on the Lofty site.
3. Supports switching the display mode of saved searches from List to Map.
