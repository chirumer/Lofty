## Summary

- CRM 3.34 Smart Plan Postcard Reporting Transaction Management: Search Functionality
- Site 5.22 Automatic Landing Page Creation

## CRM 3.34

### Smart Plan Postcard Reporting

With a recent release , we introduced the ability to send postcards in our Smart Plans. We have now made available a reporting feature to see how that postcard campaign is doing. To check the status, just go to your Campaigns page, select Postcards, and select the Smart Plan. From this area, you can review the performance of the Smart Plans Postcard campaign.

Learn More: Self-Service Postcards .

### Transaction Management: Search Functionality

We have now added the ability to search for Transaction Name, Property Address, and Lead Name in our Transaction Management section. You can even combine the searches to add multiple criteria for your search needs.

Learn More: Transaction Management Introduction

## Site 5.22

### Automatic Landing Page Creation

We have added a new feature that will automatically create a landing page with your new listing. This does require your Agent ID added to your integrated MLS. It is also required to have an active Lofty website as well, this can be a team website, an agent website, or an agent subdomain. When a new listing is created, it will be generated as the "Single Property Promotion" template. You will also receive an email alerting you to the creation and also supply you with the link to the new landing page, also under your landing pages, you will be able to distinguish these from other pages from the "A" icon at the end of the name of the landing page which was generated.

Learn More: Landing Pages
