## Open House Default Questionnaire

In this update, Lofty has optimized the Default Open House form. Navigate to the Open House Questionnaires by clicking Campaigns → Open House Forms → Questionnaires

The Default Questionnaire has been optimized so that all Lofty users have their own default questionnaire that only they can edit. The Default Questionnaire cannot be deleted.

## Reassignment Group Logic Update

The Reassignment Group logic has been optimized, so that if a new user is added to or removed from the Reassignment Group, the assignments will continue without resetting. The current assignment round will complete, to ensure that everyone is getting the appropriate amount of leads.

## Print Center Dashboard Optimization

This update includes an update to the Print Center UI, as well as additional Print Center options. The process for creating the print campaign itself is unchanged. At this time, Lofty only supports printing Postcards and Letters.

We have added an Engagement section, where you can see the number of mailers sent, and delivered, and leads that have received a mailer. The Your Engagement section only reflects the engagement for mailers sent from your account. It is not showing engagement for mailers from any other users on your Lofty account or from the total Lofty account if you are logged in as the account owner.

We have added an option for you to purchase Print Credits. This is a way to save some money on purchasing mailers, as each credit is equivalent to $1, but credit packages can be purchased at a discount. Click Add Credits to purchase a Print Center credit package.

Note: Print credit packages cannot be refunded.

A Monthly Campaign Reminder has been added, which shows all campaigns that are scheduled to be sent this month. A quick action allows you to edit and approve the design.

## Reporting Page Logic Update

Lofty has released a small update to the Reporting → Business → Revenue section.

Summary Page:

The Summary tab is only visible to Lofty users who have the 'Access All Leads' permission enabled. Here, Revenue = Team Revenue:

My Performance Page:

The My Performance tab is visible to Lofty users who do not have the 'Access All Leads' permission enabled. Here, Revenue = Agent Revenue

## Share Lead Link

This feature allows you to share a lead with other users on your Lofty account. Please note:

- Private leads cannot be shared
- You can only share a lead that you are assigned to in the primary agent role

To share a lead, click the share icon next to the lead's name on the lead detail page.

After clicking the Share icon, the following pop-up provides the share link, as well as a setting that authorizes who can access the lead via the link.

The options are:

1. Only users who have permission to view the lead can access it via the link This means that the Lofty user must either have the Access All Team Leads permission enabled or be assigned to the lead on some level
2. All users on my account can access it via the link This means that any user on the Lofty account can access the lead via the share link, regardless of their permission level

When viewing a lead that has been shared with you, a "Shared" tag will be visible in the upper left corner of the lead detail page.

There will be a timeline record on the lead detail page every time it is shared via the link.

## MLS Application Status Display

This update adds a module to the Listings tab for Lofty users who have set up their website, but have not started an MLS application. Previously, the Listings tab was not visible at all until the MLS application was approved. The MLS application is completed in the CMS tool (Website).

Click Connect MLS to complete the MLS application. This button will take you to the CMS tool.

- Note: The MLS application process has not changed.

Once the MLS application has been submitted, the status can be tracked on the Listing Discovery page. The status has historically been, and will continue to also be available in the CMS tool.

This update also allows the option to view listing data for MLSs that are connected to other Lofty websites on your Lofty account.

- Note: You are only able to view the listings for MLSs that are connected to websites that are either above yours (i.e. the team/company/group website) or websites that were built off of yours (i.e. a subdomain of your website)

To change the source website, select another website from the Source in the upper right corner. If you only have one website available, the Source cannot be changed.

## Showing Dashboard UI Update

This release features an update to the Showing Dashboard UI and also includes a change to how Calendar, Tasks, and Showing view are accessed.

To access the Lofty calendar, click Calendar. Here, the tabs at the top of the calendar allow you to select Calendar, Task, or Showing View.

The Calendar and Tasks are unchanged, but the Showing dashboard has been updated. To access the Showing dashboard, click Showing .

The tabs on the right allow you to filter by Buyer leads (touring homes) and Listings (Seller leads).

The status menu allows you to filter by the scheduled showing/buyer tour status.

The calendar allows you to see scheduled showings/tours for the week, as well as on individual days.

The left side panel allows you to see your own scheduled showings, as well as showings scheduled for others on the Team/Company.

- Note: If you do not have the User Management permission enabled, you will only be able to see your own scheduled showings.

## View Showings in the Closely App

This update adds the option for leads to view showing details in the Closely app. Additionally, leads will receive relevant push notifications, making it more convenient for them to use during the showing process. Please see our Help Center article on the Closely app here: Introduction to Closely Mobile App

- Note: This functionality is already available when leads are logged into a Lofty website.

Closely app users access their Showings via their profile. Once in the app profile, click My Tours

### Tours Tab

This tab allows the user to view the showing appointments and buyer tours that have been confirmed by their agent. The status of the showing will be displayed in the top right corner of each card.

Clicking on a card will take users to the tour detail page, to see more information, like the listing details, time, location, etc. If the tour has been Completed, the lead can leave feedback directly in the Closely app.

### Requests Tab

This tab shows the record of the user's "Request a Tour" requests from the listing details page. Clicking on the request card will take you to the listing detail page.

### Tour Detail Page

The tour detail page is accessed by clicking on a tour in the Tours tab.

The details include:

1. The entire route for the showing
2. The scheduled time
3. The listing information
4. The driving distance
5. The driving time.

Users can switch the listing information by clicking on the listing point on the map or sliding the card. Clicking "Directions" will open the map app on users' devices for navigation. If they have not downloaded a map app on their phone, it will prompt them to download one from the app store. Clicking on the "Calendar" icon in the top right corner allows users to add this showing event to their device's calendar.

### Listing Feedback

When the showing/tour status is "Completed" the user has the option to leave feedback. The feedback content is the same as the web version.

### Push Notifications

The Closely app will send push notifications to users for various events related to a showing, including:

1. Showing/Tour Creation
2. Showing/Tour modifications
3. Showing/tour cancellations
4. Reminders before the showing starts
