## New Goal Setting Portal

A new way to create goals has been added to the Settings page. Goals can be set for the entire company, offices and teams, and for individual agents. We've also introduced a goal calculator to help you determine the volume and closings needed to hit your revenue goals!

Learn how to set your goals here: Goal Setting Portal

## Log in to the Lofty mobile app using biometric or pattern lock

With this mobile app update, you can now enable the option to login to the Lofty app using biometric or a pattern lock. Navigate to the app Account & Security settings to get started!

FaceID, TouchID, and Pattern Lock are available for iPhone, while Fingerprint Unlock and Pattern Lock are available for Android. Learn more about the Lofty mobile app here: Lofty Real Estate App

## Set Global Lead Ownership by Permission Profiles

Previously, we only allowed Global Lead Ownership exceptions for specific teams, offices, or users. We heard your feedback, and now you can set exceptions based on permission profiles too—just click Individual Exceptions when the Default Rule is set to Only allow Company-Owned leads .

Learn more about lead ownership here: Lead Ownership

## New Copilot Capabilities

This update improves Copilot's lead management capabilities by expanding support for searching, updating, and adding leads with more fields.

Update Lead

- Supports updating more fields, including Property Address, Tag, Source, and more.

Search Lead

- Adds 20+ filter conditions, including Opportunity, Source, Subscription, Lead Score, Last Website Visit, etc.

Add Lead

- Adding a new lead now supports adding their Property Address as a field.

Learn more about this AI tool here: AI Copilot

## AI Smart Notifications - BETA Release

We've gotten the feedback that you get too many notifications and that it is hard to determine which actions to take. To address this feedback, we are launching a beta trial of AI Smart Notifications. When you receive a notification, you will see more details about the message at a glance, so you can decide if you need to act on it now, or if it can wait until later.

Request this feature here: Beta Feature Request Form
