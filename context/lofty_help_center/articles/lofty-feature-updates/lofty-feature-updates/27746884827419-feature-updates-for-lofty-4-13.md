## Release Date

Monday, August 5, 2024

## Summary

- Listing Variables for Texts and Emails
- Smarter Mobile App Assistant
- Zip Code Blast
- Unknown Inbound Call or Text Notification

## Listing Variables for Texts and Emails

This feature allows a listing link or listing address to be added to a text message or email via the variable tool. Note: The variable will only provide the address, not a clickable link, in text messages.

Learn more about Listing Variables here: Email and Text Variables

## Smarter Mobile App Assistant

With this update, the Lofty mobile app assistant is now smarter! It can handle more complex commands and tasks, so you no longer have to wait for the assistant to complete one step before moving on to the next.

Learn more here: Lofty Mobile App Assistant

## Zip Code Blast

Zip Code Blast is a new addition to the Lofty Blast section of the Marketing page. This is a self-purchase lead generation option that allows you to capture buyer and seller leads, without needing to promote a listing. Simply provide a zip code that you want to target and the Facebook ads will do the rest!

Learn more about the marketing tools available with Lofty here: Marketing Section -Lofty Lead Capture Tools

## Unknown Inbound Call or Text Notification

This update to the notification section provides a notification when a call or text from an unknown number is received. The option to create a lead profile is available, so you can easily follow up with the potential lead.

Learn more about Lofty notifications here: Lofty Notifications
