Monday, July 19, 2021.

## Summary

- Misc. Announcements Dubb Integration

- Site 5.18 Vanity Domain Purchase Vendor Block Sorting Agent Profile Search Bar Lofty Blog Editor: RSS Aggregator External Featured Listings Widget

## Misc. Announcements

### Dubb Integration

We are excited to announce an integration (via a Chrome extension) with Dubb. This is a fantastic tool that can be used to send videos to your leads via the Lofty platform. Sign up for a free trial of Dubb at THIS link and learn more about how the integration works with Lofty HERE .

## CRM 3.30

### Zillow Flex Support

If you are currently participating in the Zillow Flex Program which is part of Zillow Premier Agent, you might have been waiting for these leads to be labeled in Lofty . With this update that is now possible. Any leads that are generated as part of the Zillow Flex Program will enter Lofty with the source of "Zillow" and an accompanying tag "Zillow Flex Lead." This will allow you to quickly and easily locate leads that fit this criteria.

See Zillow Integration for more information on how this integration works with Lofty .

## Site 5.18

### Vanity Domain Purchase

*Was delayed and released on July 22, 2021.

If you have not yet purchased a vanity domain for your Lofty -built website, you will see an option available in the Lofty Marketplace to purchase one via Lofty . You can learn more about this feature at the following link: Vanity Domain Purchase .

### Vendor Block Sorting

The Vendor Block now supports creating a default sort method for the block. Learn more under Vendor Block > Vendor Block Sorting .

### Agent Profile Search Bar

A new search bar has been added to the backend of the CMS so that those editing the Team Website can easily search for agent profiles even if they have hundreds of them listed. With very large teams, finding the right agent profile was extremely hard to do. However, with this update, you can now search by name or email address to find an email profile easily. This is located under CMS > Settings > Team Info > Agents :

More information about managing agent profiles on your website can be found in the following article: Website Team Info .

### Lofty Blog Editor: RSS Aggregator

The Lofty Blog Editor now has the ability to support RSS feed configuration to bring multiple blog sources into blogs built into Lofty sites.

More information on how this works can be found in the following article: Blog Page > (1) Lofty Blog Editor > RSS Aggregator .

### External Featured Listings Widget

A new section will be available in the CMS that allows for you to generate an embed widget code for featured listings. With this widget, you can embed the code in an external website to display a Featured Listings block on that website.

To learn more about this feature see External Website Widgets .

## Questions?
