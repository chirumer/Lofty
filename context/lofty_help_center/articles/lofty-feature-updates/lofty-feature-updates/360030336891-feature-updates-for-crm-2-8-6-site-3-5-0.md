# Feature Updates for CRM 2.8.6, Site 3.5.0

## Body

## Introduction

*Please note that the features available to you on the Lofty platform will vary depending on the package you have purchased. With any questions in this regard, please reach out to your assigned Customer Success Manager or our Support Team for more information.

### Release Date

The release date for this set of features is July 8th, 2019.

### Summary

- New Section: Campaigns
- Customization for Vendor / Partner Feature
- Market Report for Subdivisions
- Report Optimization: Source Analysis
- Merge Optimization
- Export Optimization
- Mobile App Feature: Support Adding Unknown Numbers as New Leads
- Live Transfer
- Landing Page Optimization

### New Section: Campaigns

We have built a brand new section - Campaigns in Lofty ! In this section, you can manage all your lead capture channels available in Lofty , including Lofty Lead Generation, Landing Pages, and listing promotion tools such as the Open House and Text Code features. More tools to help you maintain a steady flow of leads will be available in the future.

When you enter this section, there will be a dashboard showing how many new leads are generating in each channel. You can click on the “View More Details” buttons to view the detailed data that feeds into these numbers.

#### Lofty Lead Generation

If you purchase lead gen services with Lofty , you can view performance and funnel conversion data for your lead gen ads via the Lead Engine section. You can also request adjustments to your monthly lead generation budget as well as view and provide your feedback on the specific ads Lofty is managing for you.

#### Landing Pages

In the Landing Pages section, you can create landing pages to capture new leads via your preferred marketing channels. You can also view your landing page performance to evaluate their performance at capturing leads. This feature was previously located in the CMS Tool, but has now been moved to this new Campaigns section.

Once again, note that the Landing Page feature will be transferred to the new CRM “Campaigns” section and will no longer appear on the CMS Tool.

#### Single Property Promotions

Previously, what are known as "Property Promotion" pages were located in the CMS Tool > Settings > Property Promotion. Now, however, these are found as a template available under Landing Pages. Note that the existing Property Promotion pages will not be affected and can still be accessed under the new Campaigns section of the CRM. This is a great change that will allow for you to have some feedback using the Landing Page "Overview" column as well as establish a specific lead source for a property promotion should this be desired.

#### Add / Edit Landing Page Blocks

Landing Page blocks can now be adjusted and added to other templates. This means that you can customize each landing page more in-depth than what was previously available. In the example below, we could create a landing page via the "Single Property (Promotion)" template, add a new section, and then reorder as necessary. This greatly increases the options available to Lofty users for customizing landing pages.

#### Listing Promotions

You can also access the Open House and Text Code tools on this Campaigns section as well. They have been moved to this section for better access to all the tools used to generate leads.

### Customization for Vendor / Partner Feature

Based on your feedback, we will now allow our users to add custom roles in the Vendor / Partner Feature.

The roles for Vendors / Partners can also be adjusted after adding them:

Also, the transactions now support being assigned to different vendors or partners with the same role at the same time. Previously, you could only assign one vendor/partner of the same role per transaction.

### Market Report for Subdivisions

A market report can now be set for leads based on subdivision.

### Report Optimization: Source Analysis

Have you ever wanted to know how each lead source is performing? You now have a report for that！ Here are some key notes regarding this feature . . .

1. The Team Owner/Admin and agents who have the “‘Manage Team” permission will have access to this “Source” report under the Marketing section.
2. Overview Tab: The “Lead Conversion” visuals in Overview show a comparison of the Total Leads and Closed Leads.
3. Table Tab: This displays a variety of different dimensions being tracked based on lead source.
4. Key Definitions: Total Leads: This is the number of leads created in the timeframe selected. Closed Leads: Leads in the Closed pipeline stage that correspond to the time frame selected. Valid Leads: Either phone or email is valid Potential Leads: Leads associated with active transactions (not including Closed and Cancelled), that correspond to the time frame selected

### Merge Optimization

Based on this optimization, Lofty users can more easily know who has duplicate leads in their database.

A new warning will appear informing the user that “This lead may be a duplicate of [potential duplicate] who already exists in [agent]’s account.”

If the user confirms that the lead is different from the other, they can hide the notification by clicking the 'x' and confirming the dismissal of the duplicate reminder. As a note, two leads with the same email address are still not able to exist in the same database.

### Export Optimization

Lofty now supports the ability to export “property address.” Lofty will export the three newest buying property addresses and two newest selling property addresses from the “Properties” section of a lead profile (under Engagement).

### Mobile App Feature: Support Adding Unknown Numbers as New Leads

Many clients have provided feedback indicating that it is difficult to add a new lead on the mobile app when an unknown number calls or sends a text to the virtual number. We have optimized the function so that when an unknown number calls the agent, there will be a push notification on the app. With just one click, the agent can add the number as a new lead.

As for the text messages from an unknown number, a text notification will be received (the “Forward Received Texts” option has to be toggled on under Settings > Manage Dialer ) that will provide a clickable link to add a new lead.

### Live Transfer

Clients currently on the Enterprise Edition will now have access to use our Live Transfer feature. This only works on click-to-call functionality (not call lists) and will allow for a phone call to be connected to a third person. Once the call is connected to a third person, the first can leave the call.

### Landing Page Optimization

1. Feature will be transferred to the new CRM “Campaigns” section and will no longer appear on the CMS Tool.

2. Landing Page - Optimization of Single Property templates:

- Support adding new blocks
- Support changing the order of blocks
- Change name to Single Property (Standard)

3. Landing Page - New Template

The Property Promotion pages are now under Landing Page templates and the name of “Single Property (Promotion).” This template (and all others besides Multi Property (Grid)) supports the following features:

- Add a new block
- Change the order of blocks

Note that the existing Property Promotion pages will not be affected and can still be accessed under the new Campaigns section of the CRM. If the content needs to be modified, it needs to be modified using the landing page function.
