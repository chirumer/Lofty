## Release Date

Monday, January 29 and Wednesday January 31, 2024

## Summary

- Available on Monday, January 29, 2024 Transaction Page UI Optimization Transaction Owner Optimization Commission Updates
- Available on Wednesday, January 31, 2024 Lead Mailing Address Optimization Showing Notification Improvements Social Studio Pro Auto-Post Listing Filter

## Available on Monday, January 29, 2024

### Transaction Page UI Optimization

We have made some updates to the CRM Transaction Detail Page UI. Overall, the functionality is not changing, but the UI will look a bit different.

Before | After

Please see our Help Center article Transaction Management Introduction for more information.

### Transaction Owner Optimization

We have optimized transaction ownership so that the primary owner of the transaction no longer has to be the primary agent who is assigned to the lead.

As a reminder, each transaction must be assigned to a lead, and each transaction must have an owner. The update here is that the transaction owner can be any agent on the team, and not just the lead's primary assigned agent.

#### Lofty Enterprise Accounts Only

If you are on a Lofty Enterprise account, you will have an additional permission added to the permission profiles advanced settings. Transaction Roles :

By default, Enterprise accounts will be set to " Allow users to assign transactions to any other user within the account." These settings will allow you to limit Transaction ownership to only users within that user's own Hierarchy group. You can also set an exception, where certain agents or groups can assign transaction ownership to other agents or groups.

### Commission Updates

We have made some general updates to the commission portion of a transaction. Please see those details in the Closing a Transaction section of our Help Center article: Transaction Management Introduction

We have also updated our Commission Disbursement Authorization (CDA) form. Please see our Help Center article: Commission Disbursement Authorization (CDA) Generation

## Available on Wednesday, January 31, 2024

### Lead Mailing Address Optimization

Previously, the lead's entire mailing address was stored in the same field on the lead detail page, as seen below:

We have separated the lead's mailing address into different fields, so you can be confident that the lead's mailing address is correct when you want to send them a letter or postcard via the mail.

Existing leads with a mailing address will be updated automatically. We do recommend that you double check the mailing address before sending a letter or postcard, to ensure that the mailing address format is correct.

### Showing Notification Improvements

We have made some improvements to showing notifications, so you never miss a showing request. The notifications tab in the web CRM now has a section for Showing Request related notifications:

We have also implemented email notifications that will be sent when a request has been pending for a few days, as well as notifications in the Lofty mobile app.

Please see our Help Center article on the Showing Tool for more information about scheduling your showings with Lofty: Listing Showing Management

### Social Studio Pro Auto-Post Listing Filter

The following update only applies if you have Social Studio Pro or Social Studio Team. Please see our Help Center article on this premium add-on: Social Studio Pro

We have added filters to the Automatic Listing Posts. These are social media posts that will post to the selected channels automatically when the listing status changes. More information on this feature can be found in the Social Studio Pro Help Center article, linked above.

With this update, you can decide exactly which listings are posted automatically. Click the Filter icon to filter out some listings from being posted automatically.

Here, you can decide to only automatically post updated listings of a certain price range, location, property type, or even from a specific MLS, if you are a member of multiple MLSs.
