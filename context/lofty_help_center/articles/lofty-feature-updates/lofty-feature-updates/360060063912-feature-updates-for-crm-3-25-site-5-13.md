### Lead Pond: License ID Field

A small improvement was already released on April 20, 2021 for the lead pond. What has been added is a "License ID" field for the lead pond virtual agent profile. This field is not required. When filled out, this license ID (and the other virtual agent profile info) will appear in auto emails sent to leads in the Lead Pond. If the field is left blank, it will not appear on the auto email signatures.

More about Lead Pond can be found HERE .

## CRM 3.25

### Postcard Optimizations

Prior to this update, only a templated, Lofty -built back page could be used on the postcards in order to make sure that the address, etc. was where it needed to be. With this update, however, you can now select your own designs for the back page and are no longer required to use a Lofty -built back page.

When postcards are sent via Lofty, the recipient's name and address are always included on the back page at the bottom-right. With this update, that spot will always be blocked and no content added in that area will be printable. As soon as the Order Postcards button is clicked, page 2 of the design will have the blocked address area highlighted on the design.

To learn more, go to Self-Service Postcards .

## Site 5.13

### MLS Associated Agent ID

This feature was built to make it easier to present featured listings on your IDX website and support other MLS listing feed-dependent features in the CRM. When adding an MLS, part of the process is to include the information for the agent associated with that MLS. That information will now be listed under CMS > Settings > Listings > MLS Integration and under the column for Agent .

Once this feature goes live, as much information as possible will be mapped to the Agent column for existing MLS connections. However, you will want to check and manually + Add Associated Agent if one has not been added.

Please note that this is not a requirement--you can leave this blank and continue using the platform as you were before. This is being released to facilitate the efficacy of MLS data for featured listings and other features in the future.

### Custom Fields for Agent Website Profiles

A new feature has been added to better build out agent profiles on your Lofty IDX website. These custom fields can be used to present more information about your agents on your website. For example, you could share information about each agent's favorite color or first job, the university they attended, etc.

To access the setting, navigate to CMS > Settings > Team Info > Agents > Click on the cog wheel at the top:

You can then create custom fields for agent profiles. They can be text boxes or drop-down lists. You can add a maximum of 15.

Once the fields are added, you can go to the agent list and add or edit an agent. A section will be available for each individual profile to add the information to those fields:

When the agent profile is clicked on the About page, etc. that agent's profile will appear and the custom fields are displayed there. Here is a sample of what this might look like:

*Note: Custom fields added at the Team Website level are the same available when editing profiles on both Agent Subdomains and Agent Websites. In other words, custom fields are added at the Team Website level and available to use at the Agent Subdomain and Agent Website levels when building agent profiles.

### Email-Only Lead Registration Optimization

This feature was originally released as part of Site 5.9 .

The following three items have changed with this release:

1. Source Change . These leads will no longer be their own unique source. Previously, they were marked as source "Site Email Lead," but with this release, this will be a Tag instead of a Source . This will allow for the original source of the lead to be retained while still being able to filter for this specific type of lead in the future as needed.
2. Toggle On/Off . You can now turn this feature off if you would prefer not to capture this type of lead.
3. Supported Capture Methods . Leads starting to register with Facebook/Gmail will also be captured.

You can find the up-to-date logic outlined here: Registration Pop-up Style & Settings > Email-Only Lead Registration .

### Link Anchor for "Request a Tour" Feature

This anchor was developed to take site visitors to the Request a Tour level on a listing detail page. If you would like for a site visitor to be sent directly to that part of a property detail page, simply add #schedule at the end of your listing detail page URL so that site visitors can be directed to the "Request a Tour" option on that listing.

Here is what it appears as on desktop view:

On the mobile view, the site visitor will be taken directly to a pop-up that looks like this one:

### Breadcrumb for Listing Detail Pages

A "breadcrumb" (location hierarchy links) has been added to every listing detail page. The format will be the following: #State# > #City# > #Subdivision#. All of this information is generated directly from the MLS. This will allow site visitors to easily find other listings in the city, or subdivision without having to back out to generate a separate search. Please note that the state is currently not clickable.

This type of feature on every individual listing detail page also improves the usability of our websites and increases overall SEO value as well.
