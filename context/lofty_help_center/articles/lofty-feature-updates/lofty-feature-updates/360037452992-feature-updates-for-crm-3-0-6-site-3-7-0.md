### Introduction

*Please note that the features available to you on the Lofty platform will vary depending on the package you have purchased. For any questions in this regard, please reach out to your assigned Customer Success Manager or our Support Team for more information.

### Release Date

The release date for this set of features is Tuesday, December 17, 2019.

### Summary

- Completely Erasing Leads via Lead Profile
- Company Information to Display in Automated Signatures
- Customize Property Alert Names and Subjects
- AI Assistant Smart Plans
- Unique Agent Addresses Configuration via CMS Tool

### Completely Erasing Leads via Lead Profile

Prior to this release, erasing leads was only accessible via the "Deleted Leads" section of the People page. Now, there is an option available directly on the lead profile for a lead that might have already been deleted. As a reminder, a lead that is "deleted" is sent to a recycle bin (Deleted Leads) and must then be erased before completely leaving the system.

If there is a specific lead that needs to be erased but is hard to find because of how long ago it was deleted, deleted leads will now show up when searched in the search bar at the top of the Lofty CRM. They can then be easily selected to navigate to their lead profile where the new "Erase" option is available.

### Company Information to Display in Automated Signatures

For all automated emails that include a pre-built signature from Lofty , the signature will now include the Company Name from Settings > Profile . If left blank, it will not appear. Automated emails include Welcome Emails, Property Alerts, Market Snapshots, and Market Reports.

### Customize Property Alert Names and Subjects

Lofty users can now name each property alert and define a customized subject. This is a useful way to keep things organized as well as reference specific searches in discussions with clients to improve property alert open rates. For the subject, custom variables can be included. If not customized, it will continue to use the template found under Settings > Email Templates > Automated Emails .

Additional improvements in this area are on the roadmap including the ability to synchronize lead/client saved searches with Lofty user-created property alerts so agents and their clients can be on the same page with their searches.

### AI Assistant Smart Plans

With this new release, the initial conversion power of the AI Assistant can be better combined with the benefits of Lofty Smart Plans for continuous conversations and lead nurturing. A described in the functionality of the AI Assistant (see Lofty AI Assistant / Chatbot ), the AI Assistant will tag leads according to certain conversation patterns. These same tags will be used as triggers for pre-built Smart Plans.

Additional prompts will also be available on the AI Assistant settings page that allow for the easy addition of new templates if they are added in the future.

Also, when importing AI Assistant Smart Plans, there is an additional "Auto Pause" trigger that can pause all other Smart Plans for leads when one of these plans is applied.

More information on the Lofty AI Assistant can be found here: How to Add the AI Assistant / Chatbot to your Account .
