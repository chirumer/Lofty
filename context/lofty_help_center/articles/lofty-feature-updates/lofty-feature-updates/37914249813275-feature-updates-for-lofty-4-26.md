## Release Date

Monday, June 16, 2025

## Summary

- New Dashboard - BETA Release
- Reporting Page Upgrades - BETA Release
- Social Studio Weekly Post Report
- Website Restructuring - Available on June 23

## New Dashboard - BETA Release

You may be seeing a new layout on your My Dashboard.

A drop-down menu allows you to sort this dashboard by your daily or weekly tasks and the tiles can be rearranged so the most important information to you is at the top. If you have access to this dashboard, we hope you enjoy it! This will be made available to all Lofty accounts soon.

## Reporting Page Upgrades - BETA Release

If you are seeing the updated dashboard, you will also see that the reporting page has gotten a major makeover! With this update, we've split the reports into their own pages, so you can easily analyze the data you are looking for.

The Agent Accountability reporting is broken down into four (4) different sections:

1. Agent activity overview
2. Leads not acted on
3. Follow-up speed & effort
4. Leads response performance

Call, Email, and Text message accountability each have their own reports.

The reports are now more customizable and more useful for you!

Learn more here: Lofty Reporting Page

## Social Studio Weekly Post Report

If you have linked at least one social media account to Lofty's Social Studio, expect a new email in your inbox on Mondays!

This email will help you track your Social account performance and improve your content efficiency.

Learn more about Lofty's Social Studio here: Social Studio

## Website Restructuring - Available on June 23

Lofty websites are being restructured so you can more easily see what type of website you have and what your website can do for you. If you currently have a Lofty website, you won't notice any changes except the website type in the CMS. If you do not currently have a Lofty website, now you have more options to choose from!

Learn more about Lofty websites here: Lofty Websites
