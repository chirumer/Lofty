## Release Date

The release date for this feature is Monday, April 27, 2020.

### Virtual Tour Requests

In order to provide site visitors/leads with additional options on the Lofty IDX websites, a new button will be made available on all listing pages to "Request Virtual Tour." The previous tour request button has been changed to "Request In-Person Tour."
