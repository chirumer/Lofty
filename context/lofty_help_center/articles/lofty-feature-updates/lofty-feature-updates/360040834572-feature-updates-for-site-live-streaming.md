### Release Date

The release date for these features is Wednesday, March 25, 2020.

### Summary

- CMS Tool Versions
- Facebook Live Block
- YouTube Live Block
- New Landing Page Templates for Listing Live Tours
- Landing Page Quick Share Option via Email/Text
- Lofty COVID-19 Outbreak Resources

### Video Introduction

### CMS Tool Versions

As announced in our previous release (see Feature Updates for CRM 3.2.0 ), a transition to the New CMS has started to take place. The live streaming features have been released for both the Original CMS and the New CMS in order to provide the tool to all users. However, the instructions will vary depending on which version of the CMS is being used. Please reference the following article to learn how to tell which version you are currently on: CMS Tool Versions (Original CMS vs. New CMS) . As a reminder, everyone will eventually be transferred to the New CMS Tool.

### Facebook Live Block

Follow the instructions that apply to the version of the CMS Tool that you currently have on your account:

- Facebook Live Block (Original CMS)
- Facebook Live Block (New CMS)

### YouTube Live Block

Follow the instructions that apply to the version of the CMS Tool that you currently have on your account:

- YouTube Live Block (Original CMS)
- YouTube Live Block (New CMS)

### New Landing Page Templates for Listing Live Tours

Two new templates will be made available with this update that include live video streaming features with the Facebook and YouTube blocks. To learn how to configure those blocks, please reference the two updates above this one.

- Listing Live Tour (Standard)
- Listing Live Tour (Promotion)

### Landing Page Quick Share Option via Email/Text

A new option will be made available with this update that allows users to quickly share a Landing Page. The feature is very similar to what currently exists to share a listing via the Listing Discovery page. A new button will be available under the "Action" column that, when clicked, will allow for the page to easily be sent out via text or email to your database.

Please note that this button is only available under the Campaigns > Landing Page.

When clicking on the "send" option for a "Listing Live Tour" landing page type, a default email template will be populated that can be used and/or customized.

### Lofty COVID-19 Outbreak Resources

Lofty has archived an article with some resources that might be helpful to you as you interact with your clients: Lofty COVID-19 Outbreak Resources .
