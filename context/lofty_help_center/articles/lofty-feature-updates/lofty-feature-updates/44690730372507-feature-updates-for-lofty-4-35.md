## Lofty AI Assistant New Features

- Introducing new Lofty AI Assistant features that improve research, file-based work, and long-running requests.
- Enhancements focus on transparency, productivity, and flexibility, and are available to all AI Assistant users.

The Lofty AI Assistant now includes an enhanced Web Search experience, file uploads, and offline tasks. Web Search allows the Assistant to retrieve up-to-date information and clearly display clickable source links, improving transparency and trust. File uploads are now supported on web and mobile, enabling you to ask questions and complete tasks using your own documents, images, or data files. For complex or time-consuming requests, the Assistant can run tasks in the background and notify you when they are complete.

Learn more here: AI Assistant

## New AI Assistant Welcome Message

- Introducing a new, context-aware welcome message in the Lofty AI Assistant to help you get started faster.
- Provides one-click suggested actions tailored to the specific page that you are on.

The Lofty AI Assistant now displays a welcome message the first time it’s opened on each page. This message adapts to your current location—such as the Dashboard, People page, Lead Detail pages, Calendar, or Transactions—to offer relevant guidance and suggested next steps. Below the message, you'll see a short list of recommended, high-value actions. Selecting one automatically starts the AI conversation, while you can still enter your own requests at any time.

## Personal Disclaimer Update

- Added an additional personal disclaimer.

You can now add more than one personal disclaimer to your profile. The disclaimers added here will automatically sync to your website's footer. Learn more here: Personal Disclaimer

## AI Listing Search

This feature is being beta tested. You may or may not have access to this feature. Please reach out to support@lofty.com to request access.

- AI Listing Search is a new natural language search experience for finding listings faster.
- Automatically converts plain-language requests into structured search filters.

AI Listing Search allows both you and visitors to your website to search for listings using natural language instead of manually setting filters. Switch to AI Search Mode and describe what you're looking for. The system automatically interprets the request, applies relevant filters, and updates results in real time. Manual filters remain available and can be adjusted after the AI search is applied. This feature is available on both the Listing Discovery page and on your Lofty website listing search.

## Smart Plan UI Updates

- Redesign of the Smart Plan experience with a cleaner layout and improved organization.
- Makes it easier to browse, manage, and preview Smart Plans and templates.

The Smart Plan experience has been updated with a modern, streamlined interface. Personal, office, and company Smart Plans are now combined into a single page, with a new Scope filter to quickly switch views. Smart Plans and library templates can be displayed in a card-based layout, making them easier to scan and compare, while the updated list view offers a cleaner design with filters moved to the top for faster access. As part of this update, the legacy Smart Plan Report has been temporarily removed while more detailed, plan-level performance insights are being developed. No Smart Plans or templates were removed as part of this change.

## VoIP on Mobile (iOS Only)

- We've added an Enable VoIP Calls setting in the Lofty iOS app to manage how incoming calls are delivered.
- Helps prevent duplicate incoming call notifications when receiving calls through bridge mode.

This update introduces an Enable VoIP Calls setting for Lofty mobile app (iOS) users. When turned on (default), incoming calls are shown using Apple’s native call screen. When turned off , notifications are suppressed, allowing calls to be handled through bridge mode only.
