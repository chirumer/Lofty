## Standard Agent Websites

Lofty is adding a new agent website package called “Standard Agent Website”. The Standard Agent Website does NOT replace any Agent Websites. The Standard Agent Website looks and feels like an Agent Subdomain with one simple difference: It allows for the configuration of a vanity/branded domain WITHOUT the need for a Lofty User to complete an additional MLS Application.

A Standard Agent Website costs $19 per month, and can be paid for by the account owner or the website owner.

In the CMS, this website will be listed as an Agent Website Standard. It is effectively the same as an agent subdomain, but has the benefit of having it's own customized vanity domain. Learn more about the types of website Lofty offers here: Agent Websites

## Bulk Transaction Task Actions

If you have a transaction that ends up getting canceled, this can result in unfinished transaction tasks remaining on your calendar and task list. Removing the tasks from the calendar and task list has until now, been a manual process. With this update, if a transaction is cancelled and there are tasks attached to the transaction that are still in a status of “To Do” or “Doing,” a pop-up window will appear.

This pop-up both notifies you that there are outstanding tasks associated with this cancelled transaction and allows you to either change the task status to "Not Applicable", which will remove the task from your task list or remove the tasks due date, which will remove and reminders and remove the task from your calendar. Removing the due date will still keep the task in your task list.

Learn more about Transaction Checklists here: Transaction Management Checklists

## Transaction Search Optimization

You are always able to view the transactions that are associated with leads that you are assigned to in the primary “Agent” role. With this update, as long as you are assigned to the lead in any of the available Role Types, you can search for their transaction on the Transaction Dashboard by selecting the option “Include Unowned Transactions”.

This makes it simple for Assistants, Transaction Coordinators, Co-agents, etc. to find transactions. Learn more about Transaction Management with Lofty here: Transaction Management Introduction

## Lead Types in the CMS Match the CRM

In Feature Updates for Lofty 4.8 we added several new Lead Type options and the ability to combine Lead Type options as needed. With this update, the CMS (Website Editor) has been update to align with the CRM. This means that lead capture forms and registration pop-ups can now be set to label a lead with any of the available lead type options.

Learn more about lead capture forms on your Lofty website here: Form Block

## Drag and Drop Email Templates

With this update, when creating email templates, you will be given the option to create one of two types of templates:

1. Plain Text
2. Rich Text

Plain Text will look familiar, as it uses the old editor

The Rich Text editor is an all-new interface that allows for more dynamic, modern designs. You can now add text, images, buttons, social media, dividers, tables, and listings to your templates.

When adding a new template, you will now be offered a choice between two types: Plain Text and Rich Text.

If you choose to create a Rich-Text template, you will be able to build a template with many more formatting options and elements like buttons, tables, social media, etc.

Learn more about email templates here: Email Templates

## Account User Status

Lofty offers both Platform Users and Display Only users. Platform users occupy a seat on the platform and can log in to their account. Display Only users are exactly that - they can be displayed on your website but do not have any Lofty account to log in to.

Platform users can have the following statuses:

- Active: Account setup complete. The user has chosen their login email and password.
- Pending Activation: A welcome email has been sent, but the agent has not activated their account.
- Invitation Scheduled: mm/dd/yy: The agent's welcome email is scheduled to be sent.
- Pending Opt-in : This status only applies to teams who choose the Agent Opt-in Process whose agents have not yet opted in.
- Inactive: This status is limited to active users that have been deactivated.

Deactivating a user allows you to temporarily pause a user's Lofty account. That user's leads will need to be transferred to another user and their Lofty account is effectively disabled. They can be reactivated at any time and their account information is retained.

Learn more about managing your account here: Add or Remove Team Members on Lofty

## Show Co-Listings Agents on Listing Pages

Lofty websites will now be capable of displaying multiple “co-listing” agents on Listing Detail pages.

Agents who are listed as the 2nd or 3rd agent on a listing can be made visible, if that setting is enabled. Learn more about listing management with Lofty here: Listing Pages

## Updated Cookie Policy

Lofty has updated the cookie preferences that visitors to your website have access to. Cookies are the trackers that remind a website visitor's device that they've visited a website previously. Visitor to your Lofty website will see one of the following options, depending on their location.

Learn more about website cookies here: Website Cookies
