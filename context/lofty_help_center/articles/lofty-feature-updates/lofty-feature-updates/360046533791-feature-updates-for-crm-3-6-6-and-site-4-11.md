## Introduction

*Please note that the features available to you on the Lofty platform will vary depending on the package you have purchased. For any questions in this regard, please reach out to your assigned Customer Success Manager or our Support Team for more information.

### Release Date

The release date for this set of features is Thursday, July 23, 2020.

### Summary

- CRM Facebook Integration Optimization
- Site (New CMS Only) Search Bar Location Logic Optimization Search Bar Location Type Options

### Facebook Integration Optimization

The process to connect your Facebook Ads to the Lofty CRM has now been optimized to more clearly outline the steps and to confirm that the appropriate access has been given to Lofty in order to receive the leads. A series of steps will now guide you through the process and system checks are in place to monitor the connection to confirm it is working.

Additional instructions are also given on how to connect additional fields and their data into Lofty .

To learn more about setting up the integration, please reference the following: Facebook Lead Form Ads + Lofty Integration .

### Search Bar Location Logic Optimization

*Only available on the New CMS

Lofty has optimized our Search Bar to force the site visitors to choose from the provided suggestions in order to better narrow down their searches. This means that if a site visitor simply presses "Enter" on the keyboard or clicks the "Search" icon on the website, it will use the first suggestion as the default input value. When combined with the additional setting to determine what displays at the top (see below ), this will increase the accuracy of listings shown when searching.

There are two ways to search listings via the Search Bar.

1. Exact Search . If you choose one of the provided suggestions from the drop-down menu, the search will show listings based on the category chosen (city, zip code, etc.).
2. Fuzzy Search . If you type in a value and press the “Enter” button on the keyboard or click the "Search" icon, listings will be shown without category restrictions (city, zip code, etc.).

With this update, there is now an option to switch between the two options in the new CMS Tool > Settings > Listings > Location Search Bar :

### Search Bar Location Type Options

*Only available on the New CMS

With this update, there is a new setting to customize what categories (city, neighborhood, zip code) appear when a site visitor uses the search bar on your Lofty IDX website.

The new setting is located under CMS Tool > Settings > Listings > Location Search Bar . With these settings you can do the following:

- Hide/Display
- Reorder (determines which one displays first, second, etc.)
- Rename
