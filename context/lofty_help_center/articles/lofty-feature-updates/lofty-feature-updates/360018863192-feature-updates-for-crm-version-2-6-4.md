# Feature Updates for CRM Version 2.6.4

- Article ID: `360018863192`
- Category: `Lofty Feature Updates`
- Section: `Lofty Feature Updates`
- Updated: `2025-11-12T05:24:28Z`
- Source: https://help.lofty.com/hc/en-us/articles/360018863192-Feature-Updates-for-CRM-Version-2-6-4

## Body

Key Takeaways

- New Lead Profile Page (Web)

-New feature to @ someone to notify team members or lenders in notes or log

-New ‘Search Criteria’ Section

-New ‘Properties’ Section

-Optimized ‘Smart Plan’ Section

-Optimized ‘Transaction’ Section

-Support for editing social account

- Dialer Optimization for Lead Pond (Web)
- MLS Transaction Search (Web)
- Working Hours Preferences (Web)
- Market Report Data Optimization (Whitelist)

New Lead Profile Page (Web)

1） New layout to better organize and display the lead information.

2） Better statistic and filtering for timeline.

3） Display more insights on the page such as search criteria, owned and interested properties.

New feature to @ someone to notify team members or lenders in notes or logs (Web)

Use @ to notify your agents or lenders when writing a note or log. The agent or lender mentioned will receive notification and email.

New Search Criteria Section (Web)
Buyer Lead Inquiries is now replaced by Search Criteria section. The system will analyze leads’ preferences based on the their activities and display them in the Search Criteria section.
New Properties Section (Web)
1. You can take note of the lead’s buying and selling preference in ‘Add a Property’ section.

1. You can track lead’s preferences on all listings under Properties now. These listings can be added manually or by lead’s site activities (Saved, Requested Showing, Left Message, Sell, Home Evaluation).

1. Send Listing/CMA or Create Transaction quickly under Properties.

Optimized Smart Plan Section (Web)
1. Find status of the plan including running, paused, completed and terminated under “Applied Plans’.
2. Find the number of plans in each state and the total number of the plans applied for this lead.

3.
Now you can find basic information of the running plan and the execution time
in ‘Next Step’.

4. Now you can find the reason why the plan is automatically suspended and take relevant actions.
5. Find smart plan templates suggested based on the lead’s info and site activities on the right side of the page under “Suggestions” now. Easily click the ‘+” button to apply it to the lead.
Optimized Transaction Section (Web)

The ‘Transaction and Documents’ section under Lead Details page just got redesigned for a more user friendly experience.

1. There’s no limit to the number of transactions per lead.
2. Agent can search the transaction by address.

3.
The lead’s property info will be auto-suggested in Transaction Name field when you add a new sale transaction
Support for social account (Web)

Agent can manually add and edit social accounts on the lead’s profile page.

Dialer Optimization for Lead Pond (Web)
For Dialer users, you can call the leads from the Lead Pond in Dialer now. Simply import the leads to Dialer from the Lead Pond page by selecting the leads and click the button “Send to Dialer”.
MLS Transaction Search (Web)
Agents can search the Unclaimed MLS Transactions by address in the Transaction Management page.
Working Hours Preferences (Web)

1. You can set the hours to receive leads or set to receive leads nonstop by choosing '08:00 AM - 08:00 AM’ from routing rules.

1. You can stop receiving leads by click the button "Switch to Vacation Mode".

Market Report Data Optimization (Whitelist)
We utilize big data analysis to optimize market report information so the reports are more accurate and being updated more frequently.
