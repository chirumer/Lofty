## Sales Agent Updates

The Sales Agent has received a series of updates this release covering expanded access, smarter automation, a cleaner interface, and more control over your account. The Playbook and Smart Leads view are now open to all users, quota alert emails have been reduced to once every 7 days, the Lead Timeline has been streamlined with new activation and stop messages, unnecessary Playbook Call Tasks have been reduced, and you can now cancel or opt out directly in the platform. New users will also find activation faster with no credit card required and a one-step setup with smart defaults pre-configured.

The Sales Agent was initially being beta tested, but is now available to all!

Highlights:

- All Sales Agent users now have access to Playbook settings and the Smart Leads view on the People Page, no special access needed
- The Lead Timeline now hides low-value system events by default and shows clear messages explaining when and why Sales Agent activated or stopped on a lead
- The "Call Task Assigned" Playbook Goal default has been turned OFF; existing accounts were updated automatically, and the setting can be re-enabled at any time
- Activating Sales Agent no longer requires a credit card, and setup now takes one step with smart defaults already configured

Learn more here: Sales Agent Smart Leads & Playbook Settings

## AI Assistant Updates

The AI Assistant has received two significant updates this release. It now understands which page you are on and remembers your past conversations, making responses more relevant to your current workflow. If you are using the free trial version of the AI Assistant, the daily conversation limit has been removed. Upgrade to the AI Assistant Pro version to access Deep Research searches.

Highlights:

- Page context awareness: the AI Assistant detects your current page and can reference it in responses
- All conversations are automatically saved and organized by date (Today, Yesterday, and earlier)
- A redesigned Prompt Library helps you discover what the AI Assistant can do, organized by task type
- A Back button lets you return to the welcome screen and start a new chat at any time

Learn more here: AI Assistant

## Personal Number Variable

A new message template variable, #agent_personal_number#, lets you automatically insert your Personal Virtual Number (PVN) into any email or text template. No more manually updating templates when your number changes.

Highlights:

- Add #agent_personal_number# anywhere in a message template to insert your PVN at send time
- If your PVN changes, all templates using this variable update automatically
- Works across both email and text message templates

Learn more here: Email and Text Variables

## Custom Date Filter Optimization

The "is less than X days ago" condition in the Custom Date filter has been updated to use the current time as the end of the date range instead of midnight. Activities from earlier today are now included in your filter results.

Highlights:

- "Is less than X days ago" now counts from the current moment, not from midnight
- Today's activity is included in results, eliminating the previous "one day behind" issue
- Existing saved filters using this condition update automatically, no reconfiguration needed
- All other date filter conditions are unchanged

Learn more here: Lead Organization with Filters

## Hyperlocal Website

A new website package is now available in the Lofty Marketplace, designed to position you as the go-to expert in your local market. The Hyperlocal Website package pairs a premium hyperlocal website with a done-for-you design service, so your site is built and ready to generate leads without the heavy lifting on your end. Once purchased, Lofty's team will reach out within 24 business hours to kick off your setup.

Highlights:

- Purchase your new Hyperlocal Website directly from the Marketplace under Branding and Marketing, where it's now featured as the top website option
- Your site is built by AI using your marketing profile and includes a premium homepage, in-depth neighborhood area pages, and an interactive click map that drives engagement and captures leads
- Three SEO-optimized blog posts are automatically generated for your farm area to help establish your local expertise from day one

Learn more here: Hyperlocal Website

## API Key Enhancements

You now have full control over your API keys directly from your Lofty account settings. The API key management system has been updated so you can create, name, and manage keys with built-in security protections, expiration reminders, and a clear audit trail. Your existing API keys have been automatically migrated and will continue to work without any action required on your part.

Highlights:

- Create and manage API keys from Personal Settings > Integrations > API Keys, with the ability to add a name, description, and optional expiration date to each key.
- Your existing API keys have been migrated automatically and remain active with no disruption to existing integrations.
- Set optional expiration dates on any key and receive email reminders at 30, 15, 7, and 1 day(s) before it expires so you can plan ahead and avoid unexpected access disruptions.
- Keep up to 10 active keys at a time. Expired or revoked keys are preserved in your history for reference and do not count toward the limit.

Learn more here: API Key Management
