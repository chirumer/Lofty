## Release Date

Monday, December 18th, 2023

## Summary

- Campaign Page UI Update
- Lead Mass Action Upgrade
- Open House on Lofty Website
- Social Studio: Instagram Update
- Agent Block Calendar Link
- Security Update
- Beta Released Feature: People Page UI Update

## Campaign Page UI Update

The Campaign tab in the header has been changed to Marketing. This section has also been reorganized.

## Lead Mass Action Upgrade

For the following mass actions, the number of leads that can be included has been upgraded from 200 to 5,000:

- Mass Email
- Change Pipeline
- Change Segments
- Change Tags
- Assign
- Smart Plan

## Open House on Lofty Website

Navigate to the CMS tool -> Listings -> Listing Settings -> Open House to decide if you want to show or hide open house dates for listings on your Lofty built website. By default, this setting will be set to Show .

## Social Studio: Instagram Update

When using the Social Studio to post content on Instagram, you now have the option to select a sub-channel.

The default channel is set to "Post," but you can choose to post to stories or reels as well.

Post Limits for Each Channel:

- Regular Post: Content Limitations: Multiple images or one video with text. Display: Posts appear on the Instagram feed.
- Story: Content Limitations: One image or one video without text. Display: Stories appear at the top of the Instagram feed and lasts for 24 hours.
- Reels: Content Limitations: One video with optional text. Supports editing the video name and thumbnail. Display: Reels are featured in a dedicated section on Instagram.

## Agent Block Calendar Link

We have added a calendar booking link to your Lofty built website. The booking URL is configured in your Calendar and the booking link is can be turned on and off on the agent block.

## Security Update

We have made an update to your account security. Please see this article for more information: Security and Account Access

## Beta Released Feature: People Page UI Update

We are beta testing a UI update to the people page. Please see this article for more details: Beta Feature - Updated People Page UI
