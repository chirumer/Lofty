### CMS Tool Versions

As announced in our previous release (see Feature Updates for CRM 3.2.0 ), a transition to the New CMS has started to take place. Please reference the following article to learn how to tell which version you are currently on: CMS Tool Versions (Original CMS vs. New CMS) . As a reminder, everyone will eventually be transferred to the New CMS Tool but this will take some time (months) as each account/site has to be transferred individually.

### AI Assistant Improvement: Listing Recommendations

*Release Date: 4/17/20

The AI Assistant can now give listing recommendations during the conversation as a tool to re-engage the lead and see if it is possible to schedule a showing when the lead finds something they are interested in. The AI Assistant will send out a link that is filtered based on the criteria already provided.

*IMPORTANT:

- Please note that the AI Assistant will currently only send listing suggestions if the lead does not respond for 24 hours after providing basic criteria. If no criteria has been provided or the lead is responsive, no listing link will be sent out. Future versions will likely include a more proactive approach to suggesting listings.
- This feature cannot be turned off as it is part of the built-in scripts
- The recommendation link that is sent will take the lead to the team IDX website, not any agent subdomain sites.

### Form Block Custom Fields

*Release Date: 4/14/20

*Only available on the New CMS

You can now add custom questions to the forms on the IDX website and the answers to the questions will be added to the lead's profile in the CRM. Currently, the only additional field available is for "Single Line Text." In the future, Lofty will add more fields such as multi-line text, drop-down, etc.

See this article for more information on how this block is to be used: Form Block .

### Questionnaire Custom Questions

*Release Date: 4/14/20

*Only available on the New CMS

The built-in questionnaires can now be customized. You can now hide standard questions and add, remove, or edit custom questions. The contents of all custom questions will be transferred to the CRM as a note.

To learn more about how to customize this, please reference the following article: Questionnaire Settings .

### Add Seats Directly from CRM

*Release Date: 4/17/20

*IMPORTANT :

- This feature is not available for Enterprise packages.
- The monthly amount for additional seats will be added to your bill starting on the next billing period.

For instructions on how this works, please reference the following article: Add or Remove Team Members on Lofty .

### Facebook Ads Integration

*Release Date: 4/17/20

If you are running your own Facebook Ads campaigns, you can now connect them directly to Lofty so that leads are brought into your CRM automatically. Once integrated, leads captured on a Facebook lead form will be automatically imported into Lofty.

*IMPORTANT :

- Only one Facebook Business Page can be connected to each Lofty user's account
- Every individual user on a team is able to integrate their Facebook Ads with Lofty

Please review the following article for specifics on setting up this integration: Facebook Ads Integration .

### UTM Settings

*Release Date: 4/17/20

This release also supports the use of UTM to tag leads and better monitor campaign ROI. Users are able to add UTM codes to URLs and have that data added to leads automatically as they are brought into Lofty . Google's Campaign URL Builder is a useful way to set these up.

There are three different parts to how this works:

1. Import utm_source as lead sources . This is ON by default and cannot be turned off. If a lead registers via a campaign or URL with an associated "utm_source," that source will be assigned to the lead automatically. A new source will be created if it does not already exist.
2. Import utm_campaign as lead tags . If a lead registers via a campaign or URL with an associated "utm_campaign," that campaign will be recorded for that lead automatically as a tag. A new tag will be created if it does not already exist.
3. Import utm_content as lead tags . If a lead registers via a campaign or URL with an associated "utm_content," that content will be recorded for that lead automatically as a tag. A new tag will be created if it does not already exist.

To edit or set this up, navigate to Settings > Features > Tags & Sources > UTM Settings :

The following article will also be updated with the above information after this release goes live: UTM Settings .
