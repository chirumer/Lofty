## Service Bot Update

The Service Bot has been updated so you can clearly see who is assisting you in the chat.  This will make it easier for you to know when it's the Service Bot, and when it's one of Lofty's support team members. In many cases, the issue can be resolved with just the Service Bot. You will see "Service Bot" at the top of the chat. It isn't perfect, so it can make mistakes, but it is getting better all the time.

Learn more about Service Bot here: Service Bot

## Lofty Present: Team and Personal Spaces

Lofty Present (formerly the CMA Tool) has been updated to support Team and Personal spaces to enhance collaboration and Listing Presentation management.

Account/Office/Group Owners have the option to buy Lofty Present Team , which will allow them to create Listing Presentation templates for their team. If you already purchased the Listing Presentation add-on, you have access to Lofty Present Team.

Everyone will also have access to their own Personal space, where you can track your own CMAs and Listing Presentations.

Still have questions? Learn more in the Help Center Article: How to Create a CMA and Listing Presentation

## Transaction Variables

When sending an email, text, or drafting a Smart Plan, you can now use transaction related variables in those messages. This will work just like using other Variables in messages, whether it's an email or text message.

#### Automated Emails, Mass Emails, Text Messages:

When sending a mass email, mass text, smart plan email/text, or a single text, by default, the transaction variable will pull data from the most recently created transaction. We'll show you a disclaimer when sending one of these messages or creating one.

#### No Transactions

If you're sending a one-off email, and your lead does not yet have any transactions, you can add one right from the email that you are drafting. Once it the transaction is added, you can continue drafting the email using transaction variables.

Want to know more about variables? Learn about Email and Text Variables

## Transaction Checklist Updates

Look for NINE updates to Transaction Checklists in this update:

#### 1. Private Transaction Checklists

You can now create, edit and delete your own private Transaction Checklists.

- Limit: 20/user
- Visibility: Only visible to the checklists' creator.

#### 2. Kanban Layout

Transaction Checklists now have a "Kanban" (card) layout.

- Transaction tasks can be dragged and dropped to a new place in the checklist.
- Tasks will display a bell icon when a due date is applied to the task.
- This update is permanent and the list view has been retired.

#### 3. Assigning Tasks to Vendors

Transaction Tasks can be assigned to one assignee per task. The assignee can be:

- Transaction owner
- Another agent involved in the transaction
- Any available vendor or lender

#### 4. Multiple Checklists added to a single transaction

There is now no limit to the number of transaction checklists that can be added to a transaction. This means you can have a standard checklist template, and one specific to a particular situation that comes up regularly.

Note: An individual task can be added to a transaction, and, if not already added to the system, the assignee can be added manually.

#### 5. Updates to the Task View

Search - Users can search for tasks by task name or by assignee.

Add Filters - Filters have been added to tasks to make finding them easier.

- Filter by Task Status
- Filter by due Date (Due Today, Due in 3 days, Overdue. These are not editable.)

Task Ordering - Within each stage, tasks are displayed in the following order:

1. Undetermined Due Date (A due date linked to a transaction date that hasn't been set.)
2. Specific Due Date
3. Tasks with no Due Date

Assignee - Assignee can now be changed directly from the task list

Overdue Tasks - A notification will be displayed for overdue tasks

Reminder Icon - Just like in the Kanban view, a bell icon will appear on tasks with a due date set.

Checklist Template - The name of the checklist template for each task will be displayed in the list.

#### 6. New Kanban view for tasks in a single transaction .

You can view the tasks for a single transaction using a Kanban view.

#### 7. Send Emails and Texts to any contact associated with the transaction.

Previously, emails and texts could only be sent to the lead.

Now, all contacts associated with the transaction can be texted or emailed.

When you click the text or email icon, the message will be directed to the lead associated with the transaction, by default, and all associated contacts can also be included.

#### 8. Update Tasks in the Calendar

Before, clicking on an unfinished task would automatically mark the task as complete. This is an issue if you were trying to look at the task or if you clicked it accidentally.

Now, clicking the task name will give you the option to mark the task as Done or Not Applicable.

Clicking the due date allows you to manually update the task status.

#### 9. Task Ownership Display

If the assignee on the task does not have an active Lofty account (a Vendor, for example), the task will appear on the transaction owner's calendar.

Want to do a deep dive on Transaction Checklists? Learn more in the Help Center in Transaction Management Checklists

## Add a Lead in a Transaction

Previously, the lead would need to be added before a transaction can be created for them. Now, you can create the lead at the same time you create the transaction.

Learn how to create a transaction here: Transaction Management Introduction

## Document Management Update

Look for four (4) updates to documentation in the platform:

#### 1. Transaction Document Folders

You can now organize transaction documents in folders and add new document folders. Each transaction will have a Default folder that cannot be deleted. This folder CAN be renamed.

#### 2. New ways to Upload Documents

Drag and Drop - You can now drag and drop single or multiple documents to Transaction Document Folders.

Upload from email attachments - You can email attachments directly to a Transaction Document Folder. Copy the provided email address and send the document to the copied email address. After sending the email, refresh the documents page and the document will have been added to the appropriate folder.

#### 3. Bulk Actions

You can now perform bulk actions on Transaction Documents.

Check the box next to one document to access these actions:

- Preview: This allows you to peek at the document without downloading it.
- Rename: This allows you to change the name of the document in the folder

Check the box next to one or more documents to access these actions:

- Download
- Delete
- Move: Moves the document(s) to another folder.
- Send Email: Attaches the document(s) to an email for sending
- Send to Docusign: Send the document for signature directly from the transaction. Requires an integrated DocuSign account.

#### 4. Integrate DocuSign directly in the transaction documents page

You can now integrate with DocuSign directly in the transaction documents page, keeping you in one spot so you don't have to navigate to the integrations page to connect.

## Inbound Voicemail Update

This update adds two default Inbound Call Voice Messages (one male, one female) and the option to record (Add) your own inbound call voicemail greeting message.

Learn more about setting up your voicemail box and checking your messages here: Inbound Voicemail

## Company Number Unknown Inbound Routing Optimization

This is an expansion on the call routing for unknown inbound numbers originally introduced in v4.15.

#### Routing Rules

Like Lead Routing for non-call lead sources, you can create custom rules to decide how to route inbound calls and texts from numbers that are not associated with any lead in the platform. You can add up to 10 custom rules . Rules can be numbered Rule #1, Rule #2, Rule #3, etc. Rules will apply to the first rule for which the call/text meets the criteria. If no rule's criteria are met, the call/text would be routed to the Default Rule, which is set to catch any remaining call/text.

Learn more about routing unknown inbound calls to the Company number here: Company Number

## Mass Create Mailing Labels

Ever wanted to turn your Lofty leads into mailing labels? You can do that from the People page of the platform now! This one is really easy. Just select the leads (up to 250) you are planning on mailing. Then, click the "More" option, and select Mailing Label.

Learn more here: Print House: Mailers

## SEO: AI Generated Meta Data

This update allows you to automatically generate page Meta titles and Meta descriptions using AI. The content generated meets keyword inclusion, brand name requirements, and character limits, all while saving the time that would be used writing these yourself.

Learn more about Lofty's SEO tools here: SEO Checklist and Page Report
