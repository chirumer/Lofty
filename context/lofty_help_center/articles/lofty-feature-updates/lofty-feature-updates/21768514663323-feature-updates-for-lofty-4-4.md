## Lofty System Tags and Sources Update

Automatic changes happening on January 16th:

Due to Lofty's recent rebranding, system tags and sources will automatically be updated from "Chime" to "Lofty." This includes all lead data (tags, sources, etc.), reporting, Smart Plans, and lead routing rules associated with these tags and sources. We are ensuring that this change is seamless, and no action is required on your part .

Updates required for third-party integrations:

If you have integrated third-party systems (like Zapier) with our platform, you may need to update those configurations by adding the new Lofty system tags and sources. Some specific changes to look for on this one:

- Sources "Chime Paid Leads" will change to "Lofty Paid Leads" "Chime Listing Ads" will change to "Lofty Listing Ads" "Chime Postcard" will change to "Lofty Postcard"
- Tags "Chime Nurturing Ads" will change to "Lofty Nurturing Ads" "Chime Email Lead" will change to "Lofty Email Lead" "ChimePaid-FB" will change to "LoftyPaid-FB" "ChimePaid-Google" will change to "LoftyPaid-Google" "Re-registered (Chime Paid-FB)" will change to "Re-registered (Lofty Paid-FB)" "Re-registered (Chime Listing Ads)" will change to "Re-registered (Lofty Listing Ads)" "Re-registered (Chime Paid-FB Form)" will change to "Re-registered (Lofty Paid-FB Form)" "Re-registered (Chime Paid-Google)" will change to "Re-registered (Lofty Paid-Google)" "ChimePaid-Microsoft" will change to "LoftyPaid-Microsoft" "ChimePaid-Remarketing Lead" will change to "LoftyPaid-Remarketing Lead" "ChimePaid-FBform"will change to "LoftyPaid-FBform"

*Important Note: Only the system tags and sources originally provided by us (formerly under the Chime name) will change. Any tags and sources you have created yourself will remain unaffected.

## Call Package Optimization

On the Call/Text Settings page, you have the option to delete or transfer a package.

The Delete logic is not changing. When a package is deleted, it can only be used by its current owner until the expiration date, when the package is deleted.

The Transfer option will allow you to transfer a package to another user on your account.

- Packages that can be transferred: All active call and text packages, including any packages that have been deleted but have not reached their expiration date.
- Who can the package be transferred to? Depending on the user management permission: Team package: can transfer to any other user on the account Enterprise package: can transfer to users in their hierarchy group or to any user in the entire company Multi-team package: Call and text packages cannot be transferred among sub-teams
- Who can transfer a package? Only the user who is paying for the package

## Character Limit Increases

### Lead Source

The character limit for a Lead Source is increasing from 30 characters to 100 characters.

### Lead Notes

The character limit for Notes on the lead's profile is increasing from 4,020 to 20,000 characters. You will also be able to export the most recent 100 notes on a lead's profile.

## Website Block Optimizations

Two (2) optimizations are available to Company, Team, Group, and Agent websites. We have added an option to copy and paste or save a customized version of the following website blocks:

- Agent
- Banner
- Content
- Call to Action (CTA)
- Embed
- Form
- Gallery
- Team
- Video

The option to customize a block is only available if your website is built on a Custom Template. If you are using one of the provided templates, you will not have this option.

## SEO Tool Beta Feature

This addition to Lofty's CMS tool will help you evaluate and improve your website's search engine optimization. If you have a Company, Team, Group, or Agent website and you would like access to this feature, please reach out to our support team to request to have it added to your account.

Our Help Center article on this feature is available here: Search Engine Optimization (SEO) Tool

## Lofty Assistant Beta Feature

We are beta testing two assistants, one for the web CRM and one for the Lofty mobile app, that can help you navigate the CRM and mobile app, answer your questions, and help you realize your potential. Please see our Help Center articles on these Lofty Assistants here:

- Lofty Web Assistant
- Lofty Mobile App Assistant

If you would like to have the Lofty assistant added to your account, please submit a request to our support team. Please specify if you would like to try the web assistant, the mobile assistant, or both Lofty assistants.
