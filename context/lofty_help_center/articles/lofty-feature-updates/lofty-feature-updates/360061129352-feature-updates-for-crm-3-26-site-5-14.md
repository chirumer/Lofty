## CRM 3.26

### Recurring Postcard Campaign Access

Currently, one-time postcard access is available directly in Lofty under Campaigns > Postcards (see Self-Service Postcards ). Now, a new tab will be available for those who subscribe to Geographic Farming's recurring farming campaigns for immediate insight into the performance and status of those campaigns.

See Recurring Postcards (Geographic Farming) for more information.

### Lead Routing: Re-Routing Groups

A new feature has been released to trigger lead routing for existing leads already in the database. Standard lead routing in Lofty works when a brand new lead reaches the CRM and then the lead routing rule kicks in and sends it to a specific assignee. This new feature, however, is different because it is intended to route leads that have already been in the system , not new ones. An example of when to use this could be that an ISA was the original "Agent" assigned to the lead via standard lead routing and then, after qualifying the lead, they want to trigger distribution to a group of agents for someone to take over.

Here are the key points for this feature:

- The routing action is triggered manually from a lead profile page
- Only available as an action when replacing the primary Agent role on a lead, not for the Assistant role, lender role, or any other custom roles.
- Only the Blast Alert distribution method is available in this release

The settings for this feature are found under Settings > Lead Distribution > Re-Routing Groups .

Learn more in this article: Re-Routing Groups .

## Site 5.14

### Agent Website Profiles Optimization

Currently, when a new agent is added to a team their profile is added to the CRM and then has to be added separately to the website via the CMS. This update intends to bridge that gap and negate the need to enter the same information twice when adding agents to the website. With this update, you can send agent profile details from the CRM to the CMS  and keep them updated in the same manner.

See Website Team Info > Agent Information for more details.

### Agent Block: Setting to Display All Agents

Hand-in-hand with the previous update, this setting allows for you to simply turn on a switch within an Agent Block in order to display all agent profiles in the CMS. Prior to this update, that was a configuration that had to be done agent by agent.

For more information on this feature, please see Agent Block .

### Agent Subdomain Page Synchronization Optimization

A new setting is now available on Team Websites that allows for certain pages to be shown/hidden on Agent Subdomains. Some pages are intended more for a Team Website and not as much for an Agent Subdomains. In situations like this, you can use this setting to hide the page from Agent Subdomains.

Please note the following:

- This is an all or nothing setting. You can show/hide on all Agent Subdomains or none of them.
- This new setting will not be available on the following pages: Home All Listings Sold Listings Home Valuation Blogs Market Snapshot Listing Detail Pages Agent Detail Pages Blog Detail Pages

See Add / Edit Website Pages for more information.
