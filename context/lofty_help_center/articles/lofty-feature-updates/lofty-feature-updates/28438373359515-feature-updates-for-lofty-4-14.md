## 10DLC Registration Optimizations

### Text Subscription Message Update

If your virtual phone number has been ported to Twilio, you have likely noticed the new Text Subscription Message setting:

We have optimized this setting so that it will now be sent in the following scenarios:

1. The first time the lead is texted
2. When the lead is texted after having not communicated via text message in the last three (3) months. This is a rolling 3 months, so for example, if the lead is texted for the first time on August 1, they will receive the text subscription message. If the lead is texted regularly, they will never see this message again. If the lead is not texted again until after November 1, they will receive the text subscription message again.

We realize the text subscription message may be annoying, but it has been implemented to ensure you are compliant with TCPA requirements. Learn more about TCPA here: Twilio TCPA Overview

### 10DLC Campaign Sample Messages

We've noticed a trend of 10DLC campaign registrations failing due to an issue with the sample messages provided. Twilio is requiring that the sample text messages include the method to opt-out of receiving text messages.

- Note: The sample text messages are simply samples of what one might send as a text message. The sample messages do not actually have to be sent to any leads.

We've optimized the campaign registration by automatically adding the Text Subscription Message to the end of the sample messages to meet this requirement.

Learn more about A2P 10DLC registration here: A2P 10DLC Registration

## People Page Filter Updates

On the updated People Page UI, we have added an option to filter by leads in a Lead Pond in the filters section. We have also added a button to quickly clear all filters that have been applied to the People Page.

Learn more about the People Page filters here: Lead Organization with Filters

## Smart Plan Improvement

This update allows recurring date Smart Plans and Smart Plans with the Lead Meets Specified Conditions trigger to apply to existing leads.

The checkbox will not be checked automatically. To enable this setting for existing Smart Plans, simply edit the trigger! Learn more about Smart Plans here: Managing Smart Plans

## CMA Optimizations

We've made some updates to the pricing estimation in CMAs. The goal is to provide straight forward costs of buying for buyer leads and net proceeds for seller leads. We have also added the buyer's agent commission fee as an editable field on the CMA.

We've also added a new block to the CMA that will explain why buyer's agent compensation is important. This block and be edited, moved, or deleted completely from the CMA report.

Learn more about Lofty's CMA tool here: How to Create a CMA Report

## Lofty Mobile App Assistant Update - Available September 2

The Lofty mobile app assistant is a voice activated assistant that helps you effortlessly manage your day, stay connected, and get instant answers, all hands-free! The voice assistant is more clever and can now help you search your notifications and calendar events, perform advanced lead searches, and answer product questions.

Learn more about the Lofty mobile app assistant here: Lofty Mobile App Assistant
