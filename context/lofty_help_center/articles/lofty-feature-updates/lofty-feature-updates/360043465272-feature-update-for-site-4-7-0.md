## Introduction

*Please note that the features available to you on the Lofty platform will vary depending on the package you have purchased. For any questions in this regard, please reach out to your assigned Customer Success Manager or our Support Team for more information.

### Release Date

The release date for this feature is Wednesday, May 27, 2020.

### Summary

- Zoom Live Block
- Listing Info Settings

### Zoom Live Block

*This update is available for both the Original and New CMS

Similar to the YouTube and Facebook Live block released in the last update (see Feature Updates for Site Live Streaming ), this is a block that can be used to add a Zoom Live Stream directly to a page on your website. For instructions, please reference the following articles:

- Zoom Live Block (Original CMS)
- Zoom Live Block (New CMS)

*IMPORTANT : Please note that currently all Zoom Meetings integrated into the Lofty website will be set to public so that all leads can participate directly.

### Listing Info Settings

*This update is only available for the New CMS

An additional setting has been added in the CMS Tool that allows for you to adjust the following:

- Sold Listings Do you want to display the listing price on sold listings? Do you want to display the sold price on sold listings?

See the following article for more information: Listing Info Settings .

## Questions?

If you have any questions regarding this topic or any others, please reach out to our Support Team via email at <support@lofty.com> or by phone at 1 (855) 981-7557.
