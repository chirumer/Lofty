## Important Updates

Please be aware of the following changes that have been made prior to this new release.

### Company Number

All Lofty packages now have access to the Company Number feature. Please see Company Number for more information on how to best use this Lofty feature.

### Email Sending Address

Some important changes have been implemented regarding the email address/domain used to send out property alerts, Smart Plan emails, etc. You may have noticed some changes in your account with emails being sent from an address that is different from what you expected. All of these changes have been made out of necessity to better protect your email reputation and set you up for continued success as you deliver emails and valuable content to your leads.

Please take some time to review the following article for an in-depth explanation of what has changed: Email Sending Address .

### Spam, Bounced, Phishing, and Unsafe Emails

In order to better protect your email reputation and that of others using the Lofty platform, new mechanisms have been put in place when a high bounce rate is triggered for emails sent via the Lofty platform. This information as well as details regarding some recent concerns regarding phishing email warnings are addressed in the following article in our Help Center: Spam, Bounced, Phishing, and Unsafe Emails .

## CRM 3.27

### Call/Text Package Usage Notifications

Be aware that you may start to notice Lofty notification pop-ups when you are at 80% of your usage on call/text packages as well as once you have reached the maximum on that package. These notifications are intended to give you options to upgrade or change your contact attempts based on available usage.

### Listing Analysis Module - Dashboard

A new module has been added to the Lofty Dashboard: Smart Listing . If you have active listings, this module will display your most recent three listings within the last 30 days. This module is intended to accomplish the following:

- Show lead activity with the listings (saved, messaged, scheduled, etc.)
- Show leads that have the potential to be interested (based on their search criteria)
- One of the buttons will provide easy access to the Listing Ads tool
- Another button will provide easy access to the Self-Service Postcards tool
- If you need to add your MLS Agent ID (connected to a variety of Lofty features) you can do so directly within this module

## Site 5.15

### MLS Agent ID Optimization

Prior to this update, you were expected to add your MLS Agent ID in both the CMS and CRM and each was maintained separately. With this update, these are now synchronized to use on both parts of the platform. Because they are now synchronized, if the MLS Agent ID is changed in the CRM it will update in the CMS and vice versa.

(a) For Team Owners/Admins who have a Team Website or for agents that have either an Agent Website or an Agent Subdomain, you can add the MLS Agent ID via the CMS > Settings > Listings > MLS Integration :

(b) The same individuals as (a) can also update in their CRM > Settings > Profile by searching for their name or email address. More information about this part can be found under Complete your Lofty Profile, Email Signature .

*IMPORTANT : Please note that only one MLS Agent ID is supported per MLS. Each MLS will have its own field.

(c) For agents that do not have an Agent Website or an Agent Subdomain, they can add an MLS Agent ID via CRM > Settings > Profile . What this does is it allows for that agent to have their listings shown on their agent profile (when clicked from the About page, etc.) as well as if a listing on the website is their listing (where they are the listing agent), their profile will display on that listing detail page. The only way that will work, however, is if they are configured as a CRM Agent as this will not work if they are only a Roster Agent . See Website Team Info for more information on CRM Agent vs. Roster Agent

### Vendor Block

A new block type has been released to support the addition of vendors on Lofty -built websites. This block type was designed to display vendors/partners and their contact information, etc. directly on your Lofty -built website to make their details accessible to site visitors.

You can learn more about this block here: Vendor Block .
