## Activity Leaderboard

This feature is currently being beta tested. You may or may not see this in your account.

The Agent Accountability Activity Leaderboard provides visibility into key performance metrics across a team, office, or company. It helps track productivity and identify top performers based on communication and task completion KPIs.

Learn more about this reporting tool here: Agent Accountability Activity Leaderboard

## Send a Landing Page via Mobile or Web Chat

When chatting with a lead, in either the web or mobile app, we’ve added a simple option to send the lead a landing page. Click the LPs icon to see a list of all the landing pages that the user has access to. There’s also a search bar and filters to find the page quickly.

Learn more about Landing Pages here: Landing Pages

## Sales Assistant Listings Updates

We're introducing some enhancements to the Sales Assistant's listing interaction abilities to deliver a higher-quality experience for leads by:

- Encouraging them to stay longer on the Lofty website and chat with Sales Assistant
- Making it easier to engage with listings in a natural, intuitive way.
- Helping them revisit and compare their favorite homes.
- Empowering agents with actionable insights into their clients’ preferences, enabling more targeted and meaningful follow-ups.

Sales Assistant already helps leads discover homes by understanding their preferences and recommending listings. Now, it can close the loop by saving those listings directly to the lead’s search portal.

Learn more about the AI Sales Assistant here: AI Sales Assistant / Chatbot FAQ

## New Branding Bundles

We've introduced two (2) new branding bundles to help you launch your business!

Here’s what’s included:

- Customizable Agent Website Launch a sleek, modern website using professionally designed templates and a personalized domain, making it easy to showcase your brand and listings.
- Virtual Phone Number Maintain a professional presence and build brand recognition when calling or texting clients directly from the platform.
- Call Package Ensures every conversation is automatically recorded and logged on the lead’s profile, giving you a clear view of their last touchpoint and helping them stay organized and responsive.
- Text Package (Elite Branding Bundle only) Share listings and keep conversations going, with every message saved to the lead’s profile for easy follow-up.
- Lofty Present A dynamic, custom-branded CMA tool that delivers detailed market insights, property comparisons, and a polished presentation experience for clients.
- AI Marketer A fully automated social media marketing tool that boosts brand awareness, promotes listings, and generates high-quality, low-cost leads.

Learn more here: Branding Bundle

## Agent Website Optimizations

This optimization allows for greater control over your Lofty website, so you can tailor your messaging, visuals, and layout to resonate with your local markets and personal style, without compromising the overall brand integrity set by the brokerage.

### What can be edited?

Feature | Permission/Behavior
Header | Optional (Can choose to edit or keep synced)
Footer | Always synced from the parent website
Menu | ✅Rename ✅Move ✅Hide ❌Delete ❌Add New Pages ❌Add New Folders
Block Library | ✅Can add the below blocks with limited styles: Hero Agent Review Featured Area Home Valuation Featured Listings Blog Form
Style | ❌
SEO Settings & Advanced SEO Tool | ❌
Blog | ✅
Featured Area | ✅ (Maximum of 6 allowed)
Registration Popup | ❌
Lead Registration Rules | ❌

If you are the account admin, you can control how agent websites sync with the parent website. The default is an ongoing sync, which will make any changes to the parent site sync to the agent sites. A new setting is a one-time sync, which unlocks the above editing capabilities for the agent websites. To enable this setting, navigate to Company Settings > Organization Hierarchy > ellipses > Agent Website Sync Mode.

Learn more about agent websites here: Agent Websites
