## Introduction

*Please note that the features available to you on the Lofty platform will vary depending on the package you have purchased. For any questions in this regard, please reach out to your assigned Customer Success Manager or our Support Team for more information.

### Release Date

The release date for these features is Tuesday, March 31, 2020.

### Summary

- Support for up to 50 Custom Fields
- New "All" Option for Lead Profile Activity Search
- Google/Outlook Calendar Integration Optimization
- Enterprise Admin Access to Lead Gen Report
- Team Member Access to Individual Lead Gen Report
- Realtor.com Connections℠ Plus Leads via API

### Support for up to 50 Custom Fields

With this update, teams can now add up to 50 custom fields via Settings > Features > Custom Fields . This change has been made to support additional information being documented in specific fields that are consistent across lead profiles. More information regarding custom fields can be found here: How to use Custom Fields .

*IMPORTANT : Please keep in mind that custom fields are not searchable and should not replace tags and segments which are designed for filtering (see Lead Organization with Tags and Lead Organization with Segments )

Because the number has increased to 50, the way they display is also different when adding a lead because there will now be a menu that has to be expanded:

All of these custom fields are also available for import which can be very useful when importing information into Lofty that should be consistent across all leads:

### New "All" Option for Lead Profile Activity Search

A new checkbox is now available when filtering activity on a lead profile. This is a simple improvement that allows for users to simply click on "All" instead of manually checking each box separately.

### Google/Outlook Calendar Integration Optimization

The appointment functionality (see Appointments ) has been improved so that events will display with the lead's name on the integrated Google or Outlook Calendar. Here is how it will work:

1. If the appointment is created in Lofty without a description, then the description of the appointment synced to Google/Outlook Calendar will be: "Lead Name - New Appointment"
2. If the appointment is created in Lofty with a description, then the description of the appointment synced to Google/Outlook Calendar is: "Lead Name - Description"

### Enterprise Admin Access to Lead Gen Report

*Only available for lead gen being run by the Lofty Ads Team

At the present time, lead generation campaigns can only be run to either the team website or individual agent subdomain websites. With this update, users of the Enterprise product will have the option to log into the teams on their accounts to view ad performance for that specific team. This was previously only available to the Team Owner/Admin of that time.

To access, an Enterprise Admin will use the Enterprise Back-End to log in to the team and then click on the Campaigns tab at the top for that team. They will then see the ad campaigns for that team:

### Team Member Access to Individual Lead Gen Report

If an individual Team Member is running a lead generation campaign with the Lofty Ads Team, they will now have access to their own individual report under the Campaigns section. This type of report was previously only accessible to the Team Admins/Owners and for team campaigns. With this update, an individual member can have insight into their own personal campaign that they can run with Lofty .

### Realtor.com Connections℠ Plus Leads via API

A new direct integration has been released with Realtor.com and is only for Connections℠ Plus Leads and works via Realtor.com's lead delivery API (eLeads). If you have a Pro account with Realtor.com, you can have your Connections℠ Plus leads imported into Lofty automatically when a new lead is generated.

To learn more about how to set up this integration, please reference the following Help Center article: Realtor.com Integration .

*IMPORTANT: Please note that this connection method is available for Connections℠ Plus leads only. It is not currently available for other leads, including Advantage℠ Pro and Profile leads. These kinds of leads can only be imported through email parsing mentioned previously.
