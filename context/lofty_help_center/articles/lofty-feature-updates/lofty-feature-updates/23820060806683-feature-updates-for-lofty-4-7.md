## Summary

- Optimizations to the Beta People Page UI
- Quick CMA
- Image to Code Embed Block
- Lofty mobile app showing request optimization
- DocuSign Integration

## Optimizations to the Beta People Page UI

We have made some optimizations to the beta-release People Page. These updates will apply to anyone who is currently on this beta. Learn more about the beta released People Page here: Beta Feature - Updated People Page UI

### Lead View Updates

It is now easier to see which filters have been applied to the People Page.

We have also added view templates, to simplify the process of creating a new custom view.

### Segment View Updates

With this update, the Segment view is much more functional. The Action column, which previously only allowed you to edit the Segment name and reminder period, change the Segment order, or delete the Segment, now allows you to also send a mass email to the leads in a segment, send letters and postcards to all the leads in the Segment, and pin a Segment to the top of the list.

When creating a new Segment, you will immediately be asked if you want to add leads to the Segment right away. If so, you can add filters to select the appropriate leads for the segment.

A new section called Automation simplifies the process of contacting and seeing data on all the leads in a Segment. Here is an example of the email automation for a Segment:

To learn more about the beta release People and Segment pages, please visit Beta Feature - Updated People Page UI

## Quick CMA

This update simplifies CMA creation and allows you to get started with one click. The quick CMA option will automatically retrieve property information and conduct a search for comparable properties.

Auto CMA criteria include radius, property type, ±50% square footage, bedrooms (0 or more), and sold date within the last 183 days.

Learn more about Lofty's CMA tool here: CMA Tool / Lofty CMA

## Image to Code Embed Block

This new website 'Embed' block will allow you to upload a static image that will be converted to HTML code that allows you to adjust the image.

Note: This is a beta released feature that can be made available by request.

This block allows you to upload an image, and AI technology will rebuild that block on your Lofty built website. After the image is uploaded, you can adjust the code manually or prompt the AI to update the image for you. Learn more about this block here: Embed Block

## Lofty mobile app showing request optimization

This update to the Lofty mobile app adjusts the Showing tool so that it is more consistent with the web CRM showing tool.

This update gives you the full functionality of the Lofty showing tool, from the convenience of the Lofty mobile app. Learn more here: Lofty Real Estate App

## DocuSign Integration

Lofty's integration with DocuSign is now available. Please learn more here: Docusign Integration
