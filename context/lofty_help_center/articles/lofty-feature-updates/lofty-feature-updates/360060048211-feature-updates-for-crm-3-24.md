## CRM 3.24

### Custom Fields: Number Data Type

You can now add "number" type custom fields if you would like for the field to only support numbers. Decimal points are also supported.

### Company Number

*IMPORTANT : This feature is currently only available for users on the Business or Enterprise Lofty packages.

A new virtual number has been released called a " Company Number ." A company number is a virtual number that is shared by all team members on a Lofty team. This is different from what will now be referred to as a " Personal Number " which refers to the virtual number that belongs to and is utilized by an individual user.

The Company Number is configured by the Team Owner/Admin and accessible by everyone on the team to use to send/receive texts or calls. Inbound calls/texts will be routed to the assigned agent.

To learn more about the Company Number, please reference HERE .

### Manage Dialer Page Adjustments

The following changes have been made on the "Manage Dialer" page:

1. The layout has now changed overall
2. A new "Sender ID to Display" field is available (associated with Company Number functionality)
3. The number forwarding feature is now built directly into these settings (see Inbound Call Forwarding )

### Rearranged Template Settings

The settings for the following have been relocated to make accessing the configuration more intuitive. No features have changed here.

- Templates Call Voice Message Call Script Questionnaires Text Auto Welcome Text Text Templates Email My Email Templates Team Email Templates Automated Templates Email Templates Report Smart Plan My Smart Plans Team Smart Plans Library

### Lead Pond Opportunity Notifications

Based on your feedback a new notification setting has been made available under Settings > Preferences > Notifications specifically for lead pond opportunities.
