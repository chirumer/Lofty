## New Navigation Bar

Overview

- Lofty’s navigation bar has been redesigned for faster access and an easier onboarding experience.
- Core product functionality remains unchanged; only menu locations have been updated.

Release Details

The updated navigation bar reorganizes features into clearer, more intuitive menu groups, helping you move through the CRM with fewer clicks. All existing tools and capabilities are still available, but several items have been moved to new locations. Notably, the Settings page has been removed from the main navigation and is now located in the Avatar menu.

## Lead Detail Page Update

Overview

- The Lead Detail Page has been redesigned to better match real-world lead management workflows.
- New tabs, streamlined note types, and reorganized data make it easier to manage properties, searches, transactions, documents, and automations.

Release Details

The updated Lead Detail Page introduces new tabs: Seller Properties, Buyer Searches, Transactions, Documents, and Automations to provide clear separation of lead activities. Insight data now appears above the Details section, and all search-related history has been moved into Preference Profiles under the Searches tab. New note types support faster showing logging and document uploads, each creating a corresponding timeline entry. All existing smart plans and alerts remain unchanged, and historical Search Criteria data has been migrated automatically to the new structure.

Learn more here: Lead Profile Page

## Transaction Management & Offer Comparison

Overview

- New AI-powered tools now enable you to search, create, and update transactions using natural language.
- A new Offer Comparison feature provides side-by-side offer reviews with an auto-generated summary.

Release Details

AI Transaction Management allows you to manage transactions through conversational inputs, including searching by criteria such as stage, property address, associated lead, and close dates; creating new transactions with basic details; and updating existing transactions through natural language commands. The new Offer Comparison feature lets you compare multiple offers from a listing or transaction. AI generates a summary and a visual side-by-side report to help sellers understand key differences between competing offers. Learn more here: Offer Management

## Buyer Lead Offer Management

Overview

- Create and manage buyer-side offers directly from the Lead Detail Page.
- All offers tied to a lead are centralized for easier review, editing, and transaction creation.

Release Details

A new offer workflow is available in the Searches tab of the Lead Detail Page, where you can manually add offers and track the status (Submitted, Accepted, Declined, Lost, or Withdrawn). Each offer includes actions such as deleting, adding notes, viewing details, or creating a transaction. When a transaction is created from an offer, the property information from the offer is automatically applied. All offers created in this area are buyer-side only, and associated lead and transaction type settings remain fixed for data consistency.

## Sales Tab Offer Management

Overview

- A new Offer List view in Sales → Offer centralizes all listing-side and buyer-side offers.
- Offers are automatically grouped based on how and where they were created, reducing duplicates and simplifying review.

Release Details

The new Offer List view provides a unified location for managing offers created from listings, transactions, or buyer leads. Listing-side offers are grouped when they originate from the same listing or listing-side transaction, while buyer-side offers are grouped by lead. Each row displays key information such as address, offer count, and highest/lowest offer amounts. Open any offer group to view or edit individual offers. This update streamlines offer organization and improves visibility across all active and historical offer activity.

## New Marketing Tab → Email

Overview

Note: This feature is being beta tested. You may or may not have access to this feature.

- The Marketing → Email module now provides a centralized view of all mass-email activity.
- Three updated sections—Overview, Campaigns, and Templates—deliver clearer analytics, improved campaign management, and enhanced template organization.

Release Details

The new Email Overview Dashboard consolidates performance metrics, including sends, opens, replies, bounces, and time-based trends. Campaigns now feature improved filtering, clearer audience details, and a two-tab Campaign Detail page for email previews and analytics. Sent campaigns include recipient-level behavior with export options. The Templates area has been redesigned with folder navigation, search, card/list views, and bulk actions. Users can create templates using either the Classic Email Editor or the Drag-and-Drop Email Editor. Learn more here: Email Templates

## New Marketing Tab → Text Messages

Note: This feature is being beta tested. You may or may not have access to this feature.

Overview

- The new Marketing → Text Messages module provides centralized analytics and management for all text-message activity.
- The module includes Overview, Campaigns, and Templates sections, with tools for performance tracking, compliance alerts, and text-package monitoring. Text sending will be added in a future release.

Release Details

The Overview Dashboard consolidates metrics such as texts sent, delivered, delivery rate, replies, and historical trends. A My Text License panel shows package usage with alerts when limits are exceeded. The Campaigns section lists all text campaigns with search, filtering, delivery insights, and detailed engagement data. Templates remain consistent with existing text-template functionality. New system notifications alert you when required compliance settings—such as 10DLC registration or quiet hours—are missing. Learn more here: Text Templates
