Important: Please note that the availability of certain features outlined in these release notes will vary depending on the package and add-ons that you have purchased as well as the account type that you have (admin/standard user). These features are subject to change at any time.

## Release Date

Monday, February 24, 2025

## Summary

- Lead Import Owner Fields
- New Transaction Variables
- Scan Paper Documents via the Lofty Mobile App
- Drag-and-Drop Email Editor Optimizations
- WordPress IDX Plugin

## Lead Import Owner Fields

With this update, you have the ability to assign lead ownership within the lead import feature, either when matching your csv file columns or on the final options page.

Learn more about Lofty's lead ownership settings here: Lead Ownership

## New Transaction Variables

Six new transaction variables have been added for all Agent and Lender transaction roles.

These new transaction-based variables are available in both the web and mobile app:

1. First Name
2. Last Name
3. Company Name
4. Company Address
5. Email Address
6. Phone Number

Learn more about personalizing your messages with variables here: Email and Text Variables

## Scan Paper Documents via the Lofty Mobile App

If you find yourself drowning in paper documents, this update is for you! We've built in an option to scan paper documents and create a pdf document that can easily be stored within a transaction or lead detail page.

Learn how to start scanning your documents and all Lofty's other document management features here: Transaction Management Documents

## Drag-and-Drop Email Editor Optimizations

Lofty v4.21 introduces four (4) optimizations to our drag-and-drop email template editor:

1. Format Brush and Eraser
2. The ability to edit the Listing Card
3. Embed YouTube videos
4. Add attachments

Learn more about this customizable email template creator here: How to Use the Drag-and-Drop Email Editor

## WordPress IDX Plugin

The first version on our WordPress plugin is now available for purchase in the Marketplace! Before you purchase, please check out our Help Center article, which outlines exactly which Lofty features are compatible: WordPress + Lofty IDX Plugin

We are actively optimizing this plugin and other features, like Property Alerts, will be available soon!
