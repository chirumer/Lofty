## Summary

## CRM 3.31

### Transaction Management: Support for Custom Dates

A new setting has been added under Settings > Transactions > Custom Fields :

These custom date fields are specific to Transaction Management (they cannot be used to trigger Smart Plans) and can be used wherever dates are displayed as associated with transactions–including the following:

Transaction Summary Page

Transaction Detail Page

Transaction Checklists

### Transaction Management: Kanban View

A Kanban view is now available to review transactions in Lofty . The concept with this view is that you can easily drag a card from one list to the next to move a transaction down the pipeline stages.

Here is a sample of what the board looks like:

Each individual card has a summary of the transaction value, associated address, (expected) closed date, task count, and a hyperlink to the connected lead profile page:

When you access the Transaction Management page next, you will automatically see the kanban view by default but you can easily switch to the original list/column view if you would like to by using the option in the top-right:
