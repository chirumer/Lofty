## Introduction

*Please note that the features available to you on the Lofty platform will vary depending on the package you have purchased. With any questions in this regard, please reach out to your assigned Customer Success Manager or our Support Team for more information.

### Release Date

The release date for this set of features is Tuesday, September 3, 2019.

### Summary

- Increased Capacity for Mass Texts
- New Permission: Edit Own Website
- Matched Listings linked to Lead Detail Page
- Landing Page: Single Property (Promotion) Improvements

### Increased Capacity for Mass Texts

Lofty users who want to send mass texts via the Lofty Web App can now send up to 200 texts at once. Previously, the limit was 50 texts at once.

*Be mindful of your text package daily limit when sending out mass texts!

### New Permission: Edit Own Website

Team Owners/Admins now have the access to turn on/off access for users on their team to be able to edit their corresponding subdomain website. If the permission is turned OFF, that Lofty user will be unable to edit their CMS Tool ( ). The Team Owner/Admin can still control these websites.

Here is where that permission is found:

Settings > Team > Agent > Agent Permissions > Toggle on/off "Edit Own Website"

This new "Edit Own Website" permission does relate to the "Manage Team" permission. Here are the two situations with how they interact and the help message that will appear if you attempt what is in the "Action" column:

Situation | Action | Help Message
Manage Team: OFF Edit Own Website: OFF | Turn "Manage Team" ON | This permission cannot be turned on until you turn on the "Edit Own Website" permission first.
Manage Team: ON Edit Own Website: ON | Turn "Edit Own Website" OFF | You must turn off the permission to "Manage Team" before turning this one off.

### Matched Listings linked to Lead Detail Page

The Listing Discovery tool (already released) allows for users to easily match buyer leads with properties based on their search criteria. This displays like this on the Listing Discovery section:

With this update (2.9.4), Lofty users can click on the new "View ______ Listings Matched" button to be shown the active listings that match the search criteria for that particular lead. Here is where this is displayed in a lead profile page--on the left Search Criteria section as well as under Engagement > Search Criteria:

### Landing Page: Single Property (Promotion) Improvements

Edit/Add Open House Times

This can be done for all landing pages that are the "Single Property (Promotion)" type. First, create the page, then edit the Open House time by selecting the "Property Info" block
