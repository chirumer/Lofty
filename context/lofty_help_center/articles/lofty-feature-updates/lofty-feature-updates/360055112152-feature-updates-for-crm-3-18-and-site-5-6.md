## CRM 3.18

### Integrations Placed in Lofty Marketplace

You can now find all of our integrations directly in the Lofty Marketplace:

### AI Assistant: Follow-Up Optimizations

#### Increased Number of Follow-Up Texts

This update increases the number of follow-up texts sent by the AI Assistant (for when a new lead does not respond) from two to four. The goal is to improve the text response rate by giving leads more opportunities to engage with the AI Assistant.

#### New Follow-Up Trigger

A new trigger has been added with this release. When an existing lead is captured via any other source (in Lofty this is considered a "Back On Market" opportunity ), the AI Assistant will follow up with this existing lead regarding their new inquiries to try to qualify them and capture their buying/selling preferences.

### AI Assistant: Mute Optimization

With this update, when clicking on the "Mute" button to stop the AI Assistant from working a lead, there will be a question asked:

"Do you still want the AI Assistant to follow up this lead in the future if they trigger opportunities (requests a showing, saves a listing, etc.)?

Based on the option selected, the following will occur:

- Yes : The AI Assistant will be muted only while in the "New Leads" pipeline stage. After that, if the lead matches the criteria to be re-engaged, the AI Assistant will still follow up with this lead in the future.
- No : The AI will be muted permanently (this is what currently happens when clicking "Mute")

The criteria to re-engage is the same as can be seen in the settings for "EXISTING LEAD qualification via text message."

### Call/Text Timeline Optimization

With this update, you will be able to better distinguish texts and calls between family members on the same lead profile. You will be able to see who sent the message or made the call and from what number, as well as who was called/texted and at what number. Previously, this information would blend together and look as if it was always with the primary lead. Now, it will display which family member the number belongs to.

Please note that this currently only applies to calls and texts, not emails that are sent/received with family members of leads.

### Lead Pond: Visible Pipeline

Prior to this update, the pipeline was not visible in the lead pond and could therefore not be used for sorting leads. Now, however, it is visible in the Lead Pond.

More information regarding the lead pond can be found here: Lead Pond .

## Site 5.6

*IMPORTANT : Features are available for New CMS only. If you have questions about CMS version, please reference this article .

### Gallery Block

This block allows for you to more effectively display multiple images. There are four different settings that can be adjusted: (1) Content (title, images), background, display mode, and style. It can be full screen width and have d ifferent background colors.

When there are more than four images, two display modes are available: (1) Horizontal Slider and (2) Vertical Tiles. There is currently no limit to how many images can be added.

There are two different scenarios where the functionality varies:

1. Listing details pages . When used on listing details pages, the images for this block will be auto-populated with the property’s images from the MLS. These images cannot be changed so there is no configuration available here.
2. All other pages (including landing pages) . Everywhere else, any image can be uploaded to build out the block.

For more information about this bloc, please reference: Gallery Block .

### Pocket Listings Image Drag & Drop

When adding/editing images for pocket listings (see How to Add Pocket Listings ), you can now drag and drop to reorder the images instead of having to re-upload, etc. Simply click and hold anywhere on the image to move it around.

### Image Previews on Listings Lists

An exciting improvement has been made on both the desktop and mobile views of lists showing the listings on a Lofty website. In other words, when performing a property search or browsing featured listings, etc., there is a list of properties displayed. Normally, only the first image for the property is displayed right next to the basic property details. Now, however, the rest of the images for those properties can be previewed. On desktop, this is done by clicking on the arrows left/right. On a mobile device, site visitors can swipe with their finger left/right directly on the list.

### Website Agent Settings

A change has been made to the CMS for agent settings that will make it more intuitive when adding and maintaining your agent lists on the website. Instead of having two separate lists for the "Creator" and "Agents," this is now all on one list. The list will be in alphabetical order.

### Agent Block Improvement

The following improvements have been made to the Agent Block:

(1) Agent profiles can be edited directly via the "Edit" icon within the block instead of having to navigate back to settings.

(2) If you would like for site visitors to be redirected when they click the headshots for users, you can now add a an external URL in the agent settings.

(3) You can easily arrange all the agents currently selected to display in this block to be rearranged in alphabetical order with a simple switch.

For more information on the Agent Block, please see Agent Block .
