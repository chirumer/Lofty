## Introduction

*Please note that the features available to you on the Lofty platform will vary depending on the package you have purchased. For any questions in this regard, please reach out to your assigned Customer Success Manager or our Support Team for more information.

### Release Date

The release date for these features is Tuesday, March 17, 2020.

### Summary

- Website Updates
- AI Assistant: Existing Lead Qualification
- AI Assistant: Extra Engagement Cap
- Add Agents as Leads
- Sort Vendor / Partner List

### Website Updates

As you may already be aware, Lofty is working on releasing a New CMS Tool that will allow for our users to better control the framework of their website block by block and take advantage of many new features that will be made available with the new website structure. This has been in the works for some time and the transition is beginning now. This note is to inform you of the existence of the New CMS that will be made available to you at some point in the upcoming months.

Please reference this article for more information on the transition process: CMS Tool Versions (Original CMS vs. New CMS) .

### AI Assistant: Existing Lead Qualification

*IMPORTANT : The number of “Engagements” available with your AI Assistant package will also be used to engage existing leads in addition to new leads.

The AI Assistant can now work to qualify existing leads in the following scenarios. Future releases will also include additional scenarios.

- Leads who have registered in the past 30-60 days, opened property alert emails, but never clicked a link in the emails
- Leads who go back to the site with incomplete inquiries/search criteria
- Leads who go back to the site and make a request that triggers an opportunity. For more information regarding Opportunities, please reference Opportunities

With this improved functionality, the AI Assistant will ask questions to determine the preferences of leads (under the assumption that the information captured for this lead may not be complete or accurate). It will also confirm opportunities and notify agent users about these leads just like it currently does with new lead qualifications.

The following are the new settings available to determine what leads the AI Assistant will work in Lofty . These are available to view and edit under Settings > Features > AI Assistant .

### AI Assistant: Extra Engagement Cap

For clients with the Premium AI Assistant package, Lofty now supports the ability to set a monthly dollar amount as a spending cap. This was designed because the Premium package allows for users to pay for extra engagements beyond the package allotment. With the new feature to work existing leads, you may find that additional engagements would be beneficial to your business model and can use the Premium package to accomplish this.

For billing, the payment on the first of each month will be the recurring monthly fee plus the extra amount used in the last month. Keep in mind that if the AI Assistant has not reached the limit established with the engagement cap, you will only be billed for the actual usage.

When AI Assistant engagements reach the upper limit for a month, the AI Assistant will stop working until the following month.

To edit this setting, go to Settings > Features > AI Assistant > Extra Engagement Cap :

### Add Agents as Leads

Prior to this release, a Lofty user's email address could not be used on a lead at the same time within the same team. With this update, this is now possible. An email address can now be used as both an agent/user login as well as an email address assigned to a lead. Admins may be interested in adding their new team members as a way to provide them with training via an automated Smart Plan, for example.

### Sort Vendor / Partner List

The Vendor / Partner feature now has the ability to sort by name. To learn more about how to use the Vendor / Partner feature, please read the following article: How to Assign a Vendor/Partner to a Transaction .
