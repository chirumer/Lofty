## Introduction

This article outlines how to configure the domain on your Lofty IDX website using the GoDaddy domain integration. If you would like to configure your website domain yourself manually, please visit: Domain Configuration Guide

Note: The GoDaddy domain integration will only be able to help you configure your domain if it is hosted on GoDaddy. If you're unsure where your domain is hosted, you can check using ICANN .

## GoDaddy Automatic Domain Configuration Steps

When you are ready to configure your website domain, navigate to CMS → Overview → Select a Domain: Choose from the 3 options provided. You will be prompted to enter the domain you want to use.

From the Settings tab → Basic Info → Domain → Configure.

Once you have provided your website domain, if it is a GoDaddy domain, a pop-up will offer two options:

1. Click Do it for me , and follow the steps below.
2. Click Do it Myself , and follow the manual configuration steps in the Domain Configuration Guide

After clicking Do it for me , authorize access to the GoDaddy account. The first step is to log in to your GoDaddy account.

GoDaddy will send a two-step verification code to complete the login.

Click Connect to approve the configuration.

It will take a few minutes to update the DNS records. The new domain will not be active until this is complete. Please be patient!
