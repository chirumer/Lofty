## Introduction

The "Affordability Calculator Page" can present finance calculations to site visitors so they feel more prepared and informed when deciding on buying or selling a home.

- Note: The currency will be displayed in USD when using the Calculator.

## Adding Calculator Pages

First, click on the "Pages" button on the page Editor:

Click on the button at the bottom left to "+ Add Page":

Choose the "Affordability Calculator" page template, and then click "Next."

To learn more about adjusting the calculator blocks, please reference this article: Calculator Block .

It is also worth noting that Lofty provides a default calculator page which will not be shown on your header/footer navigation by default but is used when directing site visitors to this page to see more detailed results if they click "View More Details" on the mortgage calculator found on a listing detail page (only on website template 1 & 2). Lofty suggests that if you use website templates 1 or 2, you keep this page and do not change its URL.

As always, you can add, delete, and edit blocks to establish the content on the website and change the style of the blocks to make the About page more attractive. More information on doing so can be found here: Add / Remove / Edit Blocks on Pages .
