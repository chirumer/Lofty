# Cancel, Reset, or Downgrade Website

- Article ID: `26507515965339`
- Category: `Website`
- Section: `Website Creation`
- Updated: `2025-11-11T02:37:41Z`
- Source: https://help.lofty.com/hc/en-us/articles/26507515965339-Cancel-Reset-or-Downgrade-Website

## Body

## Introduction

Lofty offers many types of IDX websites, each having its own settings and abilities. This article explains how to cancel, reset, or downgrade your Lofty-built website.

## Definitions

Reset: Resetting the website will remove all customized content and revert the website to the blank template.

Downgrade: Downgrading the website will revert the website to a subdomain of another website.

Cancel: Cancelling the website will cancel the entire website package and delete the website, as well as any subdomains built off of this website.

## Requirements and Limitations

While all Lofty-built websites can be reset, there is a limitation on what websites can be downgraded or canceled. Please take a look at the chart below to figure out which actions can be taken on your website. If you aren't sure what kind of website you have, you can just go to the Website tab in the CRM and check the Type column.

Website Type | Can it be reset? | Can it be downgraded? | Can it be cancelled?
Company Website + Full SEO | Yes | No | No
Team Website + Full SEO | Yes | No | Yes
Office Website + Full SEO | Yes | No | Yes
Agent Website + Full SEO | Yes | Yes | Yes
Agent Website (Original) | Yes | Yes | No
Agent Website | Yes | No | No

Websites can only be downgraded if their parent site has a vanity domain. If the parent site domain has not been configured, the website cannot be downgraded.

At this time, only Office Website + SEO and Agent website + SEO can be canceled. Once the website is canceled, the website and any subdomains built off of the website will be deleted.

## Instructions

Navigate to Website and select the website that you want to take action on. You are only able to reset, downgrade, or cancel websites that you are paying for. You cannot take these actions on a website that is paid for by another Lofty user.

Click the ... icon to see the available options.

Once the action is selected, a pop-up box will confirm that you wish to continue. To complete the action, a verification code will be sent to the email address associated with the website owner. The code must be verified to complete the action.

When canceling a website, you can opt to cancel now or cancel at the end of the month.

A final confirmation will verify that the action will take place. Once complete, the action is irreversible. If a website is canceled, reset, or downgraded, Lofty cannot undo this action.
