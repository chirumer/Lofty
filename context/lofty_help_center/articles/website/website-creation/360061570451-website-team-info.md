## Introduction

Part of any real estate organization is to present your team in the best way possible. You can do that directly on your Lofty-built website using the CMS (website editor). This article will outline the tools that you can use to display your team on your website(s) as effectively as possible.

## Summary

- Company Information
- Agent Information

## Company Information

To edit your website's "company information," navigate to CMS > Settings > Organization Info > Company . Here you can add the brokerage/company address as well as the brokerage/company name. These will appear in the footer of the website.

## Agent Information

There are a couple of methods to add agent profiles to your website. First, it is important to understand two terms related to agent profiles on Lofty-built websites:

1. CRM Agent Profile . This profile type is linked to the profile of a specific agent who has a seat in the Lofty CRM.
2. Display Only Profile . This profile type is ideal for anyone on your team who does not have a CRM seat. This may be an office assistant, marketing specialist, or anyone else you would like to present on the website, even if they are not using the Lofty CRM.

Once the agent profiles have been set up on the website, please reference Agent Block to learn how these profiles are to be displayed on the website.

As a reference, when we refer to a profile on the CMS , we are referring to the imported CRM agents and the display-only agents. it is found under CMS > Settings > Team Info > Agents :

When we refer to the profile on the CRM , it is found under CRM > Personal Settings > Profile

Below are two steps to follow when it comes to adding your agent profiles to your Lofty website(s).

*IMPORTANT :

- Please note that once imported from the CRM, changes made to the agent's profile in the CMS will also update the agent's profile in the CRM.
- If the agent seat is deleted from the CRM, the corresponding CRM Agent profile on the website will be deleted as well. It will not be converted to a Display Only Agent.

#### Step 1: You have not yet added your agents to the CRM or the CMS

For in-depth instructions on how to add a User or Display Only agent to your Lofty account, please see Add or Remove Team Members on Lofty .

IMPORTANT : The Allow CMS Import setting in the CRM Agent Detail page must be toggled on. If disabled, the agent will be hidden in the agent list while importing agents to the CMS.

Use the Permission Profiles and Agent Tag filters when adding agents. This makes it easier to sort through a large number of agents when adding them.

#### Step 2: You have already added your agents to the CRM, but not the CMS

If you have already added your agents in the CRM but not on the website, follow these steps.

Navigate to CMS > Settings > Team Info > Agents > Import from CRM :

All of the agent profiles that have not already been synced to the CMS will appear as options and can be selected individually or in mass:

### Custom Fields for Agent Website Profiles

Custom fields can be used to present more information about your agents on your website. For example, you could share information about each agent's favorite color or first job, the university they attended, etc.

To access the setting, navigate to CMS > Settings > Team Info > Agents > Settings Cog Wheel :

You can then create custom fields for agent profiles. They can be text boxes or drop-down lists. You can add a maximum of 15.

Once the fields are added, you can go to the agent list and add or edit an agent. A section will be available for each profile to add the information to those fields:

When the agent profile is clicked on the About page , etc. that agent's profile will appear and the custom fields are displayed there.

Here is a sample of what this might look like:

*Note: Custom fields added at the Team Website level are available when editing profiles on both Agent Subdomains and Agent Websites. In other words, custom fields are added at the Team Website level and are available to use at the Agent Subdomain and Agent Website levels when building agent profiles.
