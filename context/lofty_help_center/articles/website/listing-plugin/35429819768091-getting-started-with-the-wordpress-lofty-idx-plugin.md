## Who is this for?

- Agents, teams, and brokerages who want to take advantage of all the capabilities in the Lofty Platform but wish to retain their existing WordPress website.
- Existing Lofty customers who already have a disconnected WordPress site that want to significantly improve the value they’re getting from Lofty while also improving the browsing experience for their clients.

## How does this compare to ____?

A majority of other tools on the market only offer IDX connections (the MLS feeds) to WordPress websites. What's missing from this equation?

1. Actionable, insightful data on which activities the leads are performing on the agent's website
2. A seamless Property Alert experience for your leads
3. The ability to trigger Smart Plans based on website activity
4. + the multitude of other powerful features that the Lofty platform provides

## What do you need to know?

- The WordPress Plugin connects one WordPress website to one Lofty user . It cannot auto-create agent websites or send property alerts for multiple users.
- If you occupy the Account Owner seat in Lofty, your Property Alerts will send from your Lofty Company site. If you would like a dedicated site for your agent activities, we recommend configuring a separate Lofty seat and linking the WordPress plugin to that seat.

## Setup Instructions

### Step 1: Purchase the IDX Plugin

### The Lofty IDX Plugin can be purchased in the Lofty Marketplace.

### Step 2: Connect Your WordPress Website with Lofty IDX

Note: This step does not make the WordPress site go live. This just tells Lofty which WordPress site will eventually be connected, so it can use that domain for MLS feeds.

Once the purchase is complete, go to the CMS editor and select the Connect your WordPress Site option.

Clicking this link will take you to the WordPress Site connector. The domain that you enter here will be used for MLS applications and connected to your Lofty account.

Once this step is done, your WordPress site will be visible in Lofty. The domain will be listed in the domain section, and the Package will show WordPress Plugin. Your next step will be applying for your MLS feed(s)

### Step 3: Enable the IDX Plugin on your WordPress website

There are two options to enable the IDX Plugin in WordPress. You can either download from the Lofty CMS Editor, or from the WordPress Marketplace.

Download from Lofty

Go to CMS Editor > Settings > Plugin Installation File

#### Download from the WordPress Marketplace

### Step 4: Connect the Lofty API Key

Head into the CMS Editor > Settings to find your API key.

*note: this is different from the API Key in your Lofty Settings. Please make sure that you are copying from the right place.

Copy the API Key from Lofty, then log into Wordpress > Settings > Lofty IDX Settings. Paste the API Key and hit save.

At this point, you have completed the connection of Lofty and your WordPress site. Now you can start configuring your IDX pages to your liking.

### Step 5: Apply MLS to your Lofty Site

Once the WordPress site is linked, you will need to go to the CMS Editor > Listings and apply to your MLS board(s). This is a regular MLS application, so it may take some time for the board to approve.

The WordPress Plugin comes with sample IDX data so you can configure your website while you wait for their MLS feed to go live. Once the feed goes live, the sample listings will be replaced with your live feed.

When the MLS is approved, the status will be Active and the sample listings on your WordPress site will be replaced with live listings.
