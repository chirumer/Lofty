## Body

## Introduction

If you have access to sold data from your MLS (not every MLS will provide this data), there is a toggle in the CMS Tool that allows for some basic adjustments to be made to the pricing information that is available for site visitors to see.

## Adjust Settings

Previously, MLS organizations couldn’t fully control Sold Price visibility—it depended on website settings.

Now, the Sold Price display follows this logic:

Website OFF → Always hidden MLS OFF → Always hidden Both ON → Displayed MLS OFF + Website ON → Hidden for that MLS’s listings

To adjust the settings, navigate to CMS Tool > Listing Settings > Listing Info Settings .

Show Listing Price

Toggle this option on/off to choose whether the listing price is shown on sold listings. This is displayed in the following locations:

- Sold Listing Search

- Sold Listing Detail Page

Show Sold Price

Toggle this option on/off depending on whether you would like the "sold price" to display on your website's sold listings. This is displayed in the following locations:

- Sold Listing Search

- Sold Listing Detail Page

## Toggled-Off Display

If both of these are toggled off, this is how it will display on both locations (Non-Disclosure):

Note: Prime MLS requires explicit disclosure of data sources. To stay compliant, we have removed the “Facts About the Property” section from Prime MLS’s sold listings.

## FAQ

Q: How far back do sold listings show from the MLS on the website?

A: We usually only support displaying listings sold in the last 3 years, and it also depends on what sold data is included in the MLS data feed.
