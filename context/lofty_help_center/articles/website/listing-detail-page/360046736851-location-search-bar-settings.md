## Introduction

The LoftyIDX website Search Bar logic can be set to force the site visitor to choose from the provided suggestions in order to better narrow down their searches. This means that if a site visitor simply presses "Enter" on the keyboard or clicks the "Search" icon on the website, it will use the first suggestion as the default input value. When combined with the additional setting to determine what displays at the top (see below ), this will increase the accuracy of listings shown when searching.

## Search Bar Location Logic Optimization

By default, when a lead hits "Enter" or clicks on the "Search" icon, they will be sent to a results page showing listings associated with the first category (city, neighborhood, county, etc.) displayed. This is what is called an "Exact Search."

1. Exact Search . If you choose one of the provided suggestions from the drop-down menu, the search will show listings based on the category chosen (city, zip code, etc.).
2. Fuzzy Search . If you type in a value and press the “Enter” button on the keyboard or click the "Search" icon, listings will be shown without category restrictions (city, zip code, etc.).

If you would like to adjust this setting so that it is not "Exact Search" by default, you can change this setting in CMS Tool > Listings > Listing Settings > Location Search Bar :

## Search Bar Location Type Options

You can also access settings to customize what categories (city, neighborhood, zip code, etc.) appear when a site visitor uses the search bar on your Lofty IDX website. Perhaps you do not want to display a certain category, or you would like to change the order, or rename them. This is all possible with the available settings.

The setting is located under CMS Tool > Settings > Listings > Location Search Bar . With these settings, you can do the following:

- Hide/Display
- Reorder (determines which one displays first, second, etc.)
- Rename

## Search Bar Suggestions

If you go to one of our websites and simply click on the Search Bar , you will notice that it will automatically populate suggestions.

You can control which suggestions will populate by navigating to CMS > Settings > Listings > Location Search Bar > Location Suggestion . Any criteria added here will be auto-populated when a site visitor first clicks on the search bar. After they start typing, criteria matching their search will begin to populate, of course.
