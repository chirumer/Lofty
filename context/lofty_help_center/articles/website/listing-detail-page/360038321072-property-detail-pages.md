## Introduction

There are two types of property detail pages (aka: listing detail pages):

1. Property Detail (the listing is not sold yet)
2. Sold Property Detail (the listing is sold, with "Sold" status).

These two types of pages can be edited separately:

## Property Details Page

The property details page is built using the following blocks, some of which are unique to the property details pages:

- Detail Info
- Nearby Schools & Properties (Map)
- Marketing Trends
- Similar Homes
- Form
- CTA

*IMPORTANT :

- C urrently, these blocks cannot be deleted or hidden. They can be reordered. You can add blocks to these pages but please note that when you add a block to this page that all the listing detail pages will display that same block because it is a page group. In other words, you cannot add blocks to specific listing detail pages--for doing that you would want to build a landing page to feature one specific listing and add/remove blocks as desired.
- To better display all block styles, the data shown in the preview area to the right when in the CMS Tool is demo data. You can publish and go to the live site to see the actual effect.
- If you are located in Canada, please see Feature Availability for Users in Canada

## Breadcrumb for Listing Detail Pages

A "breadcrumb" (location hierarchy links) is available on every listing detail page. The format is the following: #State# > #City# > #Subdivision# (for Canada, this will be #Province# > #City# > #Subdivision#). All of this information is generated directly from the MLS. This will allow site visitors to easily find other listings in the city or subdivision without having to go back to generate a separate search. Please note that the state is currently not clickable.

This type of feature on every individual listing detail page also improves the usability of our websites and increases overall SEO value as well.
