## Add a Home Evaluation Page

One of these pages is built into the website by default, but if you want to add additional home evaluation pages, do the following.

Click on "Pages" from the Page Editor:

Click on "+ Add Page"

Select "Home Evaluation" from the page template list, select the style, and click "Next":

Reference the Home Evaluation Block to learn about the settings that can be adjusted with the Home Evaluation block.

Reference Add / Edit Website Pages to learn about editing a page's basic settings and SEO.

If you want to promote this page on social media or other marketing channels, Lofty recommends changing the "Page Style" to "With simple header" or "No header," to make sure the site visitors are focused on the Home Evaluation content and are not distracted by other pages that would otherwise be visible in the header navigation.

## Home Evaluation Report

After requesting a home evaluation via this feature, site visitors will receive an email that looks like the following (assuming the option to provide the home value is selected):

The Home Evaluation Report will include the following information about the lead's property:

- The estimated home value The estimated high value The estimated low value
- The price change in the last 30 days

## Home Evaluation Logic

The home value estimation given via the Home Evaluation form is provided by a third-party provider. The report cannot be edited. We recommend utilizing the CMA tool to provide a customized Home Evaluation report to a lead. Learn more about Lofty's CMA tool here: How to Create a CMA Report

If a lead provides a Canadian address, they will not automatically receive a home value estimation. Instead, they will receive a message similar to the one below, letting the lead know that an agent will be reaching out.

The lead's address and contact information will be captured, so that you can provide an accurate home evaluation and other relevant details directly.

## FAQ

Q: Who is the source of our Home Valuation data in the Lofty sites? A: Lofty uses Bridge API (a company owned by Zillow) data to give the estimated price.
