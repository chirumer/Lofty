## Introduction

The "Contact Us Page" is one of the default pages used for capturing leads by displaying team or company contact information. The default contact page style depends on the website template selected. If needed, additional contact pages can also be created.

## Adding Contact Us Page

To edit the "Contact Us" page, click on the "Page" button on the page editor:

Click on "Contact Us" to edit the existing page, or "+ Add Page" to add a new Contact Us page (see Add / Edit Website Pages ):

From top to bottom, the following are the blocks that make up the "Contact Us Page:"

- Contact Block
- Reviews Block
- Form Block

As always, you can add, delete, and edit blocks to establish the content on the website and change the style of the blocks to make the About page more attractive. More information on doing so can be found here: Add / Remove / Edit Blocks on Pages .
