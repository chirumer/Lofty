## Introduction

The "About Page" is the default page used for displaying team or company information with additional forms available for lead capture as well. The About page style depends on the website template that has been selected.

## Adding an About Page

Typically, a website will only have one About page. However, if you want to add additional About pages, you can follow the steps below:

Select the button to "+ Add Page":

Choose "About" from the page template list, choose the desired style (there are four styles available), and click on "Next":

To learn more about editing page options, please refer to Add / Edit Website Pages .

## Edit the About Page

From top to bottom, the About page consists of the following blocks:

- Team Info Block
- Agent Block
- Reviews Block
- Form Block

As always, you can add, delete, and edit blocks to establish the content on the website and change the style of the blocks to make the About page more attractive. More information on doing so can be found here: Add / Remove / Edit Blocks on Pages .
