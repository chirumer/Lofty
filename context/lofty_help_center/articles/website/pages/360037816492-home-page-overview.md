## Introduction

The home page is the first page site visitors will see when they visit your website if they type your URL directly into a browser. There will be many blocks on your home page by default. This article outlines what these blocks are. For more information on editing the blocks on the home page or any page, reference this article: Add / Remove / Edit Blocks on Pages .

- Hero
- Listings (Featured)
- CTA (Call To Action)

## Helpful Website Tips

##### Best practice for website photos

- Hero Image - 3000×1000px, recommended file is .jpg
- Mobile Image - 800×640px, jpg, the recommended file is .jpg
- Logo size and quality - 96 pixels in height, the recommended file is .png (Generally, a logo that is twice as wide as it is tall works best)
- Headshot/profile size and quality - 400x400px, recommended file is .jpg
- For the SNS, the recommended size is 920 x 300 pixels. Maximum file size of 5MB. JPG, GIF, or PNG
- Featured Blog Image - ratio of approximately 5:1 would be more appropriate
