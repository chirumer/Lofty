## Introduction

The "My Team Page" is a simple page that displays specific agent/team website profiles that you have created. This page will not be built by default, but can be added at any point in time.

## Adding My Team Page

To add the "My Team Page," first select the "Page" option on the Page Editor:

Click on the option to "+ Add Page":

Click on the "My Team" page template, select the desired style, and then click on "Next":

Adjust any page's basic or SEO settings (see Add / Edit Website Pages ).

From top to bottom, the following are the blocks that make up the "My Team Page:"

- Banner Block
- Agent Block

One thing to note is that the first template also has an agent search bar, and the others do not. Future versions will include a search bar for agents on all templates.

As always, you can add, delete, and edit blocks to establish the website's content and change the block's style to make the About page more attractive. More information on doing so can be found here: Add / Remove / Edit Blocks on Pages .
