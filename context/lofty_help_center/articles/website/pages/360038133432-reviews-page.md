## Body

## Introduction

The "Reviews Page" is one of the default pages that is provided and is typically used to display reviews from clients on the company/team/agent in a way that positions you well. It can also be used to capture leads by presenting successful client stories to site visitors. The default "Reviews Page" style will depend on the website template selected upon site creation. If additional review pages are needed, they can be added.

## Editing / Adding Reviews Page

First, click on the "Pages" button on the page editor:

To edit, select the "Reviews" page. To add a new reviews page, click on the "+ Add Page" button at the bottom (see Add / Edit Website Pages ).

The "Reviews Page" is broken down into the following blocks. Click the links for more information regarding those blocks:

- Banner Block
- Reviews Block
- Form Block

As always, you can add, delete, and edit blocks to establish the website's content and change the block's style to make the About page more attractive. More information on doing so can be found here: Add / Remove / Edit Blocks on Pages .
