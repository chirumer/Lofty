## Introduction

A site report will be sent out to clients monthly. This site report provides some basic Call To Action for the clients so that they can actively work to improve traffic and conversion on their Lofty-built websites.

Here is what that report looks like:

Only the Team Owner/Admin will receive this report and only when there are active leads on the website in the previous month. "Active Lead" means a lead that has done any of the following:

- Requested a tour
- Saved a listing
- Saved a search
- Requested a home valuation
- Created a market snapshot
