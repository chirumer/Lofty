## Introduction

The footer is a very important part of any website as it presents more company information, contact details, links to sites on the page, important MLS disclaimers, etc. Having this section up-to-date and ready to go is going to be an important part of building your Lofty website.

*Keep in mind that just like the website header, the footer can only be edited on the Home page via the CMS Tool. The steps to adjust this are found in this article.

There are four different styles to the footer. They will vary slightly with how the content is laid out and some of them might have two different background colors, etc.:

## Edit Website Footer

On the Page Editor, navigate to the home page, scroll to the bottom of the home page, and double-click on the footer block or click on the "Edit" icon in the top-right of the footer block.

To change the style, scroll all the way to the bottom of the footer settings and select the button to "Change Style":

You can adjust the background color(s) in the "Footer Background" section of the footer settings:

Make any changes to the "Sitemap Menu Style" including font weight, font size, font color, and hover color:

If there are any drop-down menus on your site navigation, you will need to adjust them here:

One of the most important parts of the footer is going to be the display of any logos. Currently, you can upload up to five logos on the footer. You can also define the "alt text" and URL (when clicked) for each logo. If you want to change the order of the logos, just drag and drop using the option on the right side of each logo.

Choose the "agent" whose information (name, phone, email, address) should be displayed in the footer. That information is set up in CMS Tool > Settings > Team Info > Creator/Agent .

If you are an Enterprise owner or an Enterpriser user with a Manage Website permission, there is an option to display either the company name or group name or to customize the displayed content. The dropdown menu will display the company name and all the upper-level groups' names.

There is also an option to add custom content to a Lofty website footer. This is available on any editable Lofty website. The content added here will sync to any subdomains that are created off of this Lofty website. This feature allows you to add extra phone numbers, addresses, or other agent/office information.

Adjust the "Agent Name Style," "Agent Phone Style," "Agent Email Style," "Company Name Style," and "Company Address Style." All of these settings will include Font Weight, Font Size, and Font Color as seen here:

You can also add your own disclaimers to your footer by inputting any text or external links. Up to five disclaimers can be added to the footer. The disclaimers will be displayed under the agent info when using styles 1, 2, or 3 and under the sitemap when using style 4.

### Removing or Hiding the Footer

For some pages, you might want to keep the footer from appearing in order to keep site visitors focused on the content of the page and avoid giving them access to additional content right away.

*IMPORTANT : With the footer, you need to be careful about when to hide it because it could take you out of compliance with your MLS.

In order to remove or hide the footer, you will want to access the page editor and then select "Pages" in the top-left:

You will then select the "cog wheel" edit icon next to the page where you want to adjust this setting.

You will then be able to edit the setting for "Page Style" where you can choose whether the header and footer display or maybe just one or the other.
