## Body

## Introduction

IMPORTANT: Facebook Messenger is currently unavailable.

Facebook Messenger is a very common messaging platform used by many of the people who you will be interacting with as leads on your Lofty website. If you would prefer to use Facebook Messenger instead of the Lofty Chat Box (see Chat Box Settings ), you may do so.

*IMPORTANT : Conversations that take place via the Lofty Chat Box feature will be synced to the lead's profile in Lofty and sent to the client via text message if they have provided a mobile number. However, if you use Facebook Messenger instead, these messages will not sync with Lofty at all.

## Facebook Page Setup

The first step is to create a "Page ID"

Log in to your Facebook account and find the Group section on your left-hand side.

Once in the Groups section, click on “Create new group”

In this section, you can choose a group name, and group privacy, and optionally invite friends to this group.

To have your group easily accessible. Click on the 3 dots when viewing the group page, and from here select pin group.

Now when logging into Facebook you can see the group from the home page.

To find the page ID you must enter into your created group page. From here you can select numbers appearing in the URL at the top of your screen. (Please note you only need to select the number, not the /.)

Add Lofty Site to Facebook Messenger SDK Whitelist

You will need to add your website domain in order for Facebook Messenger to function and trigger on your Lofty IDX site.

First, go to the "Page Access" page in the Professional dashboard (only accessible to the business page owners).
Then go to "advanced messaging" to add the "whitelisted domains" in the text box.
## Lofty Setup

The Lofty setup steps are outlined in the following article: Chat Box Settings > Facebook Messenger .
