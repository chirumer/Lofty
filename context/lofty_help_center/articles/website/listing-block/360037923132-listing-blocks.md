## Introduction

The "Listing Block" can be used to embed a specific selection of listings on any page that you build. This can be ideal to feature your listings, office/brokerage listings, or a specific type of listings. These blocks are added by default to the Home Page as well as on Neighborhood Pages. The instructions to use this block type are found in this article.

## Adding the Listings Block

To add the "Listings Block," navigate to the page where you would like to add it and then click on the "+ Blocks" button:

Drag the type of the "Listing Block" that you would like to add to the right side where you would like it to appear on your web page.

## Editing the Listings Block

To edit the settings for this block, double-click on the block or click on the "Edit" icon in the top-right of that block:

### Style 1

The first style looks like this:

In this style, the first thing to edit is the maximum quantity to display in this section before clicking on the "MORE LISTINGS" button:

You can then choose to select the listing source (All Listings, Sold Listings, Use Custom Listing Filter), any preset filters, and default listing sort.

You can also define what the text will say in order to view more listings (typically "View More Featured Listings"), the default view pattern (Grid, List, Map, Map+Grid, Map+List), map center point, default zoom level, and threshold for listings grouped on the map.

### Style 2

This is what the second style looks like:

In this style, there are three different versions that can be selected (V1, V2, V3) that will vary slightly in their appearance, the title can be defined as well as a description that will appear below the title. The maximum quantity to display can also be customized.

Then, just like mentioned in Style 1, you can adjust the listing source, preset filters, default listing sort, text for more listings, view pattern, map center point, zoom level, and threshold for grouping listings on the map.

### Style 3

Style 3 looks like this one here:

The settings to edit on this style are the same as with Style 2. There are more styles added to choose from shown below.

## Listings + Filters Help

For more information regarding how to set up the listing filters, please reference these articles: Listing Filter Basics and Advanced Control Panel for Agent/Office Criteria .

*IMPORTANT : Please note that selecting a specific listing source for a block will not affect the search results that a site visitor will see if they type into the search bar. In other words, the results populated by using the search bar on these blocks are not filtered by the custom listing filter (if selected).
