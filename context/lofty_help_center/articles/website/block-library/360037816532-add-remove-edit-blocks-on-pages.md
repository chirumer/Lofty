# Add / Remove / Edit Blocks on Pages

- Article ID: `360037816532`
- Category: `Website`
- Section: `Block Library`
- Updated: `2026-04-15T18:41:00Z`
- Source: https://help.lofty.com/hc/en-us/articles/360037816532-Add-Remove-Edit-Blocks-on-Pages

## Body

## Introduction

All pages on Lofty websites are composed of blocks. These "blocks" can be combined to build pages with a specific content focus or to provide a certain set of resources to site visitors. These blocks can be customized on every Lofty website page.

## Summary

## Step 1: Select the Page to Edit

Click Pages on the Page Editor and a page list will appear with all of your pages shown. Find and click on the page you want to edit and the Page Editor's interface will switch to that page.

### Add Blocks

Click Blocks in the Page Editor, and the block library will appear. 20+ block types can be added to any page by dragging and dropping the block to the right: the type has different styles to choose from.

### Edit Blocks

If you want to modify the title, image, data, etc. of a certain block, double-click the block or click the Edit icon that appears when hovering in the top-right of that specific block. Upon doing this, all of the content that can be edited with this block will be displayed.

### Block Types

The following are the different types of blocks available:

- Reviews
- Agent
- Contact
- Team Info
- Featured Areas
- Partner Links
- Form
- Hero
- Home Evaluation
- Calculator
- Banner
- CTA
- Content
- Listings (Featured)
- Search Bar
- Quick Search
- Blog
- Video
- Live Blocks YouTube Live Block Facebook Live Block

### Custom Blocks

Note: Custom blocks can only be created if your website is built off of a custom template. If your website was built off of one of the website templates that Lofty provides, the option to create a custom block will not be available.

To create a custom block, first add a block to your website by dragging the block to the body of the website. Make any necessary edits to the block and click the ... icon and select Custom

Note, not all blocks can be customized. Only the following blocks can be customized:

- Agent
- Banner
- Content
- CTA
- Embed
- Form
- Gallery
- Team
- Video

After you have saved your custom block, it can be found at the top of the Block Library in a section called Custom.

### Remove Blocks

If you need to delete a block, hover over that specific block and click the Trash Can icon in the top-right of that block.

### Reorder Blocks

You can drag a block to the desired position by clicking on that specific block until it is highlighted and then dragging it to the new destination on that page. You can also reorder by selecting the icon with three lines and dragging it to the spot where you would like it on the page:

### Copy Blocks

If the block has the capability to be Copy/Pasted, you will see a ... icon next to the other block actions. Click the ... to select Copy or Paste. The block will be copied as is. When you paste a block, it will be pasted directly below the selected block. This is only available to full websites, not to users with subdomain sites.

Note, not all blocks can be copied. Only the following blocks can be copied:

- Agent
- Banner
- Content
- CTA
- Embed
- Form
- Gallery
- Team
- Video

### Preview

You can toggle between the desktop view and the mobile view to see what the page will look like on a mobile device versus a laptop or desktop computer.

If you need to experience the effects of button jumps and pop-ups triggered by the website, you can click the preview button to open a new tab that will preview this page.

### Publish

If you have made any changes on this page by adding, removing, or editing any blocks, be sure to click the Publish button in the top-right corner in order for changes to apply to the live site.
