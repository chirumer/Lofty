## Body

## Introduction

This block can be used to display market trends based on data from listings that were sold in the last 12 months. You can add this block where you would like on your website using the CMS. It is also present by default on the Listing Detail, Neighborhood, and Market Snapshot pages.

## Summary

- Adding a Market Trends Block
- Editing the Market Trends Block

## Adding a Market Trends Block

Open CMS > Page Editor > + Blocks :

Navigate to Market Trends and drag the style that you would like to use to the right side where you want it to display:

## Editing the Market Trends Block

The Market Trends block is displayed by default on the Listing Detail, Neighborhood, and Market Snapshot pages. You can navigate to one of those pages or find the Market Trends block wherever else you have placed it when Adding a Market Trends Block . Then, double-click on the block or click on the "Edit" icon:

### Listing Search

#### Preset Filter

In order for the Market Trends block to display data, a site visitor must input some sort of search criteria. If you would like to pre-populate search criteria, you can use the Preset Filter field to do so. Please note that any search criteria added to the "preset filter" field will be reset by site visitor actions in the search bar on this page.

This behaves just like a search on the website (for sold listing data, of course) where you can add criteria for locations, prices, beds, baths, property types, and more. This will be displayed by default on this block but a site visitor can erase the pre-populated criteria and add their own if they would like:

#### Require registration to view actual data
