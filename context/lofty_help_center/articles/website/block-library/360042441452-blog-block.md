## Introduction

The "Blog" block is a simple extension of the Blog Page in that it points site visitors to the blog posts and additional articles.

For more information on how the Blog Page works, please reference the following: Blog Page .

## Adding the Blog Block

To add the "Blog" block, open the Block Library by going to the CMS Tool > Editor > Click on the "+ Blocks" button on the left side :

From this page, navigate to the Blog block type and select the style that you are interested in.

Drag the block to the right side of the screen--to where you want it placed on the page:

## Edit the Blog Block

To edit the "Blog" block, simply double-click on the block itself or click on the "Edit" icon with that specific block:

You are only able to edit the title of the block, change the style, or add spacing before or after. You can also now choose which categories you want to display within that block.

These categories are assigned when creating blog posts.

Your blog posts will display in the same order they appear within the posts list within the CMS settings. You can pin one post to the top, or you can sort the posts by published date or updated date to have those appear in that order automatically.

The blog posts that are shown will be the most recent three posts from the Blog Page.
