## Body

## Introduction

The Agent Block allows you to present specific team members on specific pages. This is a great way to showcase the talent available on your team to build confidence for all potential and current clients.

## Adding Agent Block

Click Blocks on the page editor.

Find the agent block in the block library. Choose the style that you want and drag it to the page on the right side of the CMS Tool.

Double-click the agent block or click the Edit icon on the top-right of that specific block and all of the content that can be edited with this block will be displayed.

Before clicking on Add Agent , be sure that you have already added the agent(s) in Settings > Organization Info > Agents (see Website Team Info ). Once they have been added here, they can be added to this block.

The next step is to select the agent profiles that you want to display or toggle on the Display All Agents setting to show all of the agents in your organization.

After completing the rest of the configuration, don't forget to click Publish in the top-right of the CMS Tool for all changes to apply to the live website.
