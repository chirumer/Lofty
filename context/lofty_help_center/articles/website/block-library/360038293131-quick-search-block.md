## Introduction

The "Quick Search Block" is a useful spot to outline specific filters that you have built out and want to put together in a list that displays well on any page. This article outlines the settings that can be adjusted with the quick search block.

There are a few important things to keep in mind with the Quick Search Block:

1. You can choose any search list in the Quick Search Block wherever you created it, and the same quick search list and corresponding data can be used regardless of the style or page where you add this block.
2. In most instances, Lofty suggests that you use the "Preset Filter" to help you populate the listings for your quick search links and keep the listing source set to "All Listings" unless you want to limit the searchable listings in the link. For more information on filters and listings, please reference this article: Listing Filter Basics .

## Adding the Quick Search Block

To add the "Quick Search Block," navigate to the page where you would like to add it and then click on the "+ Blocks" button:

Drag the type of the "Quick Search Block" that you would like to add to the right side where you would like it to appear on your web page.

## Editing the Quick Search Block

To edit the settings for this block, double-click on the block or click on the "Edit" icon in the top-right of that block:

## Quick Search List

Users can build quick search lists that they can reuse or keep independent from one another.
Users can add a new quick search configuration in the Quick search list, give it a name, and then define the links that will be saved and synced anywhere else that this specific configuration is selected:
Also, users remove any existing quick search configurations or choose an appropriate existing quick search configuration from the quick search list and add it to the corresponding page.
## Quick Search Configuration Editing

For the quick search configuration, in the quick search list, you can edit the title:

Under "Link Management" you have the option to define the links that will display under the "Quick Search" menu on this block.

Clicking on "+ Add Quick Search Link" will take you to this menu where you can define the link name, the listing source (All Listings, Sold Listings, or Use Custom Listing Filter), preset filters, and default listing sorts. There is no limit on the number of links you are allowed to create.

You can also select a specific "View Pattern" for each link. This will adjust how a lead views the listing pages when they click that specific quick search link, not how the quick search link displays.
