## Body

## Introduction

This block type was designed support the addition of vendors on Lofty-built websites. This block type was designed to display vendors/partners and their contact information, etc. directly on your Lofty-built website to make their details accessible to site visitors.

## Summary

- Vendor Block Setup
- Vendor Block Sorting

## Vendor Block Setup

To add a new vendor, navigate to CMS > Settings > Team Info > Vendors > + Add a Vendor :

The following are the fields that can be added to a vendor profile. Company Name is required but you will definitely want to provide as many details as possible.

To add a vendor category, click on the settings cog wheel. You can edit, reorder, and delete the categories as needed.

Next, to add the block, navigate to the Page Editor > + Blocks > Vendor > Drag the block where you would like to add it on the page:

Below is how it is displayed on the website. All vendors added via the settings will be displayed within this block and can be searched. You are not currently able to choose only certain vendors to display in specific blocks of this type, it's all or nothing.

When a vendor profile is clicked, it will redirect to their website.

## Vendor Block Sorting

As of July 19, 2021, the Vendor Block supports creating a default sort method for the block. This is done by editing the vendor list under CMS > Settings > Team Info > Vendors , dragging/dropping to reorder, or clicking to move one to the top of the list. In other words, the order of vendors can be customized in the CMS settings.

When editing the actual Vendor Block, there is a switch. By default, the switch will be ON which means vendors in that block will be sorted A-Z. However, if you turn the switch OFF , the sorting order will reflect exactly what was configured above in Settings > Team Info > Vendors instead of being alphabetical.
