# Featured Areas Block

- Article ID: `360037923152`
- Category: `Website`
- Section: `Block Library`
- Updated: `2025-11-11T02:49:57Z`
- Source: https://help.lofty.com/hc/en-us/articles/360037923152-Featured-Areas-Block

## Body

## Introduction

The "Featured Areas" block is used to display a selection of pre-built neighborhood pages on a specific part of a page.

## Summary

- Import the Area you Need
- Add Featured Areas Block
- Edit Featured Areas Block

## Import the Area you Need

Choose the area you need by navigating to
Settings>Featured Areas
in the CMS tool and apply it in
Add / Edit Featured Area Pages or Groups (https://help.lofty.com/hc/en-us/articles/360037816512)
or
Featured Areas Block (https://help.lofty.com/hc/en-us/articles/360037923152)
.
Click the "+ Add New Area" button:
Use the search bar to type in the area you want to add：
Select all areas you need and click "OK" to get to the next step. If the button is unclickable and grayed out, you have already added this area.
The newly added areas will automatically generate an introduction page, which will be adjusted to the most suitable page style for your website, but they will not appear on your site unless you add the corresponding pages or blocks.
Use the search bar to locate the area you added and use the three buttons to the right of the area display row to customize or delete it.
Learn More:
Add / Edit Website Pages (https://help.lofty.com/hc/en-us/articles/360037816472)
.
1. Customize the page
2. Edit the page settings, i.e. Page name, URL, open style
3. Delete the Featured Area
## Add Featured Areas Block

In the CMS tool, navigate to the Page Editor and click on the "Blocks" option:
Find the featured areas block in the block library. Choose the style that you want and drag it to the page on the right side of the CMS Tool.
Double-click the featured areas block or click the "Edit" icon on the top-right of that specific block.
All of the content that can be edited for this block will be displayed:
Locate the area you want to add by using the search bar in the "Featured Area" section and select it by clicking the box next to it.
## Edit Featured Areas Block

You can edit, delete, or change the display order of the Featured Areas.
1. Edit the displayed name, upload an image, or add a tag
2. Delete the Featured Area
3. Change the display order
The page design of the area you need to update cannot be changed directly in the block. Navigate to
Settings>Featured Areas
to edit.
Refer to
Add / Remove / Edit Blocks on Pages (https://help.lofty.com/hc/en-us/articles/360037816532)
for the best instructions on how to change the page Style.
After completing the page setup and customization, don't forget to click the "Publish" button in the top-right of the CMS Tool for the changes to apply to the live website.
