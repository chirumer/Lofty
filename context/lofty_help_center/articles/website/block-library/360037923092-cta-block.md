## Introduction

CTA stands for "Call To Action" and is well-known among those with experience building websites. A CTA is used to encourage site visitors to visit specific pages and act on what is being suggested to them. The Lofty block library has several types of CTA blocks that can be used on any page. This article explains how these blocks work and can be added/edited via the CMS Tool.

## Summary

- Adding a CTA Block
- Editing a CTA Block

## Adding a CTA Block

First, from the Page Editor, click on the "+ Blocks" button.

Choose the CTA option from the library and then drag the desired style to the right side where you would like to place it on the right.

## Editing a CTA Block

To edit a CTA block, double-click on the block or click on the "Edit" icon in the top-right of that block.

### Edit Options

When editing a CTA block, the configurable options will vary depending on the style of the block . Across all CTA block styles, you will see a mix of the following settings that can be adjusted:

- Background Desktop Image Mobile Image Background Type Color Image Border Color
- Block Size Desktop Size Type Height Mobile Size Type Mobile Height
- Style Add spacing before/after the block
- Opacity Layer Show Opacity Layer Vertical Margin Horizontal Margin
- Heading and Description Heading Description
- Button Action Type URL Your site visitors will be redirected to a different URL when they click the button. Please note that if you just want to redirect the visitor to a page on your Lofty site, you only need to enter the "relative URL." For example, enter "/evaluation" to send the site visitor to the Home Evaluation page. If you want to redirect the visitor to an external page (one not part of your Lofty site), you will need to enter the complete URL including https:// (e.g. https://www.google.com/ ). After entering the URL, you can also choose your "Open Mode" to open the page in a new window/tab or open the page in the current window/tab. Trigger Registration Set the lead type using the Lead Type Settings dropdown menu for this action type. When your site visitor clicks the button, the site global registration pop-up will appear. See Registration Pop-up Style & Settings . Text Color Button Position

The best way to learn about all you can do with a CTA Block is to test it out on your website. The visual builder gives you a great preview that can be used to see how it will work on your website. If it doesn't work out, you can always delete the block and try again.
