## Body

## Introduction

This feature is designed to allow Lofty users to add a YouTube Live stream block to their Lofty website.

## Summary

- Schedule a YouTube Live Stream
- Add the YouTube Live Block
- Edit the YouTube Live Block

## Schedule a YouTube Live Stream

Before you start, make sure that you have a YouTube livestream scheduled and that you have the URL to the live stream ready to go.

- Click HERE to learn how to schedule a YouTube Live stream
- Another useful video on this topic can be found HERE

Be sure to click the "share" button and then "COPY" so you can grab the stream URL and add it into Lofty later in the CMS Tool.

## Add the YouTube Live Block

Click “+ Block” to open the Block Library.

Find the "Content" category and then select Media, then look for the YouTube version, and then drag it to the position where you want to add it on the page:

## Edit the YouTube Live Block

Double-click the YouTube Live Block or click the "Edit" button. The following are the options that can be edited on the YouTube Live block:

1. Live Name . This is the title of the block.
2. Live Description . The description of the block.
3. Live Embed Type . Choose the integrated type for the YouTube Live Block. Live Embed Code : We do not recommend choosing this option. Live URL : Paste the YouTube Live URL that you copied in the "Schedule a YouTube Live Stream" step.
