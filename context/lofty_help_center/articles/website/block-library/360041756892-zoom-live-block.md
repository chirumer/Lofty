## Body

## Introduction

This feature is designed to allow Lofty users to add a Zoom Live meeting block into their Lofty website.

## Add the Zoom Live Block

Click “+ Block” to open the Block Library.

Find the "Media" category and then select the option for Zoom, and then drag it to the position where you want to add it on the page:

## Edit the Zoom Live Block

Click the edit button in the Zoom Block section to add the Live Name, Live Description, Zoom Integration details, and meeting settings.
