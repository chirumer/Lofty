## Introduction

When building your online presence with Lofty, you have three main website options. Each serves a different purpose and offers varying levels of customization, branding, and SEO capabilities. This article covers what you need to know.

## Summary

- Agent Websites
- Vanity Domain Sites
- Full SEO Sites
- Quick Comparison Table
- Which Option Should You Choose?

## Agent Websites

What it is: An Agent Website is the most basic option, designed to give agents a quick and easy way to establish an online presence. These sites are typically created automatically when an agent activates their Lofty account.

Agent Websites are a carbon copy of its parent website.

Key Features:

- Domain: Uses a subdomain, like firstname.companyname.com.
- Cost: Included at no extra charge.
- Customization: Limited. You can edit basic elements like the header and hero section but cannot add custom pages.
- MLS Integration: Inherits MLS feeds from the parent site (Full SEO Website).
- SEO: Minimal. No individual SEO optimization tools.

Best For: Agents who need a simple, functional site without investing in branding or advanced marketing features.

## Vanity Domain Sites

What it is: A Vanity Domain upgrade allows you to replace your subdomain with a custom domain, like yourname.com. This is a branding enhancement that makes your site look more professional and easier for clients to remember.

Vanity Domain Sites start as a carbon copy of its parent website, but have a custom domain and can be edited.

Key Features:

- Domain: Custom vanity domain.
- Cost: $20/month.
- Customization: Moderate. You can edit navigation, add custom pages, and personalize templates.
- MLS Integration: Inherits MLS feeds from the parent site (Full SEO Website).
- SEO: Basic SEO tools available, but not as comprehensive as Full SEO sites.

Best For: Agents who want their website to reflect their branding, without customizing an entire website.

## Full SEO Sites

What it is: A Full SEO site is the premium option for agents serious about online marketing. It includes advanced SEO tools, full customization, and enhanced MLS integration.

Full SEO Sites are completely unique and designed by you.

Key Features:

- Domain: Custom vanity domain required.
- Cost: $79/month.
- Customization: Fully editable. Custom pages, blogs, featured areas, scripts, and styles.
- MLS Integration: Must complete MLS applications.
- SEO: Comprehensive SEO checklist, meta tags, keyword optimization, and blog capabilities.

Best For: Agents who want to maximize lead generation, improve search rankings, and build a strong digital brand

## Quick Comparison Table

Feature | Agent Website | Vanity Domain Site | Full SEO Site
Domain | Subdomain | Custom Vanity Domain | Custom Vanity Domain
Cost | Included | Paid Upgrade | Premium Upgrade
Customization | Limited | Moderate | Full
SEO Tools | Minimal | Basic | Advanced
MLS Integation | Inherited | Inherited | Application Required

## Which Option Should You Choose?

- Agent Website: If you need a quick, no-cost solution.
- Vanity Domain Site: If branding and professionalism are priorities.
- Full SEO Site: If you want maximum visibility, lead generation, and customization.
