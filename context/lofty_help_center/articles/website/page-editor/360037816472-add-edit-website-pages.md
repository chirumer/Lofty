## Introduction

Lofty provides a library of page templates to speed up the construction of your professional website. These page templates can serve as a foundation that can then be edited and rearranged according to the theme you are looking to present on your site.

## Add a Page

To add a page, click on the “Pages” button while in the Page Editor

Then, click on the "+ Add Page" button.

You will then need to select a page template. There are currently 12 types of page templates (more on the way). You can choose the template that best matches what you need to accomplish.

Current page templates include the following:

- Home
- Listings
- Sell
- Home Evaluation
- Reviews
- Neighborhood Detail
- About
- Contact
- My Team
- Mortgage Calculator
- Affordability Calculator
- Blank
- Link

After you have selected the page, you will need to configure the page settings. There are two parts to this process (three if doing a neighborhood page). . .

### Part 1: Basic Settings

The following are the options that can be configured in the "Basic Settings" section. Default values are provided by Lofty, but you can modify them as needed.

Page Name : The name of the page that will be displayed on the CMS Tool and the website to distinguish it from other pages.

Page Template : This section will simply display the page template that was selected in the previous step. You can also return to the previous step and select another one by clicking on "Change it."

URL : Define the URL for this page.

Open Style : Configure whether the link, when clicked, will open on the "Current Page" or as a "New Page."

Display Style : Configure whether to show on desktop or mobile view.

Page Style : Setting to turn on/off page header and footer.

There is also a setting to hide a page on all Agent Subdomains (see Agent Subdomains ). This option will only be available if the page can be hidden. Please note that the following pages cannot be hidden on Agent Subdomains:

- Home
- All Listings
- Sold Listings
- Home Valuation
- Blogs
- Market Snapshot
- Listing Detail Pages
- Agent Detail Pages
- Blog Detail Pages

You may consider using this checkbox if you have a page that makes sense at the Team Website level but does not work as well on an Agent Subdomain. The setting is all or nothing--you are not able to choose which Agent Websites are affected.

### Part 2: Page SEO

This section can be used to configure the meta title, meta keywords, and meta description of this page. This section also has support for inserting variables (merge fields). As the CMS-related values change, these meta fields can change automatically.

The "SNS Cover Photo" is the image that is displayed when sharing the link on platforms such as Facebook, etc.

In order to improve your website's SEO, it is recommended that you configure different content on different pages. You will also want to keep the meta content highly summarized. If you want to learn more about meta tags, please reference Edit Website Meta Tags .

### Part 3: Neighborhood Data

*This section will only appear if you select the "Neighborhood Detail" page template.

More information about configuring this section can be found here: Add / Edit Neighborhood Pages or Groups .

---

*The final step is to click on the "Save" button. Please note that all added pages/folders will be located on the "Hidden Navigation" by default. See this article for more information on editing the navigation: Edit Website Navigation Bar .

## Edit a Page

If you want to adjust the page style, please refer to Add / Remove / Edit Blocks on Pages .

If you want to modify the content of the page, click on the "Edit" icon on that page.

## FAQ

Q: Is there a character limit when adding a Page name?

A : Yes, 50 characters maximum.
