# Add / Edit Featured Areas

- Article ID: `360037816512`
- Category: `Website`
- Section: `Featured Area`
- Updated: `2026-04-15T17:38:40Z`
- Source: https://help.lofty.com/hc/en-us/articles/360037816512-Add-Edit-Featured-Areas

## Body

## Introduction

Lofty supports creating a landing page to feature each area in your market to attract more leads using auto-populated local information. Different featured area pages have the same style with content related to that area. Creating them one by one could be a lot of work, so the CMS Tool also supports simultaneously creating a group of featured area pages.

## Summary

- Add a Featured Area
- Add a Featured Area Page to your Website
- Edit a Featured Area Page

## Add a Featured Area

Navigate to the CMS and select Areas .

Click the
+ Add New Area
button and pick
City
or
Neighborhood
.
The cities and neighborhoods available are dependent on the connected MLSs. Use the search bar to type in the area you want to add.
Select the Agent who represents this area.
#### Featured Area Pages

After the city/neighborhood has been added, 2-3 pages will be created.

##### Introduction Page

The Introduction page includes a description of the area, market trends, current listings, amenities and attractions, schools and demographics.

Note: If the region selected lacks data, the Introduction will not be displayed.

##### Search Page

The Search page lists the homes for sale in the selected area and market insights.

##### Market Page

The Market page provides a market snapshot, market trends, and recent listings.

## Add a Featured Area Page to your Website

Navigate to the Page Editor and click on the
Pages
option.
Click the
+ Add Page
button and select the
Featured Area
page template.
Select a style and click
Next
. Locate the area you want to add using the search bar and choose it by clicking the box next to it. You can also click the top box to select all areas.
The introductory page navigation for any areas you have chosen and saved will display under
Page Editor>Pages>Hidden Navigation
and can be personalized like other pages.
To display the area in the navigation bar menu, hover over the box corresponding to the area, click, and hold while moving the pointer to the related folder like "Neighborhoods".
After completing the rest of the configuration, don't forget to click the "Publish" button in the top-right of the CMS Tool for the changes to apply to the live website.
## Edit a Featured Area Page

If you want to adjust the page style, please refer to
Add / Remove / Edit Blocks on Pages (https://help.lofty.com/hc/en-us/articles/360037816532)
.
*IMPORTANT
: Please note that if you edit a Featured Area page group, your modifications will apply to all Featured Areas in this group at the same time.
If you want to modify the content for the pages you just configured, you can click the
Edit
option next to the Featured Area that you want to edit.
