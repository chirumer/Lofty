## Body

## Introduction

Meta tags are snippets of text that describe a page’s content. The meta tags do not appear on the page itself, only in the page’s source code. Meta tags can help Google and other search engines understand your content and thus help your SEO ranking if adjusted correctly.

Lofty supports the ability to configure the meta title , meta keywords , and meta description for each page.

## Meta Title

This is the text you will see at the top of your browser. Search engines view this text as the "title" of your page. These tags have a real impact on search rankings and allow visitors to easily distinguish your site from others.

## Meta Description

Meta Description is a brief description of the page and, put simply, explains to search engines and (sometimes) searchers themselves what your page is about. Please note that the meta description tag will not always show up in the results of a Google search.

### Meta Keywords

Meta Keywords are a series of keywords you deem relevant to the page in question. Nowadays, they are not as useful as they once were. They no longer provide any real benefit for SEO.

Even though Lofty supports the ability to configure meta keywords, we do not recommend that you configure them.

### Editing Meta Tags

First of all, find the page that you want to edit on your CMS Tool navigation and then click on the "Edit" icon:

From this section, you can configure the "Page SEO" which includes the meta title, meta keywords, and meta description of the page. This also supports the insertion of variables (merge fields) that will update automatically with adjustments via the CMS Tool.
