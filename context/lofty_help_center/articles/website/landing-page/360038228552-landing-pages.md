## Introduction

"Landing Pages" are a single page created specifically for marketing and advertising to bring leads in and get them to register. With the Lofty CMS, the ability to create high-quality landing pages is quick and easy to access.

All users on a Lofty account with an IDX website can access landing pages. A gents without a website will use the Team or Company Website to build landing pages. These users can create up to 10 landing pages. If the limit is exceeded, the user will need their own agent website or subdomain to create more landing pages. All leads captured on these landing pages will be assigned directly to the agent who created the page. The account admin can disable the user's access to build landing pages by turning off the Landing Page permission (see Organization - Permission Profiles ).

## Adding Landing Pages

I want to let you know that the Landing Page functionality is not found directly in the CMS Tool. Instead, it is located in the "Marketing" section of Lofty.

Click on "Landing Pages" from the options available on the left and then click “Add a New Landing Page” to start building a page:

The first step is to choose a page template to use. Page templates provide the basic page skeleton for you to edit and will also provide default blocks and content on the new landing page that you create.

Available Templates:

1. All This is all of the Landing Page templates
2. Listing Includes the following: Feature a Listing New Listings Open House Listings Price Reduced Listings Listing Search Campaign Multi-Property with Map
3. For Seller Includes the following: Home Valuation New Seller Form Seller Guide Download
4. For Buyer Includes the following: Featured Area Page Buyer Guide Download Live Tour (Standard Listing) Host a Live Tour
5. Activity Includes the following: Lead Registration Form Meeting with leads Build Your Own

The next step is to enter the page URL / Page Name / Lead Source according to your preferences and campaign goals. The leads registered on this page will be added directly to the Lofty CRM and classified into the source defined in this setting. All of these fields can be modified later when editing the page.

Click "Save" and you will then be taken to the new landing page:

## Automatic Landing Pages

Automatic Landing Pages are a feature that creates landing pages every time a new listing is added to the MLS. This requires that your Agent ID be added to your integrated MLS. It is also required to have an active Lofty website as well; this can be a team website, an agent website, or an agent subdomain. When a new listing is created, it will be generated as the "Single Property Promotion" template.

You will also receive an email alerting you to the creation, and also with the link to the new landing page.

To distinguish these from other pages in your Tools section. The automatically created listing will have an "A" icon at the end of the name of the landing page that was generated.

You can disable this feature if needed at Marketing> Landing Pages> Settings

## Recommendations

A list of recommended (commonly used) landing pages is available at the top of the page. A landing page can be created directly from this list by clicking the button below the desired option. This menu can be hidden if no longer helpful.

## Editing Landing Pages

In the interface to the edit page, you will see three floating icons on the left (Settings, Style, and Block Library, SEO):

### Settings

In this section, you can configure the following:

- Basic Info Basic Settings: Page Name URL Page Style Lead Source Lead Type (leads who register on this page will come in as this type) Lead Privacy and Assignment Lead Privacy (see Lead Privacy: Team Leads vs. Private Leads ) Assignment Method (Directly Assign vs. Assign via Lead Routing Rules) Additional Actions Tag Note Send Welcome Email (yes/no) Send Welcome Text (yes/no) SEO Meta Page Title Meta Page Description SEO Cover Photo (what displays when sharing a link to social media) Chat Box Show Chat Box (yes/no)
- Page Tracking Google Analytics Account Facebook Pixel ID

### Style

In this section, you can edit the theme color, title style, and button style of your landing page.

- Theme Color . This consists of two parts: (a) primary color and (b) hover color. This includes all colors except the title and buttons. The primary color is the default color for most elements on a website. The hover color is the hover color of all clickable elements on the website.
- Title Style . You can edit the title style of all blocks
- Button Style . You can edit the style of all the buttons

### Block Library

20+ block types can be added to any page by dragging and dropping the block to the right side. Each block type has different styles to choose from. If you want to modify the title, image, data, etc. of a certain block, double-click the block or click the "Edit" icon, and all of the content that can be edited on this block will be displayed.

For a full list of the blocks and how to use them, see this section in the Help Center: Block Library .

You can drag a block to the desired position by using the arrow icon.

When finished with editing, always remember to click on the "Publish" button in the top-right in order for changes to be reflected on the live website.

## Sharing / Using Landing Pages

### Share on Social Media (Facebook, Twitter, LinkedIn)

Whether you are on the interface to edit the page or on the page list, you can quickly share your landing page to Facebook, Twitter, and LinkedIn by clicking on the "Share" icon:

### Share via Link

The direct link to the landing page can be copied and used in an ad campaign or on other social media platforms not currently supported to drive traffic to the landing page and obtain visitor registrations.

### Share via Email/Text

On the Landing Pages section of the Marketing page, you can click on the "send" option to share the landing page directly to leads via email or text:

Upon clicking on the option to send a page, you will be able to filter out leads (200 at most) and send them via email or text:

### Share via Chat

Click the LP icon to send a landing page to a lead directly via chat in the web or mobile apps. Use the search bar or filter to find the landing page you want to send.

## Registration Rules

Landing page registration settings have been set up to make the transition to a redirected page work more smoothly. With this setting, the registration rules of the landing pages, a user can configure where registration is triggered.  This will allow users to better control the registration pop-up on this transition.

*IMPORTANT : Please note that if you plan to test the registration rules (which is always a good idea), be aware that having the main IDX website and a landing page open at the same time and in the same browsing session, etc. will likely cause a conflict. Be sure to test using a new incognito window each time you test or be sure to clear the browser cache and cookies.

## Viewing Conversion

You can view the conversion details and lead activities on each landing page directly on the list interface as seen below. The overview is not currently clickable, but you can filter by "Lead Source" or "Tag" directly on the People page if you have set those to register specifically for a landing page.

## FAQs

Q: Sounds like the 10 Landing Page limit is in place for users with NO website, and either a subdomain or website user can have more than 10.

A: Yes, users with a subdomain or website can create unlimited Landing Pages.

Q: When building an Open House Landing Page, how does Lofty define “this week” (Sunday–Saturday or Monday–Sunday)? A: When "This week" is selected, the search will show properties listed as available this week. The time range for "this week" is from Sunday to Saturday.

Q: If an admin logs in using the main account to create a landing page for a subdomain, will the setting be available like the ones in the parent site? A: Landing pages created in the parent (main) site cannot be directly synced or copied to subdomain sites. Each subdomain’s landing page is managed separately.

Q: Is the build your own page option available for all packages?

A: The "Build Your Own" option is NOT available for all packages. The ability to create a blank landing page (i.e., a fully customizable landing page where you can add/remove blocks as you wish) is only available on upgraded website packages. Specifically, this feature is included in:

Vanity Domain Website

Full SEO Website

Team Website (with upgraded package)

Company Website (Enterprise, with upgraded package)

It is NOT available on the basic/free/agent website, only packages. Users on these entry-level packages do not have access to the blank landing page option or are limited to pre-set templates with minimal customization.
