# Custom Website Fonts

## Body

## Introduction

It is easy to change fonts on your Lofty-built websites. Below the steps to change this are highlighted in two ways.

## Summary

### Custom Website Fonts

You can upload custom fonts to your Lofty website or choose from the 28 most popular fonts provided by Google.

### Popular Fonts

There are two ways these fonts can be applied to Lofty websites.

#### Global Site Font Modification

To edit fonts for the entire website, navigate to Page Editor > Style > Font .

From here, the 28 different fonts can be selected. Once edited, all text on the website will be changed to this new one. If an individual block (see next section) has already had the font edited, then that block's font will not be updated by this global setting–the individual block's settings always take priority.

#### Individual Block Font Modification

Every individual block and/or location that allows for text style modification within the Lofty CMS will also allow for the Font to be customized after this update. This includes website headers, footers, blog posts, and other text content.

### Upload Custom Fonts

You can now upload custom fonts to use on your Lofty website!

There are two ways these fonts can be applied to Lofty websites.

To find this new setting, navigate to CMS > Editor > Style > Font :

#### Global Site Font Modification

Use the primary Font option to select a font that you would like to use as a global font on your website:

Use the three drop-down menus to get very specific, if you would like to select a specific font in any of these locations and make it different from the rest:

- Titles
- Paragraphs
- Buttons

To upload a custom font you can either hover over the " ? " icon and select the hyperlink or when you are accessing any of the drop-downs on this settings page, click on the Upload Fonts button.

Before being able to upload, you must verify that you have the rights and permission necessary to use this font on your website. This is your responsibility to research.

Once you have uploaded custom fonts, they will be available to manage from this same location:

Before deleting a font, make sure that you are not using it anywhere on your website as deleting it could cause display issues. You will be prompted to confirm when deleting.

If you delete a font that is being used, the site will continue to use that font but it will no longer be displayed as an option to use elsewhere.

#### Individual Block Font Modification

Any custom fonts that you have uploaded will be available under My Fonts :

Custom fonts can also be utilized directly in individual blocks once uploaded.

*Please note* A maximum of five custom fonts can exist at the same time and they are limited to the CMS/Website.
