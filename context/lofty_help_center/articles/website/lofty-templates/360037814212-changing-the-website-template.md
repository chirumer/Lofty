# Changing the Website Template

- Article ID: `360037814212`
- Category: `Website`
- Section: `Lofty Templates`
- Updated: `2025-11-11T09:27:40Z`
- Source: https://help.lofty.com/hc/en-us/articles/360037814212-Changing-the-Website-Template

## Body

## Introduction

Lofty provides thirty-three (33 mobile-friendly website templates that are designed to load quickly, be optimized for SEO, and provide you with the flexibility you need to display your business. You first choose a template when you start your website for the first time on Lofty. However, if you would like to change this website template, that is also possible. Below are the template styles you can choose from:

Reliance, Hearth, Echelon, Primenest, Harmonia, Anchor, Nexus, Ambiance, Inspira, Elyssian, Serenity, Pinnacle, Prestige, Homestead, Apex, Azure, Elevate, Oakridge, Greenwood, Heritage, Verity, Skyline, Havenwood, Sundara, Serena, Aviara, Solace, Ember, Horizon, Lumina, Vista, Willow, Luxenest

## Steps

To change the website template, click “Style” in the Page Editor first.

In the Style tab, select Template . When you select another template, you will immediately see the website style change in the preview interface on the right. You can also switch between pages to see how the change applies to different pages. When changing templates, you may need to adjust some individual block styles to make everything look its best.

If you want to go back to the previous style, click the "Undo" icon on the top bar.

Always be sure to click the "Publish" button in the top-right for changes to apply to the live website.

Currently, we only support switching between default templates and do not support switching to a custom template.
