## Body

## Introduction

The messaging feature within the Lofty mobile app is intended to allow for Lofty users to communicate effectively with their leads as well as for Team Leaders, Brokers, Agents, Assistants, etc. to communicate with each other directly in Lofty.

- Chat/Text Leads Individually
- Chat/Text Leads via a Mass Message
- Chat with your Team
- Company Number and Calling/Texting Number

*All users must set up a text package with a virtual number in order for this feature to work . See How to Set up Call/Text Packages for more information related to that topic. To set your virtual number in the app, go to the App settings in the bottom right of the app, and select whether to use your virtual number or personal cell phone number to text.

## Chat/Text Leads Individually

*These messages will count towards your daily text limit.

1. Open the mobile app

2. Select the "messages" bubbles at the bottom of the page:

3. To start a new message click the "+" button in the top-right:

4. To send an individual message to a client, click on the "New Chat" option:

5. Tap on "Leads" to select the person you would like to send a message to:

6. Select the lead to whom you want to send a message:

7. Type an SMS message ( sending/receiving images is not currently supported ). You can also add tasks and appointments directly from this section as well. The leftmost icon allows you to choose from any text templates that you have access to.

8. Clicking on the "i" details icon in the top-right will allow you to see that lead's profile page:

### Chat/Text Leads via a Mass Message

* These messages will count towards your daily text limit.

*These messages will be sent as INDIVIDUAL conversations . When a lead responds, they will only respond to you. No recipients can see each other as they are all receiving a separate conversation from you.

1. Open the mobile app

2. Select the "messages" bubbles at the bottom of the page:

3. To start a new message click the "+" button in the top-right:

4. To send a mass message to multiple clients, click on the "Lead Mass Text" option:

5. Tap on "Leads" to select the people you would like to send a message to:

6. Select the leads to whom you want to send a message:

7. Type an SMS message (the sending/receiving of images is not currently supported). The leftmost icon allows you to choose from any text templates that you have access to. The "tag" icon will allow you to insert variables for lead names, etc.

8. Clicking on the "i" details icon in the top-right will allow you to see the details of that conversation to add/remove leads from the "group."

9. Adjust the group settings here:

## Chat with your Team

All users have to have a virtual number in order to be added to message groups (see How to Set up Call/Text Packages ).

*These messages will not count towards your daily text limit and are only available in the mobile app version.

Follow these steps to access and use this feature:

1. Open the mobile app

2. Select the "messages" bubbles at the bottom of the page.

3. To start a new Team Chat click the "+" button in the bottom-right:

4. Click on "Create Chat Group"

5. Choose the participants for your team chat:

6. Give the group a name and then click on the "Create" button

7. You can now send messages to your team members. You can send standard text messages, recorded messages, pictures directly from the camera, or uploaded images:

8. To edit the group, you can always click on the "i" icon in the top-right corner:

11. If you have your Google Calendar connected, you can also add tasks and appointments directly from these options while in the Team Chat:

10. You can (a) edit the group name, (b) add/remove members, or (c) Delete the group and leave it:

## Company Number and Calling/Texting Number

#### Company Number in Phone Settings

When accessing the phone settings via the Lofty mobile app, you can now view the Company Number.  If no Company Number is available, it will not be displayed on the mobile app.

#### Calling/Texting Numbers

With this update, you can now see exactly what Calling Number or Texting Number is being used to initiate the communication and can choose that option more easily depending on where the communication is starting:

- Lead Details Page Users can select Lofty virtual numbers (Company Virtual Number or Personal Virtual Number) and their cell phone number
- Chat Detail Page Users can select Lofty virtual numbers (Company Virtual Number or Personal Virtual Number)
- Call List Users can select Lofty virtual numbers (Company Virtual Number or Personal Virtual Number)
