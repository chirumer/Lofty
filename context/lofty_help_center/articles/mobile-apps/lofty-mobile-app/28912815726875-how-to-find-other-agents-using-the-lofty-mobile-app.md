# How to find other agents using the Lofty mobile app

- Category: `Mobile Apps`
- Section: `Lofty Mobile App`
- Updated: `2025-11-11T09:35:04Z`

## Body

## Introduction

Connect directly with other Real Estate Agents in your Lofty app! The Lofty mobile app allows you to search for and connect with other agents in your MLS. The ability to search for other agents and be found by other agents can be disabled in your Lofty mobile app settings.

This feature is not currently available in the Lofty web app.

## Find an Agent

To find a fellow agent in your MLS in the Lofty app, select the People icon and select Contacts . Here, you will see that your own team members and other contacts, like lenders, are already visible to you. To search for another agent, who does not have to be a Lofty user, click Find Agent and select them from the list.

Use the Location, With Listing, or Specialty filters or the search bar to find your friends. Adding a friend will send an invite to connect with the agent. They must agree to send any communication.

## Disabling this Feature

If you do not want to be able to search for other agents or be found via an agent search, navigate to the Lofty mobile app settings to disable these features. As a Lofty account owner, you can enable or disable these features for all the users on your Lofty account.
