## Body

## Introduction

This report is now available within Lofty to send to your seller leads. The Seller Report is intended to give the seller lead more information on what activities you are doing to market the property.

## Usage

For a Seller Report to be generated, the following criteria must be met:

- Lead Seller Lead Valid Email
- Lofty User Lofty IDX Website Active listings (including manual (pocket) listings)

To add a Seller Report to a lead, navigate to their lead profile and then get to the Engagement tab. Click on + New Report under the "Seller Report" heading.

First, select the listing:

Next, preview the Seller Report:

Then, configure the following:

- Email Subject
- Select a frequency
- Choose the schedule

After hitting Save, the system will suggest other features to enrich the listing:

Here is what the Seller Report email will look like:

- Traffic Overview Listing Page Views Favorites Potential Buyers
- Listing Activity A potential buyer registered via ___________ a promotional ad a social post a flyer a landing page an open house form a text code
- Agent Activity Agent Name created ____________ a promotional ad a social post a flyer a landing page an open house form a text code

When viewing the actual report, the lead will be redirected to your website and a seller report landing page. This is what that page will look like:

- Same as Seller Report Email
- Full list of activities (email only shows the last five)
- Form for lead message submission

## FAQ

Q: How far back do sold listings show from the MLS on the website?

A: We usually only support displaying listings sold in the last 3 years, and it also depends on what sold data is included in the MLS data feed.
