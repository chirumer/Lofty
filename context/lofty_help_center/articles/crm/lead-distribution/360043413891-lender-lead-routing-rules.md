## Introduction

For a detailed explanation of how lead routing works, please reference the following article, as everything in that article applies here as well: Lead Routing Rules .

This article will explore a little more about how lead routing works specifically for lender-type accounts on Lofty. As a review, the lender-type account is different from a standard Lofty agent account. Please reference Being a Lender with Lofty for more information.

## Lead Routing to Lender

Lofty can lead routes to any of the different roles available on a lead, including Agent, Assistant, Custom Role, and Lender. The lender slot is always at the bottom of the list, as seen here:

A lender must be an actual lender-type account to be selected in this slot (meaning they cannot be on a standard agent seat). An agent on a team can select a lender from this drop-down in the "Assigned To" section, and this will automatically assign the lead to the lender.

Otherwise, lead routing rules based on source and other criteria can be set up (see Agent Lead Routing Rules for specifics) to route to different lenders, etc. To set this type of rule up, go to Settings > Lead Routing > For Lender :

A "Default Rule" can also be set up to assign to no lender, a specific lender, to randomly distribute via Next Up or user Blast Alert as well. All of these distribution methods are described in detail in the referenced article for Agent Lead Routing Rules .

The Lender also has the New Leads button, which allows the Lender to route leads based on the source.

## Manually-Added Leads & Lender Lead Routing

It is important to note that one difference from the Agent Lead Routing Rules is that leads that are manually added via the People page in Lofty are also sent to lenders (though they are not routed to agents, etc.). This means that when a lead is manually added using the option shown in the screenshot above, it will be sent through the "For Lender" rules (if established). If the default rule in that section is "No lender," then none will be assigned.

## Lofty Paid Leads + Lender Lead Routing

If a lender is set up on a cost-sharing relationship with the agent, specifically for lead generation purposes, they will automatically have the leads assigned to them without having to set up lead routing rules manually. See How to Invite a Lender for more information and note that the lender must be sharing buyer/seller lead generation in order for the automatic assignment to happen.
