## Body

## Introduction

Account Owners/admins can create additional custom roles for their members to fill when working with individual leads. Each additional role will appear in the bottom-left section of a lead profile called "Assigned to".

Three roles are in this section by default:

(1) Agent (2) Assistant (3) Lender

Please note that agent users cannot be assigned to the "Lender" role. An additional TEN agent role can be created . All users assigned to a lead will be able to have access to view the lead, receive opportunity notifications, etc. A new filter on the People Page is also created for each new role.

If you want to learn more about how to add a lender, please see: How to Invite a Lender

*Please note that the primary owner of the lead (associated with reporting, transaction management, property alerts, etc.) is always going to be the Lofty user in the "Agent" slot, which is always first on the list:

### Adding Additional Roles

To add additional roles, follow these steps:

1. Navigate to Settings
2. Click on Users under the Company User Settings section
3. Select the Agent Roles tab at the top
4. Click on the Add A Role button
5. Type in the new "Role Name"
6. Click Add
7. A new role has now been added to every lead profile

### Editing or Deleting Additional Roles

To edit or delete an additional role, follow these steps:

1. Navigate to Settings
2. Click on Users under the Company User Settings section
3. Select the Agent Roles tab at the top
4. Select either the Edit icon or the Delete icon to adjust the roles as desired

*IMPORTANT: Custom Role should not be confused with or replace the idea of Office/Personal Leads and Team Permissions. For more information on this topic, please reference this article: Lead Ownership as well as Permissions .
