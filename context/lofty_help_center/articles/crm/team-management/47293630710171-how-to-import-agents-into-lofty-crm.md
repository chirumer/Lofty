## Introduction

Bringing your agents into Lofty CRM ensures they have immediate access to leads, transactions, and team collaboration tools. This guide walks you through the process step by step.

We recommend using the sample file linked at the bottom of the article to configure your agents before uploading.

## Summary

- Bulk Import Agents
- Required Import Fields
- Optional Import Fields
- Troubleshooting

## Bulk Import Agents

### Step 1: Access Agent Import

1. Go to Company Settings → Users

2. Select +Add Agent

3. Select Import Members By CSV File

### Step 2: Download the Template

- Download the provided SAMPLE FILE template.

- Complete the file with your agents’ information

### Step 3: Upload the Completed File

- Save the file as a CSV.
- Upload it back into Lofty.

- Review the preview screen for errors.

- If errors appear, correct the file and reupload it before confirming.

### Step 4: Confirm & Send Invitations

- Confirm the import.
- Invitations will automatically be sent to all successfully imported agents.

### Step 5: Review Imports that Failed and Reimport (If Necessary)

In some instances, agent imports may fail even if the preview screen did not show errors.

To review failures:

1. Go to Import History
2. Select Details
3. Download the detailed CSV file to see the specific reason for failure

Correct the errors in your file and reimport as needed.

## Required Import Fields

These fields should all be in their own individual column.

If the field is not filled, the agent will not be imported.

1. First Name
2. Last Name
3. Email Address
4. Phone Country Code Ex: US
5. Phone
6. Account Type User Display Only
7. Permission Profile
8. Office

Important: The Office name must match exactly as it appears in your Organization Hierarchy.

## Optional Import Fields

1. Agent Tags Agent tags must be created in the system prior to import.
2. Default MLS Provide the name of the integrated MLS associated with your Lofty website.
3. Address Work address
4. License ID
5. Position
6. Personal Website
7. Self-Introduction Agent Bio
8. Social Media Links Facebook LinkedIn X (Twitter) Zillow Yelp Instagram YouTube TikTok Snapchat Pinterest Angi (Angie’s List) Google WhatsApp Redfin

## Troubleshooting

#### Agent Didn’t Receive Invite

- Confirm the email address is spelled correctly.
- Ask the agent to check their spam/junk folder.
- Resend the invitation from the Users page.
- If the agent is still not receiving it, please reach out to support for further assistance at (855) 981-7557 or support@lofty.com

#### Agent Already Exists in System

If the email is already in use:

- Search for the agent under the Users page.
- If the agent does not appear in your system, the email may already be registered under another Lofty account. Our team will need to release their email address. You can reach out to support to assist with this at (855) 981-7557 or support@lofty.com

## Questions?

If you have any questions regarding this topic or any others, please reach out to our Support Team via email at <support@lofty.com >, by phone at 1 (855) 981-7557, or by chat with us through your Lofty CRM.
