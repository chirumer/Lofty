## Introduction

The People Page is where you see and manage your leads within Lofty. This article will review each section within this page.

## Summary

- General Information
- The People Page
- The Segment Page

## General Information

Navigate to the People Page by clicking People . A drop-down menu will allow you to select a People view, which will show all of your leads, or a Segments view, which will allow you to see all of your Segments.

## The People Page

You can easily navigate between All Leads, your Leads, Leads in a Lead Pond, Partial Leads, and you can create a custom lead view.

Click + View to add a custom view. These views replicate the Saved Filters in the previous UI.

The Pipeline is located at the top of the page. Click the Settings Cog Wheel (#1) to edit the pipeline. Click Filters (#2) to add a filter to the leads page. Click the Graph icon (#3) to edit the columns.

#1 - Lead Pipeline

For more information on organizing the lead pipeline, please see Lead Organization with Pipeline Stages

#2 - Filters

When adding Filters, the viewable leads will automatically update based on the selected filters. Click Create View to save this view to the top of the page for future use.

#3 - Column Organization

Here, you can customize the order and visible columns on the lead page.

### How to Create a View

The View feature allows you to see a specific selection of leads with one click. To create a View, click the + View button and click Create a View

You have the option to create a fully custom view or use one of our pre-built templates.

- Not Replied to Today: The Lead has replied by Email, Call, or Text, but has not been in contact in the last 24 hours.
- Not Replied to This Week: The Lead has replied by Email, Call, or Text, but has not been in contact in the last 7 days.
- Email Activity The lead has replied by Email in the last 7 days
- Call Activity The lead has replied by Call in the last 7 days
- Text Activity: The lead has replied by Text in the last 7 days
- Active Website Browsing: The lead has visited the website in the last 7 days and browsed more than 5 properties
- Birthday is this month: The lead's birthday is this month
- Lofty Paid Lead: The lead's Source is Lofty Paid Lead

## The Segment Page

Select Segments from the drop-down menu to see the Segments.

The Action column allows you to edit the Segment name and reminder period, change the Segment order, delete the Segment, send a mass email to the leads in a segment, send letters and postcards to all the leads in the Segment, and pin a Segment to the top of the list.

### How to Create a Segment

Segment creation ability is determined by permission. Your Account Owner or Admin can toggle on the Segments permission in Settings > Permission Profiles > System Configuration > Segments . While there, they can decide if you should have the ability to create segments that are visible to everyone on the Lofty account, or only those members in your Office or Team.

If you have the Create Segments permission, you can create a Segment by going to the Segments page and clicking the + Add New button.

When creating a new Segment, you will immediately be asked if you want to add leads to the Segment right away. If so, you can add filters to select the appropriate leads for the segment.

The Automation section streamlines the process of contacting and viewing data for all leads in a Segment. If a segment does not have any automations set up, you can easily see the available automations to get started.

Once you have set up the automations, you will be able to see some reporting data. Here, we can easily see the email response rate for the leads in this segment.

Email Automation supports the following:

- Send mass email to all leads in the segment
- Send scheduled email
- Data report of every email that is sent This report can also be downloaded
- Data report of all of the mass emails sent to leads in this segment

You can manually add a smart plan to all of the leads in a Segment via the segment detail page or in the segment list. Note: You are only able to add a Company/Team Smart Plan.

If a Smart Plan is manually added to a Segment, then all of the existing leads in the segment and new leads that are added to the segment will automatically have this Smart Plan applied to them.

If a Smart Plan trigger is set to this segment in the Smart Plan settings, then the Smart Plan will only apply to leads who meet all of the triggers and conditions.

Physical letters and postcards can be sent to all of the leads in a Segment. Here, we support the following:

- Data reporting for direct mail sent to leads in the Segment
- Send postcards and letters to all the leads in the segment
- Data reporting of every campaign sent to leads in the Segment
- Record the total date of all campaigns set for this segment

The Reminder Period automation lets you set up the period during which a lead should be contacted. This automation will show you how many leads have missed their reminder period.
