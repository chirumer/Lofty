# Lead Phone Number Validity

## Body

## Introduction

Lofty uses a new API improvement to detect the number type when new leads enter the system from the Website, Zillow, Zapier, Open House, or Email Parsing (other sources). This integration will determine whether the number is a landline as well as whether the number is valid. Because this API improvement will not always be 100% accurate, users can still mark numbers as " Bad Number " to manually void that number.

There will also be a warning that displays when an invalid or landline number is selected. This will display on both the web app:

Here is how it displays on the mobile app:

For mass text messages, the system will exclude the leads with invalid phone numbers. See the screenshot of the pop-up message below:

For any auto texts scheduled in Smart Plans, the system will skip the texts if the lead’s number is marked as invalid or is a landline number.

For leads that are coming from Zapier/Zillow (no other sources are currently supported), this integration will work to detect the lead’s name as well (if unknown). Lofty will then update the lead’s name if applicable. There will be a system log left on the lead's timeline indicating what happened as an explanation to all users:
