## Introduction

The search bar allows you to search for a lead or a note using any keywords or information.

## The Search Bar

The search bar is visible on all pages of the Lofty CRM. Click the magnifying glass icon to open the search bar.

A larger search bar will open, allowing you to enter any keywords that will help you find the correct lead or note. To search for a lead, select the People tab. To search for a note, select the Note tab.
