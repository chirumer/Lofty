## Introduction

A Comparative Market Analysis is a tool that is used by real estate agents to get seller business. This is done by providing a report, called a CMA or Listing Presentation, that includes an estimate of the value of a specific property based on comparable listings that have sold, are pending, or are still active on the market. Learn more about Lofty Present here . The Listing Presentation Templates allow you to quickly create Listing Presentations without needing to make the same adjustments every time.

## Template Basics

Navigate to Marketing > Lofty Present and select Listing Presentation

A pop-up box shows the template options. Click + New Template to create a Listing Presentation template. The template options are Seller, Buyer, and Agent Presentation.

### My Templates

My Templates are Listing Presentation templates that only you can see. These are only available if you have purchased Lofty Present Personal.

### Shared Templates

Shared Templates are Listing Presentation templates that everyone on your Lofty Present Team can see and use. The shared templates can only be edited by the template creator.

### Recommended Templates

The recommended templates were created by Lofty. If you choose to use one of these templates, they can be edited when the Listing Presentation is created.

## Creating a Template

Creating the template is very similar to the customization page of the Listing Presentation report.

Hover over the page that you want to edit and click the edit icon. Move the pages around by clicking the hamburger icon. Pages can be deleted by clicking the trash can icon.

Once your edits are complete, click Save . Give the template a name so you can easily find it in the future.

After saving the template, it will be available to use in your templates list. Delete or edit the template by clicking the ... icon.
