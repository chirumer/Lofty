## Introduction

In this article, you'll learn how to use the Lofty Agent Activity tool. This tool allows you to set up and track various metrics for your team.

Note: Some of the content in this article is being Beta tested. Your Reporting page may or may not reflect this experience.

- Creating the Metrics
- Agent Metric Notification
- Agent Metric Data
- Activity Leaderboard

## Creating the Metrics

As an account admin, you are able to set up metrics for your team to report their activity, and you have the option to make these metrics mandatory or optional. To get started, navigate to your Company Settings and select Reporting . To add your first metric, click + Add Custom Metric .

Next, give the metric a name and an optional brief description to explain what this metric is to your team. Click Add Metric to create this metric.

Once the metric has been created, it will automatically be set to Active . This means that each day at 6pm (per that agent's browser settings) each of your team members will receive a push notification asking them to provide their activity for this metric.

If the metric is only Active, they can bypass the notification and continue to access their account. However, if the metric is set to Mandatory , they must complete the metric before they can use their Lofty account.

## Agent Metric Notification

If you have active metrics set up, all agents on your account will receive a notification at 6pm to complete their daily metrics. This can be done in web or mobile. On Web, the metric notification can be found via the Bell Icon under Company Announcements . The Activity Reporting announcement that is marked as To Be Submitted is the most recent daily metric request. Older unsubmitted metrics will be marked as Overdue . Completed metrics will have the status of Submitted .

The process for submitting metric data on mobile is exactly the same as outlined above.

## Agent Metric Data

Agents can also submit their metrics on the same page where they view their metrics. Navigate to Reporting and select My Activity . Here, the agent can see their own metric data and also submit historical metric data, ensuring that they are always up to date!

The My Activity page includes both custom metrics (created by the admin) and default metrics, like Calls Made and Texts Sent, which are collected automatically via the system. This means that calls made via Lofty will be tracked for you here, automatically.

## Activity Leaderboard

The Activity Leaderboard allows agents to compare their activity with others on their team. As an admin, you can compare all users across the entire account. Non-admin users can compare themselves with others in their group or sub-group. To compare across specific metrics, select the metric from the drop down menu at the top of the screen. Both default and custom metrics are available.

Note - if the data doesn't look quite right, click the refresh icon in the upper right corner!
