## Introduction

The Activity Leaderboard provides visibility into key performance metrics across your team or company. It helps track productivity and identify top performers based on communication and task completion KPIs.

## Summary

- How to use this report
- Key Performance Indicators (KPIs)
- Visuals &amp; Data Display

## How to use this report

Navigate to the Reporting page and select Activity Leaderboard . This report is available to all Lofty users. Utilize the filters to sort the activity data by a time range.

- If you are an owner or admin, you can also filter by office or team.
- If you are not an owner or admin, you can only see activity data for the agents in your office or team.

## Key Performance Indicators (KPIs)

The report tracks the following KPIs:

- Calls Made
- Conversations Over 2 Minutes
- Texts Sent
- Emails Sent
- Appointments Completed
- Tasks Completed
- Any Custom Metrics , created here - Agent Activity Metrics

## Visuals & Data Display

- Top 3 Users: Highlighted visually based on performance.
- Full Data Table: Displays all user records with the following metrics: Count: Total value for each KPI Rank: User’s position relative to others % of Total: User’s contribution as a percentage of the overall total
