# Retired - Automatic Listing Posts

## Body

## Introduction

Update: the information in this article refers to retired packages and UI. If you're looking for the latest version, check out AI Marketer .

_____________________________________________________________________________________

Automatic listing posts will automatically be posted to your selected social media profiles when the listing status changes. This feature is only available to Advanced Social Studio users.

The available listing statuses are:

- Coming Soon
- New Listings
- Open House
- Price Reduced
- Under Contract
- Sold
- Back To Market

## Instructions

To set up this feature, navigate to the Social Studio, click the Settings button, and select Auto-Post Settings:

Default content has been created for each of these status changes. The content may be edited by clicking Default Content:

Select Auto-Post Listing Rules to set when a social media post will be automatically posted and the channels to which it will be posted, you can auto-post Office and/or your listings:

To add a filter to the types of listings that are included in an auto-post, click the Filter icon next to Office Listings or My Listings . The total number of listings included, after applying a filter, is available in the lower left corner.

To turn auto-posts on for listing status changes for Office Listings or My Listings, toggle the switch to the right. To edit the social media profiles the listing status change is posted to, click the edit icon. Check the box at the bottom to set this preference for all Listing Status change auto-posts that are enabled:
