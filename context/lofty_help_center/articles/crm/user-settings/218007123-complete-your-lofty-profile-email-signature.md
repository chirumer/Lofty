## Body

## Introduction

Setting up the Lofty Profile is a key step in making sure your account is ready to go before interacting with clients via the CRM. The fields that can be edited in this section will be displayed in emails sent from the Lofty CRM, including Property Alerts and Welcome Emails, so it is very important to have your profile set up from the very beginning.

## Summary

- Profile Settings
- Email Signature

## Profile Settings

To navigate to your profile go to Settings > Profile :

Once on this page, you can complete the following profile fields. Each one is defined below.

### Profile Photo

Add your headshot, this will appear in an auto-populated email signature for property alerts, market reports, etc.

### First Name / Last Name

No explanation is needed. This is simply your first and last name as the Lofty user. If you need to edit this, here is where it's done!

### Email Address

This is the email address you will use to log into Lofty. If you change this, it will affect the email on file for billing statements, email notifications, etc.

### Phone Number

Add the best phone number to reach you here. This will be the phone number that is also placed into the auto-populated email signature for property alert emails, etc. You can always update it as needed.

### License ID

Add your license ID as an agent. This will also display in auto-populated email signatures for emails sent via Lofty so keep this up-to-date as well.

### Position

Choose your position within your organization from the pre-populated options or choose the option to Customize if you would like to add your own.

### MLS Agent ID

This part is very important to get right because this ID is used to pull in your listings for Listing Discovery , Transaction Management , and other Lofty tools.

These fields will not appear until your MLSs have been connected to your website. Once that happens, you will be able to add only one MLS Agent ID per MLS. Each MLS will be listed. In the sample below, there are four MLSs

## Email Signature

Under Settings > Communication > Email , you will find the Email Signature section. This email signature will be pulled in automatically when you send manual emails in the system and when utilizing the #signature# variable (see Email and Text Variables to learn more about how this works). To attach this signature to Automated Emails, such as the Welcome Email and Property Alert Emails, check the box at the bottom.

For your signature, you will want to typically replicate what you have used before in your email, so add your logo, email address, name, phone number, social media links, etc. Take advantage of the hyperlink option, embedding an image, etc.

If for whatever reason you would like to make your phone number clickable, follow the steps below. First, edit the code of the email signature:

Then add this part (changing both numbers of course to be your own):

<a href="tel:+1-123-456-7890">123.456.7890</a>
Here is what it would look like in the code view:

Once you click "Save", this number should now be clickable. Test it to make sure it works, as sometimes copying/pasting, etc. throws off important formatting that could cause it to not work. If for some reason it stops working, something might have been edited in the email signature so check to make sure the same format is in place as described above.

#### Email Signature Preview

The email signature shown at the bottom of Settings > Communication> Email> Email Settings is a preview only. To edit the email signature you must click on the Edit icon:

#### Variable Support

Email signatures now support agent variables. When a variable is used, it will show in the "edit experience" but once saved it will have the actual information pulled into the signature preview so that you can make sure it is working correctly.

#### Apply this signature to ALL outgoing emails

After choosing the option, the Email Signature set in the profile will be applied to all emails being sent from Lofty.

#### Default Format & Reset Link

This option will reset the signature in the profile to the signature in the welcome email which is created by the system and consists of variables as stated above.

You can set the default information for "Reset Signature" as well by following some of the steps below:
