## Introduction

Learn more about all Lofty Transaction Management features in this section of the Help Center: Lofty Transaction Management .

When you create a transaction in Lofty, you can apply a checklist that will automatically create tasks as you move the transaction to the next stages of the pipeline. In simple terms, the checklists can provide a templated set of tasks that can be made available to the team as they manage transactions.

*IMPORTANT :

- You are only able to create a maximum of 10 checklist templates for all transaction types. If a new template is needed, you will have to delete an existing one.
- If you edit/create/delete transaction stages, do not forget to update your checklist templates

## Permissions

The Company Owner/Admin or users who have the Transactions Setting permission have access to create Company checklist templates. All users on the account can use the Company checklists that have been created.

- For more information regarding permissions, see Organization - Permission Profiles

All users can create their transaction checklist templates, which are only able to be used by the creator.

## Checklist Folders

Transaction Checklists are organized into folders. The folders can be in the Company, Office, or Personal scope.

- Company folders contain checklists that are available to everyone in the company.
- Office or Team folders contain checklists that are available to everyone in the office or team.
- Personal folders contain your own personal checklists that are not available to others.

Click + Add Folder to add a new checklist folder.

Permissions mirror existing checklist permissions:

- Company Admins can manage all folders across the company.
- Office Admins can manage folders for their office and sub-offices.
- Personal folders are private to each user.

## Set Up Checklists

To create a checklist, navigate to Settings > Checklist Templates > + Add Checklist :

Company transaction checklist templates will be located in the Company settings. Personal checklist templates will be located in the Personal settings. The process for creating the templates are the same, regardless of whether you are creating a Company or Personal transaction checklist template.

First, give your checklist a name so that you can easily reference it later and choose the Transaction Type that you want this checklist to be available for. The available transaction types are Purchase, Listing, Lease, and Other. The transaction checklist can only be applied to transactions that match the type.

Once you've created the checklist, click the Edit icon to start adding the tasks.

Simply click on the + Add a Task button under the stage where you would like to add the task. The stages will correspond with what you have configured under the Transaction Management page. If you add/edit/remove a new state under transaction management for a certain transaction type, it will be reflected here automatically.

Create the task by giving it a name/description. When the task is created, this is the actual title of the task.

The Assign To field allows you to choose the transaction owner or other transaction roles. These roles must be defined in the transaction role section of the CRM. For more information go here .

Choose either "No Due Date" or choose a Due Date. This will have to be associated with a date listed on the transaction details. If you would like the due date to be on a specific date simply choose "0 Day(s)" before/after. You can add custom date fields (see Transaction Management Introduction > Transaction Custom Dates ).

If you would like to set up a reminder, you can do so either by email, SMS text, call, or push notification. Please note that a call/text package must be active to receive a notification via call or text.

The order of transaction checklist tasks can be adjusted when building out the checklist templates. When a transaction moves to the corresponding stage, all tasks will still trigger, but they will be in the order created within the checklist template.

Once you are finished adding the tasks where you would like them at the stages, be sure to click on the blue Save button at the bottom right so that the checklist is complete.

## Applying a Transaction Checklist

Please note that transaction checklists do not auto-apply like Smart Plans. They must be applied manually to a transaction.

To apply a checklist to a transaction, first, navigate to the transaction detail page. There are two ways:

(1) via a lead detail page

(2) via the Transaction Management page

Once you are on a transaction detail page, select Checklists > Apply a Checklist Template . There is also an option to add an individual task, that is not related to a checklist.

Next, choose the checklist that you want to apply to the transaction. The only ones that you will see on this list are those that match this transaction type. Click the blue Confirm button to apply it to the transaction. You can select as many checklist templates as necessary.

If you have tasks that trigger based on the stage you are currently on, they will appear immediately on the transaction detail page.

The checklist tasks can be viewed in either a list or kanban view.

As you move the transaction to a new stage ("Under Contract" in this screenshot below), the other tasks will be created as well. You may have to refresh your browser for the new tasks to appear. Note that if you go back to a previous stage in the pipeline, it will not delete the tasks that have already been created.

To mark a task as complete, simply drag the task to the Done column (Kanban view) or hover to trigger the change of status to Done (List view).

- We support up to four-digit numbers when editing the days.
- Tasks from templates can be switched to a specific date within the transaction.

- The two filter options in the list view of the transaction will retain your last selection, so you don't need to reapply the filters every time they enter the transaction page.

## Transaction Checklist Library

Transaction Checklist Library allows you to import transaction checklists directly into your workflow. No matter whether "Personal," "Office," or "Company" is currently selected in the top-left navigation bar, the Library will always remain available. The difference is that, depending on the selected option, importing a Checklist from the Library will automatically correspond to the respective scope.

Press the checklist name, and see the details of the checklist to be imported.

Importing Process:

Step 1： Name the imported template.

Step 2：Map the Stages and the importing is completed. If you have not customized the stages, this step will be skipped.

## Viewing Tasks

There are a few locations where you can view tasks that need to be completed on a transaction.

On a transaction detail page:

On the transaction page

On a lead profile page

On the Tasks page

Completed Tasks must be opted into being shown, this option is under Actions .

#### Task Presentation

All transaction tasks are displayed under a transaction stage. This makes keeping old and new tasks in the right order will be much easier to accomplish.

## Cancelled Tasks

If a transaction is cancelled and there are outstanding tasks, a pop-up will give you some options to either remove the task from your task list completely or just remove any scheduled due dates.

This pop-up both notifies you that there are outstanding tasks associated with this cancelled transaction and allows you to either change the task status to "Not Applicable", which will remove the task from your task list or remove the tasks due date, which will remove and reminders and remove the task from your calendar. Removing the due date will still keep the task in your task list.
