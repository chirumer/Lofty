## Introduction

Transactions always include some sort of documentation or paper trail. There are several ways to save documents in Lofty so that you can access them later as needed. Learn how to upload documents to Lofty here: Uploading Documents to Lofty

## Summary

- Document Instructions
- Document Folders

- FAQs

## Document Instructions

To access and save a document associated with a transaction, navigate to a Lead Profile > Transactions & Docs > click on the transaction :

You can also access a transaction by navigating to Transaction Management > clicking on a transaction :

You are now on the transaction detail page. Next, click on Documents :

Use the Click here to upload a document to attach a file:

Upload a file from your computer, Dropbox, Google Drive, send as an email attachment, or DocuSign.

- Each file that is uploaded can only be a maximum of 70 MB in size.
- There is currently no limit to the number of files that can be uploaded to a transaction.

Another way to upload a document is via a transaction task. Transaction tasks are accessed on the Checklists page of a transaction. Once you click on a task, you will be presented with four different options. The one related to this topic, of course, is the Upload option:

You will have the same options for uploading a document, and you can toggle on/off the switch that allows you to mark a task as complete once a document is uploaded.

To learn more about Transaction Checklists, see HERE .

## Document Folders

Documents are categorized in folders. A default folder will be created on each transaction and lead profile.

- There is no limit to the number of folders that can be created.
- Each file that is uploaded can only be a maximum of 50 MB in size
- There is no limit to the number of files that can be uploaded to a transaction

The default location for documents uploaded will be the Default folder. Each transaction will have a default folder. This folder cannot be deleted but can be renamed.

You can also rename or delete the other folders at any time if needed. Folders will be categorized by A-Z.

## Bulk Operations

If you need to take action on multiple documents, select the documents and choose the action from the menu.

Check the box next to one document to access these actions:

- Preview: This allows you to peek at the document without downloading it.
- Rename: This allows you to change the name of the document in the folder

Check the box next to one or more documents to access these actions:

- Download
- Delete
- Move: Moves the document(s) to another folder.
- Send Email: Attaches the document(s) to an email for sending
- Send to Docusign: Send the document for signature directly from the transaction. Requires an integrated DocuSign account.

## FAQs

#### Are notes in Transactions searchable?

Yes, the following types of notes can be searched:

- Manual Notes (including those made for calls, emails, and texts)
- System Log

#### Is it possible to upload more than one document to a transaction checklist task before it's marked as completed?

Yes, you can click the edit button on the checklist and upload the additional document.
