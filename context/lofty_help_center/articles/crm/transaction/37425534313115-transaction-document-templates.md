## Body

## Introduction

We know that real estate transactions often use the same documents. This feature lets you add those documents into Lofty and use them over and over on your transactions.

Note: All Lofty users can access Transaction Document Templates in their personal settings, but you must have the templates permission to add or edit these templates. Please reach out to your account owner for assistance creating a Transaction Document Template.

## Summary

## How to Create a Transaction Document Template

To get started, navigate to Company/Office Settings > Transactions > Document Templates . The template must be created for the specific transaction type - Purchase, Listing, Lease, or Other. Existing templates will be available here or click + Add Template to create a template.

Give your template a name, select the transaction type, then upload your documents.

Once you have uploaded the template documents, click the Edit icon to add text fields, check boxes, and radio buttons to your document.

Double click a Text box to add an autofill field from the standard and custom transaction fields.

### Document Limitations

1. Documents must be in pdf format
2. Up to 40 documents can be added to each template
3. Each document can be up to 30MB

### Template Limitations

1. Enterprise Lofty accounts can create an unlimited number of document templates
2. Non-Enterprise Lofty accounts can create up to 50 templates in the Company scope and up to 20 templates in each Office/Team scope

### Editable Elements Limitations

Each document up to the following amount of editable elements:

1. Up to 200 Text boxes
2. Up to 50 Checkboxes
3. Up to 50 Radio buttons

## Adding a Document Template to a Transaction

To apply the template to a transaction, navigate to Transactions > Select a transaction > Documents > Add New > Upload a document > Document Template.

Here, you can add as many templates and as many documents from each template as is appropriate for the transaction.

If you have added autofill fields to your template, edit the document to make sure that the autofill fields are sync correctly.

You have the option to sync these fields to the transaction.
