## Body

## Introduction

Zip Code Blast is a self-purchase lead generation option that leverages Facebook Ads to capture buyer and seller leads in a specific zip code. The AI Assistant is included for any leads generated as a result of this package.

### Why is Blast awesome?

1. Cost Blast is one of our lowest-cost lead generation options. This gives you, our users, an affordable way to find new business opportunities.
2. Availability Previously, you needed a specific listing to create a Facebook ad. With Blast, you can generate an ad using a zip code you would like to target. This opens up availability to anyone, regardless of whether you have a listing. It also allows you to target specific areas you may specialize in, or want to specialize in.

Service Type | Availability | Notes
Digital Zip Code Ads | Only available in the U.S. | Target Zip or postal codes for digital ads via the Lofty Blast platform

## Start a Campaign

To start a Campaign, go to Marketing > Lofty Blast > Zip Code Blast .

Zip Code Blasts are a monthly recurring subscription. Adjust the pricing through Market Share . Market Share controls how much of the available audience in a Zip Code your ads are shown to on Facebook. After the purchase charges successfully, a window will appear where you can customize the settings that apply to the leads captured by the ads and create recurring Ad campaigns.

IMPORTANT!

If you do not fill out these settings, we will use the default values. If this window is closed without being completed, you cannot go back and edit them.

## Cancellation

To cancel your Zip Code Blast, navigate to Marketing > Lofty Blast > Zip Code Blast and find the campaign that you want to cancel. Click the [...] icon and select Cancel .
