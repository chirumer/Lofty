## Body

## Introduction

Custom fields can be added to your Lofty instance as a way to save information in a pre-planned spot that needs to be available for every lead. When you add a custom field to the settings, you will be able to then add data to that field when editing a lead record.

## Creating Custom Fields

To add custom fields, navigate to Settings > Custom Fields > + Add New Field :

Give the field a name that you will recognize later. This field name will appear next to the field when editing the lead record:

Choose the Data Type for the field. You can create 50 of each custom field (a total of 350).

- Text
- Date
- Number
- Percentage
- Currency
- Single-Select
- Multi-Select

Notice: The Starter package is limited to 10 custom fields per type, but the rest is 50 per type. If you are still using a Starter package and are interested in using this feature to its full effect, don't hesitate to contact support(support@lofty.com) to get upgrade options.

## Adding Data to Custom Fields

To add data to custom fields, simply navigate to a lead profile page > click the three dots > Edit Details :

Scroll down and find the custom field(s) where you would like to add data and do so directly in that field. The example below shows "Favorite Color" as a custom field, but you will, of course, be adding the information to whichever fields you have created:

## Using Custom Fields

### Accessing Via Lead Profile Page

When custom field data has been added, it will appear on each lead profile under the Details section. This example below is for a custom field called "Favorite Color," and because it has information in it, the field will appear. If a custom field is left blank on a lead profile, it will not appear:

### Access Via Columns on the People Page

You can add each custom field as a column on the People page. This allows for more visibility into custom field data across multiple leads, as well as the ability to sort. The sorting logic is as follows, depending on the custom field type:

- Date : Oldest to Newest, Newest to Oldest
- Number : Highest to Lowest, Lowest to Highest
- Text : A-Z, Z-A

Note: Empty custom fields will always be last when sorting.

### Filter by Custom Fields

You can filter and therefore search your leads by using custom fields. This is accessed via the Custom Fields header under Advanced Filter .

### Using In Email/Text Variables

For more information on how to use custom field data in email/text variables, please see Email and Text Variables: Custom Fields .

## Exporting Custom Fields

Custom fields will be available in a CSV export. For more information on exporting leads from Lofty, see Lead Export .
