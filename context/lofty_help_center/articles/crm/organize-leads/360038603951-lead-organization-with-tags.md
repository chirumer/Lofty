## Introduction

The main purpose of any CRM is to provide an organization above and beyond what can be done with a typical spreadsheet or contact list. In Lofty, this happens on the People Page and consists of Pipelines, Segments, Tags, and a variety of filters. This article will introduce Tag.

## General Information

The third level of organization with the People Page is done with tags. Similar to social media "hashtags," tags can be used for whatever purpose that an Office finds useful--providing a tool that can easily be searched later on for Office leads.

Every user can create their own Tags or lead an organization, and also utilize Tags in the Company or Office Tag Library. The entire office can use Company or Office Tags, but only those created by users with the "Office Filter" or "Company Filter" permission (see Permission Profiles ).

## Manage Tags

A full list of all tags can be managed by doing the following:

1. Click on Settings
2. Navigate to Tags & Sources under the Features section If you do not have the "Office Filter" or "Company Filter" permission enabled, navigate to Tags
3. Select the Tags tab at the top
4. Add new tags, edit a tag to rename it, or delete a tag from your personal Tag Library.

## Tag Management

If you have the "Office Filter" or "Company Filter" permission enabled, you will have the Tag Management button. Any Tags added here will sync to all other users' Tag libraries. T he lock icon keeps users from editing or deleting this Tag from their libraries. Office Owners' accounts have the same logic, but their Tag Management only includes their own Office Tags.

A Company/Office Owner/Admin can add Company/Office Tags to the Tag library by clicking "+Add New" above. There is a 100-character limit when creating a Tag.

## Add / Edit Tags

To add tags to individual users, navigate to a lead profile and select the + in the "Tag" field of the Details section. If a tag does not exist, you can choose to create it:

You can also add/remove tags on up to 200 leads at once by navigating to the People Page , (1) selecting the boxes next to each lead, (2) clicking on the option to "Change Tags," and (3) selecting from the list, removing, or creating a new Tag.

The following tags are built into Lofty by default: Open House, Text Code, and Lofty Paid.

## Lofty Paid Lead Tags

All leads that enter Lofty from one of our marketing campaigns currently have the Source of “ Lofty Paid Lead .” Now, with this update, Lofty users will be able to see whether they came from one of the following, in addition to that source:

1. LoftyPaid - Google
2. LoftyPaid - FB
3. LoftyPaid - FBform

One of the above will be added as a Tag on the lead in addition to the source being Lofty  Paid Lead.

- The tags can now be used for filtering specific sources even more granularly, Smart Plans, etc.
- The tags can be added/removed manually if needed

## UTM Parameters

See the following article for a full explanation of how to edit UTM settings: Lead Source Logic > UTM Settings . As to how this applies to tags, note that the following can be populated into Lofty as tags using UTM parameters:

1. Import utm_campaign as lead tags . If a lead registers via a campaign or URL with an associated "utm_campaign," that campaign will be recorded for that lead automatically as a tag. A new tag will be created if it does not already exist.
2. Import utm_content as lead tags . If a lead registers via a campaign or URL with an associated "utm_content," that content will be recorded for that lead automatically as a tag. A new tag will be created if it does not already exist.
