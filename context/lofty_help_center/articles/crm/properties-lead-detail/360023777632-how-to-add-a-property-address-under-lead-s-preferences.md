# How To Add a Property Address Under Lead's Preferences

## Body

## Introduction

Adding a property address to a Lead Profile can help you know their preference better and keep track of the properties that they are associated with. Listings that have been saved by a lead on the Lofty IDX website will also show up in this section.

## Add a Property Manually

First, choose a lead on the “ People ” page:

Click the Properties tab.

Click “+” to add a property. Add any additional details that you might know about the property.

Input the property address. Please note that this field is required. You can select an address from the drop-down box or record the Unit or the PO Box of this property in the “Unit/PO Box” field.

*Note: If you want to input a Canada address, please ensure your browser language settings have been changed to English (Canada). Using Chrome, for example, Settings > Advanced > Language > Language > English (Canada) > Move to the top.

Choose the label from the options available that best describes this property:

- Selling: Home (Default) Investment Lease Listed Sold
- Buying: High Interest Saved Listing Left Message Requested Showing Finished Showing Under Contract Purchased

Please note that if leads have corresponding activity on the website, a property will be created automatically and labeled as “Saved Listing / Left Message / Requested Showing...” This property would also be removed automatically if the lead goes back and removes that listing from their saved listings.

Fill in the basic info about this property. Such as beds, baths, price, etc. When you fill in all the information, just click the “ Save ” button.

## Use a Property

The main purpose of the property section is to have a place where properties can be saved. An image of the property can be previewed, and the following actions can be taken as well:

#### 1. Send a CMA Report / Listing Presentation

Lofty does not create CMA reports but does integrate with CloudCMA. The only reason "Send CMA" will work is if this needs to be integrated with Cloud CMA first. More information can be found here: How to Integrate Cloud CMA with Your Lofty CRM .

#### 2. Create a Transaction

Create a transaction based on this property. More information regarding how to use transactions can be found here: Transaction Management .

#### 3. Send Home Report

Email your lead with this home report. Only available when this property is listed on the MLS.
