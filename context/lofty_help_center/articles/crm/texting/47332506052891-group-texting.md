## Introduction

Group Text in Lofty allows you to create a shared SMS thread with multiple participants, including leads, vendors, and team members. All replies are visible to everyone in the thread, making it easy to coordinate follow-up and keep conversations organized.

## Summary

- How to Create a Group Text

- Group Text Billing

## How to Create a Group Text

1. Go to a lead's profile and click Text
2. Click the + icon to create a New Group Text
3. Add leads: the lead and family members you want to include in the thread Only the selected lead and their family members can be included in the group text.
4. Add agent virtual numbers: select one or more agent virtual numbers to include in the conversation
5. Type your message and click Send

Tip: All agents whose virtual numbers are included in the thread will be able to see and respond to messages in the conversation.

## Managing a Group Text Thread

- Viewing the thread: All participants (leads and agents) can see the full message history
- Replying: Any agent in the thread can reply on behalf of their virtual number
- Adding participants: Currently, participants must be added when the thread is created
- Leaving a thread: Contact Lofty Support if you need to remove a participant from an active group text

## Group Text Billing

Each Lofty text message package has an allocated number of text messages that are available to be sent each month. Learn more about this here: Billing, Usage, and Availability for Call/Text Packages . Please be mindful that you may hit your allocated number of text messages sooner than you typically do. The number of text messages sent each month is calculated as follows:

- Each text message sent counts towards your monthly allocation. Example 1: If you send one (1) text message to one (1) number, this counts as one (1) towards your allocation. Example 2: If you send one (1) text message to a group text with three (3) other numbers, this will count as three (3) towards your allocation. Now, if one of the numbers involved in the group text responds to the group text, you will have three (3) more text messages towards your monthly allocation. This is because you were the group text initiator, so you are responsible for all text messages sent by yourself and by the others in the group text. Example 3: If you are involved in a group text, but did not initiate the group text, only the text messages that you send will count towards your monthly allocation. This is because you are not the initiator of the group text.
