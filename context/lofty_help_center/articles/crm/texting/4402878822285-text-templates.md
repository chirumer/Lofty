## Introduction

Use Lofty to create text templates that you want to have easy access to in the future. You can build out responses that you find yourself having to repeat over and over again or put together a template that you want to use in a mass text or Smart Plan. All of these are available options.

## Accessing Text Templates

To access your text templates, go to Marketing > Text Messages > Templates :

## Setting Up Text Templates

### Welcome Text

The Welcome Text is a way to automatically text your leads when they first enter your database, when you turn on the toggle button. Any welcome texts built out here are unique to your specific user account and are not shared with others on the team.

*IMPORTANT : If enabled, this Welcome Text will be sent to leads from all incoming lead sources (i.e., Zillow, Realtor.com, etc.), and it cannot be customized to trigger only for specific sources. If you would like a "welcome text" for specific sources, we recommend using Smart Plan auto texts for that purpose.

Click on + Add to add a new welcome text. Each welcome text can have a defined time range. So, you could create a welcome text that triggers after hours to let people know you will reach out the next day. If a lead enters the CRM at a time when no corresponding time range is set, no welcome text will be sent to them.

You can also utilize a previously built text template as well as image and variable options (see Email and Text Variables ). Type your message and click on Save if you have finished.

Use the on/off switch to enable or disable a certain auto text, the edit option to edit an existing auto text, and then delete if you would like to remove an auto welcome text.

With auto welcome texts configured, any new incoming leads that are assigned to you will receive the welcome text, regardless of source, as long as they are within the defined time range.

### Text Templates

These are standard text templates that, once created, can be utilized in a variety of ways throughout the Lofty platform (outlined below in Using Text Templates ). There are two types of text templates.

#### My Text Templates

Text templates added here will only be visible and accessible to you as an individual user. They are not intended to be shared with others on your team. On the main page, you can preview your templates as well as edit or delete them if you would like.

Click on the + Add to create a new template that only you can access:

You can add new content or pull in content from an existing template that has already been created. With text templates, we recommend setting up variables (see Email and Text Variables ) so that you can easily use them with many different leads but still make them personal.

#### Company and Office Text Templates

These sections are the same as "My Text Templates" except that these templates are accessible to all users in the Company/Office. However, only those who have been given the permission (see Permissions ) will have the option to create, edit, or delete these templates. All other users in the Company/Office can still use these templates!

## Using Text Templates

You are able to use text templates anywhere a text message can be sent in the Lofty platform. This includes (but is not limited to) the following:

- Lead detail/profile page
- People Page
- Smart Plans
- Call panel (during or after a call made via Lofty)
