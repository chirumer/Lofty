# Scheduled Emails

## Body

## Introduction

Lofty allows users to schedule both individual and mass emails in the CRM. This is not available in the mobile app.

### How to schedule an email

Whenever any email is being sent via the Lofty web app platform, there is a button to schedule the email:

When clicked, a menu will appear to select when the email is sent:

- Tomorrow morning
- Tomorrow afternoon
- Custom date/time

Once an email has been scheduled, it can be accessed in the top-right of a lead profile by hovering over Scheduled Tasks . From here, you can either edit a scheduled email or you can delete it.

### Important Notes

- This is currently only supported for emails, but texting will be supported in future releases
- Emails can only be scheduled for at least 5 minutes from the current time
- If an email is being edited while the originally scheduled time has already passed, the previously scheduled email will be sent without the edits.
- A maximum of 10 emails can be scheduled per lead
- A timeline log will be made every time an email is scheduled or edited
- Recipients can only be leads, not other users or external individuals. However, external recipients can still be added as CC or BCC when sending a scheduled email.
- The default time zone will be the one set in your settings/preferences, but it can be edited when scheduling each email
- If you are sending an email in bulk and need to make changes before it's scheduled, for more information, please check Send Mass Emails & Texts.
