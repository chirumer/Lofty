## Body

## Introduction

The SEO Setup Checklist is the first tab within the CMS SEO settings. This feature will help you maximize your site SEO with the help of a simple checklist.

The SEO Checklist is only available if you have a full Lofty website.

The SEO Checklist outlines the steps required to optimize your website's SEO. Click the Go to Fix button next to each step to see why this step is important and how to optimize this step.

## Basic Info

This section allows you to set your core SEO inputs, such as Brand Name, Service Area(s), and high performing website keywords.

## Integrations

Here, connect your search engine integrations, like Google Search Console. This is also where you can set up your custom website domain and your service area pages.

## Page SEO

This section lists the pages on your website and alerts you to missing SEO information. Those details can be edited here.

## Schema & Technical

This section controls advanced SEO and structured data. Most sites don’t need to change anything here. ‘Not Found’ just means no custom schema or files have been added yet — it doesn’t mean anything is broken.
Schema markup is structured data added to your site’s code that helps search engines understand:

- What type of page this is (homepage, listings, reviews, location page, etc.)
- What entities exist (real estate agent, city, property, reviews)

Think of schema as labels for Google , not text for visitors.

Techincal files control how search engines crawl and index your website. Lofty provides safe defaults, so most sites won’t need to upload anything here unless directed by an SEO professional.

- robots.txt – Tells search engines which pages they can and can’t crawl. Lofty includes a default file automatically.
- sitemap.xml – Helps search engines discover your pages. Lofty generates a sitemap for you; upload one only if you have a custom version.
- .htaccess – Advanced server rules for redirects and security. Only upload this if explicitly instructed, as incorrect files can impact site performance.

Tip: If you’re unsure, it’s best to leave these settings unchanged.
