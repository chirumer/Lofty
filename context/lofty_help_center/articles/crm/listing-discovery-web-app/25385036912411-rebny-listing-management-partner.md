## Body

## Introduction

The Real Estate Board of New York (REBNY) has added Lofty as a Listing Management Partner (LMP). This feature allows REBNY members to upload a manual listing from Lofty to the MLS.

This is a whitelisted feature. If you are a member of REBNY MLS and would like access, please reach out to support@lofty.com .

In order to access this feature, you must follow these steps:

1. You must be a member of REBNY MLS. This feature is not available to any other MLSs.
2. You must request access to this feature by reaching out to Lofty support.
3. You must sign an agreement with REBNY to switch your LMP to Lofty.

## Instructions

To get started, navigate to Listings and click + Add Manual Listing . Learn more about manual listings here: Manual Listings

### Step 1: Basic Information

The first step is to provide the listing address. You have the option to select the Entire Building for the listing. If Entire Building a toggled off, there is a field for the Unit number.

### Step 2: Listing Information

The next step is to add the listing information:

1. Basics: Listing Type Listing Status Active Coming Soon Property Type
2. Agents: Up to four (4) listing agents may be added

### Step 3: More Information

This section contains the detailed information about the property, as well as listing photos:

1. Building Info Borough Neighborhood Number of Units Built Year
2. Unit Info Ownership Type Floor of Unit Bedrooms Bathrooms Total Rooms Sq Ft Unit Exposure Unit Condition Unit View
3. Sale Info Listing Price This includes a toggle for Non-Disclosure Date Available CC/Maintenance RE Taxes Taxes Financing Co-broker Agreement Exclusive Type Commission Type Buyer's Broker Commission
4. Features Pet Policy Apartment Amenities Building Amenities Detailed Description
5. Open House Option to add Open House information, as well as select 'Broker Only' or 'Appointment Only'
6. Access Info Broker Viewing Instructions First Showing Date
7. Media Photos Video Virtual Tour link
8. Syndication: This is where this listing will be populated. The listing can be added to RLS IDX, RLS Vow, your Lofty built website, or just to the CRM. Multiple options can be selected.

The final step is to click Launch . This will publish the listing in the locations selected in the Syndication step.

### Coming Soon Listing Upload Rules

Maximum Duration:

- Listings may remain in Coming Soon for up to 14 calendar days from submission.
- Listings exceeding 14 days in this status are marked non-compliant .

Showing Start Date Requirement:

- Must be set within 14 days of the submission date when uploading the listing.
- After the Showing Start Date passes, if the listing remains Coming Soon , the system automatically changes its status to Temporary Off Market (TOM) .

After Auto-Transition to TOM:

- You can edit and resubmit the listing as Active when ready for public display.

Remember:

This is a whitelisted feature. If you are a member of REBNY MLS and would like access, please reach out to support@lofty.com .
