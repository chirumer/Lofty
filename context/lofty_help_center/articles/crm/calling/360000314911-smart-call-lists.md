## Introduction

Smart Call Lists are a perfect way to dial through a long list of potential clients. Keep in mind that in order to use the call list functionality, you must have purchased the call package add-on and the tier that provides this feature (listed as "Smart Call List"). This is available on the "Accelerator," "Unlimited," and "Three Line Dialer" call packages:

Lofty Smart Call Lists provide a quick place to find all tasks with the task type of "Call" that are due today or overdue . Because these call tasks are compiled into two easy-to-access lists, a Lofty user can easily click to begin calling all those that need to be contacted in each of those two categories.

## Today's Scheduled Tasks

1. Open the Dialer Panel by clicking on the "phone" icon in the bottom-right of the CRM.
2. Select "Today's Scheduled Tasks" from the options at the top. The leads that are populated to this list will be any that have a "Call" type task that is due today .
3. Click on the green "phone" icon to dial the list.

## Overdue Scheduled Tasks

1. Open the Dialer Panel by clicking on the "phone" icon in the bottom-right of the CRM.
2. Select "Today's Scheduled Tasks" from the options at the top. The leads that are populated to this list will be any that have a "Call" type task and whose due date has already passed.
3. Click on the green "phone" icon to dial the list.

An additional option when editing the dialer settings ( Dialer Panel > Settings > Smart Call Lists ) that allows a new filter to exist and allows for overdue call tasks to be generated from the last 30, 60, 180, or all overdue tasks regardless of how long ago they were created.

*IMPORTANT : Only a total of 150 will be part of this list–this will be the most recent 150. If the call list is finished, however, any overdue call tasks that are from before will be added to the list for the next time assuming the "All" option has been selected in the setting.

## How It Works

The calling process is the same as with any other Lofty call list. Feel free to review this article to learn more about how call lists work: Call List (Standard) .

An additional feature for Smart Call lists is that you can quickly create callback tasks for the leads that you are calling. This can be done both manually or automatically in the settings.

### To automatically create a callback task:

1. Open the Dialer Panel by clicking on the "phone" icon in the bottom-right of the CRM.
2. The menu at the top-left of the panel.
3. Select "Settings" at the bottom.
4. Choose "Auto".
5. Select the leads you want to apply it to and the default task time to be created.
6. The setting will be automatically saved as there is no "Save" button.
