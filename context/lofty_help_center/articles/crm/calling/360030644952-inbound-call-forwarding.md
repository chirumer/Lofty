## Introduction

Lofty provides a solution for making sure incoming phone calls are not missed. With this feature, incoming calls to Lofty virtual numbers will be forwarded to a specific phone number if the agent is not available or does not pick up the phone within a specified time.

* This feature is available on all Lofty call packages.

## Important Definitions

Bridge Number : The number that is connected to the Lofty virtual number. For example, if you call a lead via click-to-call, the virtual number will call this number so you can answer, and then a call will be made to the person you are calling.

Forwarding Number : This is the number that will be called when the bridge number is unavailable or the agent does not answer the call for the indicated time.

Transfer to Forwarding Number after If a call is not answered within the defined time limit, the call will be transferred to the Transfer Number . This will also happen if the agent’s bridge number is busy, has no signal, etc. If the latter is the case, we will transfer the call immediately without waiting for the defined period.

Apply the rule to team members : The switch is only available with “Manage Team” permission (see Team Permissions ). They can easily apply all the calls to the same phone number (maybe a company number) by this setting in case of changing the number of every account one by one.
