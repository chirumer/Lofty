## Introduction

Revaluate has built an integration with Lofty that will be managed directly via their platform and allows scoring and other data to be visible within Lofty. Please visit revaluate.com/lofty to sign up and request additional information on how this works.

If you would like to discuss questions regarding Revaluate, please reach out to Revaluate at <support@revaluate.com>.

## Questions?
