## Introduction

Lofty has a direct API integration with Ylopo that is set up from Ylopo's end. There are no specific steps that need to be followed on the Lofty side to set this integration up other than to provide the team at Ylopo with your Lofty API Key. This can be found by going to My User Settings > Integrations > API and selecting "Copy":

Provide this API key to Ylopo so they can connect your Ylopo account with Lofty.

Once Ylopo has the required credentials to connect with Lofty, users of the Ylopo platform will go through an onboarding process on the Ylopo side to show you how to use the Ylopo (Stars-based) tools and how this connects in the Lofty platform as well.

## New Users

Users interested in signing up with Ylopo can reach out to <sales@ylopo.com> and their onboarding team will guide you through the typical steps of adding a Ylopo integration to an existing Lofty account.
