## Introduction

Certain IMAP/SMTP email accounts can be integrated with Lofty. We currently have support for the following:

- iCloud
- GoDaddy Webmail
- Yahoo!
- Newtek Webmail
- AOL Integration

*For any email services not on this list, please contact our Support Team ( support@lofty.com ) to determine whether we will be able to make the connection or not.

## General Steps to Integrate Your IMAP/SMTP Email

Navigate to Settings > Integrations > IMAP/SMTP , click the " Connect " button and a new window will appear.

Here, you can enter your Email Address, Password, and Server settings. Then click Save .

*Note: It may take some time to verify your IMAP/SMTP email account.

## iCloud Settings

IMAP server:  imap.mail.me.com

IMAP port: 993 (SSL)

SMTP server: smtp.mail.me.com

SMTP server: 587(TLS), 465

Note: When integrating iCloud, please use the app-specific password here:

For more details about the app-specific password, please refer to Using app-specific passwords.

## GoDaddy Webmail Settings

*This feature will not work with GoDaddy Office 365.

IMAP server: imap.secureserver.net

IMAP port: 993 (SSL), 143

SMTP server: smtpout.secureserver.net

SMTP server: 465 (SSL), 80, 3535, 25

For more details, please check the Email Setup Center in GoDaddy Webmail:

## Yahoo! Settings

IMAP server:  imap.mail.yahoo.com

IMAP Port: 993 (SSL)

SMTP server: smtp.mail.yahoo.com

SMTP server: 465 (SSL)

Please note that you need to Allow apps that use a less secure sign-in in Yahoo! account settings before connecting this way. For more details, please refer to Ways to securely access Yahoo Mail.

## Newtek Webmail Settings

IMAP server:  mail.yourdomain.com . (e.g. mail.todayrealestate.com)

IMAP Port: 143 (No SSL, select None in Security Mode)

SMTP server: mail.yourdomain.com . (e.g. mail.todayrealestate.com)

SMTP server: 25 (No SSL, select None in Security Mode)
