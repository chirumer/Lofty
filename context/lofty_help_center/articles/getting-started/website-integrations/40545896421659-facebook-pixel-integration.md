## Body

## Introduction

If you are running ads on Facebook to send leads to your Lofty IDX website, a very important tool to set up via your Lofty website settings is the Facebook Pixel.

## Facebook Setup

The first step is to make sure you have your Facebook Pixel set up. For more information reference the following article by Facebook: The Facebook Pixel . Once you have this setup, locate your Facebook Pixel ID and have it ready to add to your Lofty CMS Tool. You can reference this article by Facebook for more information on doing so: Create and Install a Facebook Pixel .

## Add Facebook Pixel to Lofty Site

First, open the CMS Tool > Settings > Tools > Facebook Pixel>Edit:

To connect, first, create and install a Facebook Pixel (follow Facebook's instructions to connect Facebook Pixel to your site), then add the Facebook Pixel ID to your site.

This will start working on the website almost immediately.

## Test the Connection

If you want to check whether the installation was successful, you can use this Chrome plugin: Facebook Pixel Helper .
