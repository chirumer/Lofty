## Introduction

Google Search Console is a free service provided by Google that helps you monitor and maintain how your website displays in Google search results. This article will show you how to set up Google Search Console. Learn how to manage your index here: Mastering Site Index via Google Search Console

## Summary

- Set Up Google Search Console 1. Authorize via the SEO Tool 2. Authorize via HTML Tag

## Set Up Google Search Console

Before managing your page or website index on Google Search Console, you need to add your site as a property in your Google account. There are two methods to connect your Google account with your Lofty website:

### 1. Authorize via the SEO Tool

1. Navigate to Website > SEO and scroll down to the SEO Checklist to find the Connect to Google Search Console task.
2. Click Connect and log in to your Google account. Lofty will automatically submit the sitemap once the connection is complete.

### 2. Authorize via HTML Tag

1. Log in to Google Search Console
2. Select URL prefix
3. Find the HTML tag and click Copy
4. Navigate to CMS > Settings > Tools > Header Meta Tags
5. Paste the full code into the input box
6. Click Save
7. Return to Google Search Console and click Verify

Google's official instructions are available here:

- Add a website property to Search Console
- Verify your site ownership
