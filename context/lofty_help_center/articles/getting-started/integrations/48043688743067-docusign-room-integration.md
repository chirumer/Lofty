## Body

## Overview

DocuSign Rooms is a DocuSign product designed specifically for real estate transactions. It gives you a centralized workspace to store all deal-related documents, collaborate with other parties (buyers, sellers, title, etc.), and track the progress of a transaction from start to close.

Lofty integrates with Docusign Rooms, allowing you to connect your transactions in Lofty directly to your DocuSign Rooms workspace. This keeps your deal information organized and in sync across both platforms, without switching back and forth or duplicating work.

Note: DocuSign Rooms is a separate product from DocuSign eSignature. If you are looking for information on the Docusign e-signature integration, check out Docusign E-Signature Integration.

## Getting Started

### Connect Your DocuSign Account

Before you can use the integration, you'll need to link your DocuSign account to Lofty. Navigate to Personal Settings > Integrations > DocuSign.

You can either connect your exiting DocuSign account or sign up for a new one.

### Linking a Transaction to a DocuSign Room

You can link a Lofty transaction to a DocuSign Room from three places:

- A lead's detail page
- The Transaction List
- A transaction's detail page

#### Option 1: Link to an Existing Room

If you already have a DocuSign Room created for the deal:

1. Open the transaction in Lofty
2. Select the option to connect to a DocuSign Room
3. Search for and select the existing room
4. On first-time mapping, you'll be prompted to choose which values to keep if there are any conflicts between the two

#### Option 2: Create a Room While Creating a Transaction

If you're starting fresh:

1. Create a new transaction in Lofty
2. Select the option to also create a DocuSign Room at the same time
3. Lofty will create the transaction on its side and a new Room in DocuSign, then link them together automatically

### Claiming Unclaimed Rooms

If you have existing DocuSign Rooms that aren't yet linked to a Lofty transaction, you can claim them from the Transaction List. A drawer will display all unclaimed rooms, and you can map each one to an existing transaction or create a new one.

### Syncing Between Lofty and DocuSign

Once a transaction and a Room are linked, changes stay in sync automatically:

- Lofty → DocuSign: Syncs in real time
- DocuSign → Lofty: Syncs within 5 minutes

### Viewing Folders and Files

Once a transaction is linked to a DocuSign Room, the folders and files from that Room are visible directly inside the transaction in Lofty. This gives you a read-only view of all your deal documents without leaving the platform.

### Sending for E-Signature

From within a linked transaction, you have two options for document signing:

- DocuSign eSignature – Send an envelope for signing directly from Lofty (same as the existing eSignature feature)
- DocuSign Rooms – Click to open the full DocuSign Room in a new tab for more advanced document management

### Frequently Asked Questions

Do I need a DocuSign Rooms subscription? Yes, DocuSign Rooms is a separate DocuSign product. You'll need an active DocuSign Rooms account to use this integration. Contact DocuSign directly for pricing and plan details.

Will this affect my existing DocuSign eSignature setup in Lofty? No. Your existing eSignature workflow is unchanged. This integration adds Rooms functionality alongside it.

Can I link one Room to multiple transactions? Each DocuSign Room maps to one Lofty transaction.

What happens if there's a conflict when linking for the first time? Lofty will prompt you to choose which values to keep, so nothing is overwritten without your input.
