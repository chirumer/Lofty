## Introduction

Lofty integrates with Adwerx for those who use their advertising services. This integration is available for all Lofty websites, including subdomains.

You will need your unique Adwerx retargeting pixel to set up the integration. You can find this by logging into your Adwerx account and finding the Agent Retargeting Pixel Guide ( screenshot ).

Your retargeting pixel should look like this:

## The Integration

Navigate to Website/CMS Tool → Settings → Tools → Integrations to connect to Adwerx.

To complete the integration, fill in the retargeting pixel, provided by Adwerx, and the Lofty website URL of a specific page that you want to add the retargeting pixel to.

Note: The Lofty website URL will be auto-filled as the website whose settings you are currently in. The empty field after the URL is to add the pixel to only one specific page. If you leave the website URL field empty, the pixel will apply to all pages on this Lofty website by default.

You can update the integration by clicking Edit .
