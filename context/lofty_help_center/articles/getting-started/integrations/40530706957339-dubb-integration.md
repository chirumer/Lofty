## Introduction

One of the most powerful ways to communicate with your leads is with video messaging and one of the best tools out there to do this is Dubb.

*IMPORTANT : This integration only works with the Chrome browser . You will need to access Lofty via Chrome in order to use Dubb directly on our platform. On the mobile side, you can use the Dubb mobile app to produce content and create sharable links that are sent out via SMS messages using the Lofty mobile app, but there is no direct integration at that level currently.

## Sign Up with Dubb

To use Dubb with Lofty, you must first have a Dubb account. You can set up an account by clicking on the following link: CLICK HERE .

You can also navigate to your Marketplace > Marketing Tools > Dubb :

You will use your Dubb account credentials later during the setup process so keep them available.

## Dubb + Lofty Setup

Two separate connections need to be made to have the full functionality. Both are outlined below.

### (1) Chrome Extension

This connection is important because it is via this one that you will record and select videos on the Lofty platform.

Navigate to the following link to install the Dubb Chrome Extension:

Link = Screen Recorder, Webcam Recorder - Dubb Video

Click on the Add to Chrome button to add this extension to your Chrome browser:

Confirm that you would like to add the extension by clicking the Add extension button:

You should then see a screen from Dubb explaining the basics of how to use the Dubb. Once you have reviewed and followed the indicated steps, go ahead and click on the green Continue button at the bottom.

If you have any issues in giving Dubb microphone and webcam access please review How to Allow Webcam and Mic Access to the Dubb Chrome Extension .

Next, click on the Dubb icon that is part of your Chrome extensions, and then click on the log-in hyperlink.

You will be redirected to the Dubb login page where you will sign in with the credentials that you created in the first step of this process.

Once you are logged in you should be redirected to the Dubb dashboard which will look something like this:

Click on the Dubb icon again in your menu bar and it should automatically recognize that you are signed in.

You have now connected Dubb to your Chrome browser via the extension which allows for it to be used in a variety of platforms, including Lofty.

### (2) API

This part of the connection is important because it allows for activity on your Dubb videos to feedback on the lead profiles within Lofty.

Sign in to Dubb, click your profile picture in the top-right, and then select Your Settings :

On the menu at the left, select Team and then Marketplace :

Scroll down until you find Dubb Lofty Extension and click the Install button:

You will see a pop-up appear like this:

To find your Lofty API key, navigate to the Lofty CRM, click on Settings > Integrations > API , and then click on the Copy button to copy your unique Lofty API Key.

Go back to the Dubb pop-up, paste the Lofty API Key into the API Key field, and then click on the blue Submit button.

## How the Integration Works

There are two main parts to using the integration. The first is the actual embedding of videos into communication sent via the Lofty platform. The second is the activity tracking.

### Adding Videos

In the Lofty platform, navigate to any of the tools you typically use to either send emails or text messages. Within each of these tools, you should see the Dubb icon present. If the icon is present, it means you can use Dubb to access any pre-recorded videos or record another one that can then be sent out via text or email in Lofty.

- When sent via email, a clickable GIF will be embedded in the email.
- When sent via text, a Dubb link will be added to the text message.

Below we will review two examples to show how this works, but the integration can be used wherever you send texts/emails in the Lofty platform including all of the following locations:

- Email Templates
- Text Templates
- Smart Plans Auto Emails Auto Texts
- Text Codes
- Mass Email
- Mass Text

Example 1 - Email Template

In a Smart Plan auto-email, you will see the Dubb icon here:

When you click that icon, you will see the Dubb application pop-up appear with access to videos you have already recorded or the ability to record a new one if you would like to do so.

Once you have selected a video that you would like to insert, you will see this screen appear. Click on the Insert Video button to add the video to the email.

The video will then be added directly to the email with a GIF to show a video can be clicked when the email is received by the recipient.

Example 2 - Text Template

In a Smart Plan auto-text, you will see the Dubb icon here:

When you click that icon, you will see the Dubb application pop-up appear with access to videos you have already recorded or the ability to record a new one if you would like to do so.

Once you have selected a video that you would like to insert, you will see this screen appear. Click on the Insert Video button to add the video to the text.

The video will then be added directly to the text. The difference from an email is that this will just insert a link that can be sent via text, no image, etc.

### Activity Tracking

When we talk about "Activity Tracking" for Dubb videos, we are referring to the ability to have all of the following actions feed a log back into each corresponding Lofty lead profile:

- CTA Clicks
- Email Clicks
- Emoji Reactions
- Form Submissions
- Email Opens
- Video Replies
- Page Views
- Video Views

When tracked in Lofty, the logs will be documented as notes added by Dubb:

The tracking logic works slightly differently for mass emails and emails sent via Smart Plans vs. those that are one-off emails to one specific person.

#### Mass Email / Smart Plan Logic

Any emails sent via Lofty in mass or via Smart Plans will automatically have tracking data produced for everything listed above and directly in the corresponding lead profiles in Lofty.

#### One-Off Emails

For one-off emails sent via a lead profile page, it works slightly differently.

The very first thing that you will want to do is copy the lead's email address from their lead profile:

A one-off email is sent by navigating to a lead profile and clicking the Email button:

Click the Dubb button:

Choose a video that you would like to add to your email:

Once you select a video, you should see another pop-up appear that asks for you to enter the lead's email address. You can now paste in the email address that you copied before which will allow for Dubb to find this lead in the future and feed in the tracking details. Click on the Insert Video button to add the video to the email and proceed.
