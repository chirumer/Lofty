## Introduction

Sisu is a powerful tool that allows for great visualization and gamification of goals, transactions, etc. For more information see https://sisu.co/ .

## Lofty <> Sisu Integration

Sisu and Lofty have collaborated to build an integration that provides access to as much data as possible on Sisu. To learn more about this integration, please reference the following article maintained by Sisu in the Sisu Knowledge Base:

Integrating Sisu and Lofty
